◆ Stack check

Next.js Sept 30

Still nothing new to patch: Next.js 16.3.8 is current

The newest Next.js release is v16.3.8 (Sept. 30), a scheduled security update covering one high, five medium and one low severity issue: SSRF in Image Optimization, metadata route information disclosure, SSG/ISR cache poisoning and Draft Mode leakage. v15.5.27 is the matching 15.x release. v16.3.7 (Sept. 29) backported bug fixes. My searches found no new React, Tailwind or Supabase advisories since.

So what for TSD: If any client site is below 16.3.8 (or 15.5.27 on the 15 line), upgrade it today and redeploy. Check with npm ls next on each repo.

◆ Breaches that came through a trusted door

Breach Oct 5

Hackers took Denmark's population registry data for 8.8 million people

Attackers obtained names, addresses and CPR national ID numbers by compromising a Danish company that legally had access to the registry. Denmark's digital affairs minister called it extremely serious. No perpetrator has been named, and the compromised company's access had not been revoked at the time of reporting.

So what for TSD: The weak link was a vendor with legitimate access. For client sites, list every third party that holds a key or login (analytics, CRMs, form tools, agencies) and revoke the unused ones.

Exploited Sept 27–Oct 4

Citrix NetScaler flaws are being mass-exploited

CISA and Google's threat team describe active exploitation of critical NetScaler ADC and Gateway zero-days (CVE-2026-88771 through 88778 per This Week in Security; one outlet cites a further CVE-2026-88779), allowing remote code execution and wider network access. Guidance is to assume compromise and preserve forensics before patching.

So what for TSD: Not your stack, but any client with a NetScaler gateway is exposed. Ask during discovery calls and flag it.
CISA ↗ · This Week in Security ↗
Supply chain Jul–Sep

LuaRocks and a Polish invoicing platform both lost API keys

LuaRocks rebuilt its servers after multiple incidents exposed usernames, bcrypt hashes, API keys, 2FA secrets and GitHub tokens. Fakturownia, a Polish invoicing platform, lost data on 500,000+ businesses including invoices, payment details and API keys.

So what for TSD: Stored API keys are the prize in both. Keep client secrets in Vercel/Supabase environment variables, rotate them on a schedule, and never in the repo.
