◆ Patch this — your stack

Security June 2026 release

Next.js June security release: upgrade to 15.5.18 or 16.2.6

Next.js shipped security fixes spanning Server Components, App Router, middleware, and proxy — covering denial-of-service (CVE-2026-23869), SSRF, XSS, cache poisoning, and a middleware/proxy bypass via segment-prefetch routes (GHSA-267c-6grr-h53f). All issues are patched in 15.5.18 and 16.2.6, with backports for 15.5.16 and 16.2.5. These are described as June backports of fixes first shipped in May, so anything you didn't patch then is still exposed. Patching is the only complete fix.

So what for TSD: Concrete action this week. Most of your client and demo sites run Next.js on Vercel. Run npm ls next (or check package.json) across every site and bump any below 16.2.6 / 15.5.18, then redeploy. Vercel-hosted apps still need the dependency bumped — the platform doesn't auto-patch your lockfile. While you're in there, confirm FFmpeg ≥ 8.1.2 on the podcast pipeline from yesterday's note.

Patch June 2026

Node.js also shipped June security releases

Node.js published its own June 2026 security releases. Since your Vercel functions and local tooling run on Node, it's worth bumping to the patched runtime line at the same time you do the Next.js upgrade — one maintenance pass, two fixes.

So what for TSD: Pin your Vercel project Node version to the latest patched LTS and update local nvm. Batch it with the Next.js bump so you only redeploy once.

◆ Silicon — the buildout keeps reshaping the supply chain

Hardware Tue, June 24

OpenAI unveils "Jalapeño," its first custom inference chip with Broadcom

OpenAI unveiled its first custom-built inference processor, "Jalapeño," designed and manufactured with Broadcom for its own inference systems. Early results claim significantly better performance-per-watt than current state-of-the-art parts. It's the latest big lab to go vertical on silicon to cut the cost of serving models, following the path Google (TPU) and Amazon (Trainium) already took.

So what for TSD: Indirect but it points one way: inference costs keep falling as labs build their own chips. That's tailwind for your margins on AI products — the per-call cost of an AI receptionist or RAG concierge trends down over time, so retainer pricing you set today gets cheaper to serve.
TechCrunch — OpenAI unveils its first custom chip, built by Broadcom
Costs June 2026

TSMC raises prices across all advanced nodes

TSMC told clients that "all advanced nodes" are getting more expensive — extending hikes beyond 3nm and 2nm to 5nm and 7nm, roughly in the 5–10% range. Those nodes are about 74% of TSMC's wafer business, so Nvidia, AMD, Apple, and Qualcomm all eat higher costs, which eventually shows up in device and GPU pricing.

So what for TSD: No direct hit, but it's a reason hardware (laptops, phones, GPUs) won't get cheaper near-term. If you're advising clients on hardware refreshes or planning your own gear buys, lean toward "buy what you need now" rather than waiting for price drops.
