◆ Patch now

Advisory Oct 21

Node.js fixes ten vulnerabilities, including remote code execution in Brotli decompression

The Node.js project shipped security releases for every supported line on Oct 21. Konfirmity counts ten CVEs with four rated high; the worst is a memory corruption bug in Brotli decompression that Node.js says permits remote code execution. Fixed versions are 22.23.4, 24.22.1 and 26.12.1. There are no workarounds, and Node 20 and older get no fix (Node 20 hit end of life Apr 30). One other write-up counts three highs instead of four, so check the official advisory for the final tally.

So what for TSD: Patch instruction: set every client project's Node version on Vercel to 22.x or 24.x so it picks up the patched runtime on the next deploy, redeploy each production site this week, and bump any local nvm or Docker images to the fixed versions. Any project still pinned to Node 20 gets moved now.

Advisory Oct 21

PHP2Shell: emergency PHP fixes for two critical unauthenticated RCEs

CVE-2026-109618 and CVE-2026-109619 (CVSS v4 9.2 each) let an unauthenticated attacker run code on servers running PHP. Wiz says every PHP release of the last decade is affected by at least one, back to 5.4. Fixed versions: 8.5.12, 8.4.27, 8.3.36 and 8.2.35. Finland, the Netherlands and France took government sites offline while patching, and the NSA issued similar direction.

So what for TSD: Patch instruction: TSD's own stack has no PHP, but many prospects run WordPress. Any client or prospect on WordPress or shared PHP hosting should confirm their host has moved to a fixed PHP version this week. That check is a five-minute favor that opens a rebuild conversation.

Reminder Oct 14–15

Still on Next.js older than 16.4.1? Last week's critical RCEs still apply

The Oct 14 release (15.5.28 and 16.4.1, with 16.4.2 a day later) fixed critical RCEs in use cache and SVG image optimization plus a Server Actions DoS. One secondary source warns an old lockfile can keep a vulnerable sharp version even after bumping next.

So what for TSD: Patch instruction: if any client repo has not landed 16.4.2 or 15.5.28 yet, do it in the same redeploy as the Node bump, and regenerate the lockfile.

◆ Your stack

Supabase Oct 22

Supabase shows how to give your app its own MCP server

A new Supabase post lays out a per-app MCP server where every tool call runs as the signed-in user, so the row-level security policies you already wrote decide what each agent can reach. A day earlier Supabase shipped a unified .NET SDK, and on Oct 20 it posted a guide to checking production with a coding agent.

So what for TSD: This is the cleanest way to let a client's customers use ChatGPT or Claude against their own account data. Prototype it on one existing Supabase client app and add it as an "agent-ready" upsell.

Vercel Oct 16–20

Vercel adds usage-billed Daemons and a Drives storage product

A pricing tracker logged Vercel Daemons with 5 included Active CPU hours a month, then from $0.128/hr, and 420 GB-hrs of provisioned memory, then from $0.0212/GB-hr. It also logged Vercel Drives, persistent storage at $0.05/GB-month with metered reads and writes. These come from a third-party tracker, so confirm on Vercel's changelog before pricing anything on them.

So what for TSD: Long-running daemons on Vercel would let TSD Front Desk's background workers live next to the site instead of on a separate box. Read the docs before quoting it to a client.

◆ Chips and big tech

Markets Oct 22

AI spending fears hit chipmakers; Apple closes in on Nvidia

The Nasdaq fell 2.6% on Thursday, its steepest drop since June, and the S&P 500 lost 1.21% after Meta raised capex guidance and posted negative free cash flow. Intel and AMD each fell about 8%, Broadcom 4.3% and Nvidia 4.4%. Apple was the only Magnificent 7 gainer, rising 1.2% to a record $348.22 and sitting about $42B below Nvidia's market value; Apple reports Nov 2 and Intel Oct 29. Lam Research had reported a record $8.2B quarter on Oct 21, up 54% year over year.

So what for TSD: No action for the business. AI compute supply keeps growing either way, which keeps model prices falling for small builders.
