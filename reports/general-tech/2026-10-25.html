Security Oct 23

PHP warns of another session flaw, CVE-2026-115560, with no emergency fix

This is separate from the two PHP2Shell bugs. It only hits apps that set session.serialize_handler to php_binary or php_serialize, switch it to php at runtime before session_start(), and leave session upload progress on. PHP will fix it in its next routine release, with no severity score yet and no reported exploitation. Mitigation: set session.upload_progress.enabled=0. Hosts that already did this for PHP2Shell need nothing more.

Context: Reuters reports the PHP Foundation runs on one full-time staff member and 14 contractors, which helps explain the patch pace.

So what for TSD: Prospects running WordPress are on PHP. Anyone you do the PHP2Shell check for should get this line in php.ini (or their host's panel) at the same time. It costs five minutes and gives you a second reason to follow up.

Security Oct 23

Node2Shell: the Node.js Brotli RCE gets a CVE and a warning about the wrong fix

The Brotli decompression bug Node fixed on Oct 21 is now tracked as CVE-2026-111497 ("Node2Shell"), rated 9.2 under CVSS 4.0. Fixed versions are 26.12.1, 24.22.1 and 22.23.4. Updating the npm package called brotli does nothing for it; the bug is in Node's built-in decoder.

Next.js reminder: 16.4.1 (Oct 15) carried the critical RCE fixes, and 16.4.2 (Oct 16) is an LTS update with Turbopack fixes. Anything older than 16.4.1 is still exposed.

So what for TSD: Vercel manages the Node runtime for hosted functions. Anything you run yourself (the Mac mini, local scripts, any Docker or VPS deploy) needs Node bumped by hand. Run node -v on each box this week and confirm every client repo is on Next.js 16.4.1 or later.

Platform Oct 23 · Oct 12

Supabase opens a Knowledge Base beta and confirms the Nov 10 TLS cipher cutoff

Supabase launched a Knowledge Base in public beta with troubleshooting and migration guides written for developers and the coding agents they use. Separately, its Oct 12 breaking-change notice stands: an outdated subset of TLS 1.2 ciphers will be disabled on project HTTP APIs (Auth, Data APIs, Storage, Realtime, Edge Functions) on Nov 10. Supabase puts affected traffic at under 0.0001%, and it hasn't listed the exact ciphers.

So what for TSD: Modern browsers and Node are fine. The risk is an old device or integration hitting a client's Supabase API, such as a legacy POS, a kiosk, or an old Zapier-style webhook relay. If any client has one, test it before Nov 10. Point Claude Code at the Knowledge Base when debugging Supabase.

Security Oct 24

Reuters: experts expect AI-found bugs to keep causing outages

Seven security professionals told Reuters to expect more outages like this week's government-site shutdowns. Cloudflare CEO Matthew Prince said he knows of "a bunch of additional severe vulnerabilities" in other critical software and expects a couple of years of constant alarm. VulnCheck says AI helped double year-over-year vulnerability discoveries. Others pushed back: curl's Daniel Stenberg says AI-found bugs tend to be exotic and hard to exploit, and more disclosures don't automatically mean more successful attacks.

So what for TSD: Patch speed is becoming something clients will pay for. A "we patch within 48 hours of a critical advisory" line belongs in every Managed AI and hosting retainer, and these reports give you the evidence to back it up.

Privacy Oct 23

Google: connected Gmail and Photos content can now shape ads

Google's updated privacy policy still says it doesn't use Gmail, Drive or Photos content for ad personalization by default, but there's now an exception for users who explicitly connect that content to Google services that offer personalized ads. To turn it off: Google Account → Data & privacy → Personalization settings → Manage Personalized Recommendations in Search Services, then disconnect Workspace and Photos under Connected Content apps. Disconnecting doesn't erase data already in Search history.

So what for TSD: Check that setting on the TSD Google accounts. It's also a two-minute tip worth sending to clients who run their business out of Gmail.
