◆ Patch this weekend

Security June 2026

Next.js coordinated release fixes 13 advisories, including an RSC denial-of-service

Vercel's June coordinated security release spans 13 advisories across denial of service, middleware/proxy bypass, SSRF, cache poisoning, and XSS. The headline is CVE-2026-23870, a high-severity React Server Components DoS: specially crafted HTTP requests trigger excessive CPU on React 19.x and on every Next.js App Router deployment across 13.x, 14.x, 15.x, and 16.x. Separately, CVE-2026-44578 is an SSRF via crafted WebSocket upgrade requests that hits self-hosted Node.js deployments, letting an attacker proxy requests to internal or external targets.

WAF rules can blunt some of this, but every writeup says the same thing: upgrading to the patched release is the only complete mitigation.

So what for TSD: Most of Nash's client sites are Next.js App Router on Vercel, so the RSC DoS applies broadly. The SSRF one matters most anywhere a build is self-hosted on Node rather than on Vercel. Action: bump every TSD repo to the patched Next.js version this weekend and redeploy — it's a 20-minute sweep that closes a real hole.

◆ Your stack got more headroom

Platform June 2026

Vercel Functions can now run up to 30 minutes on Fluid

Guillermo Rauch said Vercel Functions can now run for up to 30 minutes on Vercel's homegrown microVM infrastructure, Fluid — a jump aimed squarely at longer tasks like AI workloads. Fluid also brings in-function multi-concurrency (one instance handling several calls) and Active CPU pricing that bills only while code executes, at $0.128 per Active CPU-hour plus provisioned memory and per-invocation charges. Builds, Sandbox, and Functions all now run on Fluid.

So what for TSD: The old serverless timeout was a real wall for anything heavy — multi-document RAG ingestion, the daily podcast render, longer agent chains. Thirty-minute functions plus pay-only-while-running pricing means more of Nash's pipeline can live on Vercel instead of a separate worker, with cost that tracks actual work.
