◆ Patch list

SecurityAdvisory Aug. 25; exploited Sept. 18+

Next.js CVE-2026-75604: RCE via backslash path traversal

Next.js 13.4.0 through 15.5.23 and 16.3.2 do not consistently escape backslashes in route segments, which can expose the server-reference-manifest encryption key and lead to remote code execution. The write-up states it needs a Windows-hosted server with Pages Router and App Router both enabled, Cache Components off and the default on-disk cache; Linux and macOS are not affected. Fixed in 15.5.24 and 16.3.3; the analysis recommends 15.5.26 and 16.3.6. After patching, delete cached encryption keys and rotate the Server Actions key. This is a secondary analysis, so confirm against the Vercel advisory. Yesterday's "nothing to patch" holds for Linux and Vercel-hosted apps.

So what for TSD: Confirm every client app runs on Vercel or Linux and write that down; scanners will flag the CVE regardless. If any client self-hosts on Windows, patch today.

◆ Supabase & Vercel

BreakingOct. 30

Supabase: new public tables no longer auto-exposed to the Data API

Per a May 29 write-up, projects created after May 30, 2026 already follow the new behavior; existing projects switch on Oct. 30. New tables in the public schema will need explicit GRANT statements for anon, authenticated and service_role. Existing tables keep their grants. Migrations and AI tools that create tables will break without grants. That source does not link Supabase's official notice, so verify in the Supabase docs.

So what for TSD: Add GRANT statements to your migration template now and test on a staging project. Offer clients a pre-deadline check as a paid add-on.

DealOct. 2

Supabase acquires Turso and raises $150M

Supabase announced a $150M round led by GIC with CapitalG, IronArc and SquarePeg, and said it is acquiring Turso; Turso's founder Glauber Costa becomes Head of Agentic Services. Supabase says over a million databases are created weekly, about 70% by agents or AI tools. Price and closing were not disclosed.

So what for TSD: Supabase is betting on agent-built apps. Expect more agent-friendly features, and expect clients to show up with half-built AI-generated apps on Supabase.
Supabase blog PR Newswire
PlatformOct. 1

Vercel: Node 20 disabled, metric rename, Secure Compute for Sandboxes

Vercel's changelog lists Node.js 20 disabled in Project Settings on Oct. 1, Edge Requests renamed CDN Requests with pricing unchanged, Speed Insights dropping First Input Delay on Nov. 1, and Sandboxes able to join a dedicated Secure Compute network.

So what for TSD: Check each client project's Node version setting and move anything on 20 to a supported version before the next deploy fails.
