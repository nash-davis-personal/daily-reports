No new advisory for Next.js, React, Tailwind or Supabase

Breach Nov 25–26

An attacker used one 1Password employee's GitHub account to push code that downloaded customer records

1Password began investigating on Nov 19. The attacker used the compromised account to reach private repositories, reach the CI/CD system, and inject code into backend services that pulled customer records: names, email addresses, account identifiers and some Secure Remote Password data. The company says vaults, vault keys, recovery keys, apps and browser extensions were not affected, and it found no sign of account takeovers. It disabled the account, rotated build-system credentials, and lengthened email verification codes from six digits to ten alphanumeric characters. It has not said how the GitHub account was taken over or how many customers were affected.

So what for TSD: One GitHub login reached production at a security company. Check TSD's own GitHub today: hardware-key or passkey 2FA, no stale personal access tokens, and Vercel and Supabase deploy keys scoped to one repo each. Expect 1Password-themed phishing to reach clients; a one-line heads-up email is cheap goodwill.

◆ Web platform

Beta Nov 25

Cloudflare launches Search for Agents on every plan, Free included

Site owners turn it on with a dashboard toggle. Cloudflare indexes the site with its AI Search product and serves a search endpoint at /.well-known/search on the site's own domain, advertised to agents through meta tags. Agents send keyword or natural-language queries and get back retrieved Markdown, and the agent's own model does the reasoning. Bot management and AI Crawl Control rules still apply. Billing follows AI Search pricing from Dec 1, and the site owner pays; reported free allowances differ between outlets (1,000 queries a month appears in both).

So what for TSD: For any client site behind Cloudflare, this is a five-minute setup that makes the site answerable by ChatGPT, Claude and other agents. Check each client's DNS this week, switch it on for one as a test, and set a spend alert before Dec 1.

◆ Hardware, space and health tech

Supply Nov 26

The memory chip shortage is now raising holiday device prices

The Wall Street Journal reports companies have set up procurement "war rooms" and that some memory prices rose about tenfold in a year. Independent data is less extreme but still steep: one tracked 16Gb DDR5 contract price went from $8.70 to $48 in 11 months. Apple raised MacBook prices $100 to $500 and the iPhone 18 Pro by $100, and some phone makers are cutting storage. Data centers are on track to take about 70% of this year's memory output, and supply relief is expected around 2028.

So what for TSD: Client hardware refreshes will get pushed back. Web and cloud tools that run on what a client already owns get easier to sell than anything needing a new device.

Space Nov 25

FCC conditionally lets SpaceX launch up to one million AI computing satellites

The partial grant for SpaceX's orbital data-center constellation sets milestones from a first satellite by November 2033 to the full system by 2040. The report is secondhand; the FCC docket holds the conditions.

So what for TSD: Nothing for years. It does show how far the compute buildout is reaching for power and space.

Health Nov 25

FDA clears Neuralink's first US pivotal brain-implant trial

The trial, called LINK, enrolls adults with ALS and follows them for up to 24 months. A pivotal trial is the stage that can support a marketing application.

So what for TSD: No business angle. It is the furthest any brain-computer interface company has reached in US regulation.
