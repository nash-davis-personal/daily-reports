◆ Security — patch and audit

Breaking June 17, 2026

Entire Mastra npm scope backdoored in an 88-minute campaign

An attacker hijacked a forgotten @mastra contributor account whose publish access was never revoked, then republished 142 packages under the scope — including @mastra/core (~918K weekly downloads) — each with a single injected dependency: easy-day-js, a typosquat of dayjs. A clean version was published first to build trust, then weaponized as v1.11.22 minutes before the mass-publish; semver ranges (^1.11.21) pulled the malicious build automatically. The payload disabled TLS verification, beaconed to attacker C2, fetched a second-stage RAT, and self-deleted. Snyk and Orca link the tradecraft to the North Korean group Sapphire Sleet (BlueNoroff).

So what for TSD: Direct action item. If any TSD project touches the Mastra AI framework, treat installs from the June 17 window as compromised: pin to known-good versions, delete node_modules and lockfiles, reinstall clean, rotate any credentials that lived on a dev machine that ran npm install in that window, and grep for easy-day-js. Broader lesson: pin exact versions and turn off install scripts (npm config set ignore-scripts true) for agent-built repos.

Fix June 2026

Microsoft Defender zero-day and Oracle's quarterly patch

Microsoft disclosed it's patching a Defender zero-day codenamed RoguePlanet (CVE-2026-50656, CVSS 7.8). Separately, Oracle shipped its June 2026 Critical Patch Update fixing flaws across Communications, E-Business Suite, Enterprise Manager and more.

So what for TSD: Low direct exposure (no Oracle stack, Defender auto-updates), but if Nash or a client runs Windows endpoints, make sure Defender definitions are current.

◆ The build economy

New June 4, 2026

Supabase raises $500M at a $10.5B valuation

Supabase closed a $500M Series F led by GIC (with Accel, Y Combinator, Coatue, Stripe and Salesforce Ventures), roughly doubling its valuation to $10.5B in eight months. The tell is in the metrics: databases are up 600% year-over-year, Claude Code is the single largest source of new projects this year, and AI agents now deploy the majority of new databases on the platform.

So what for TSD: Supabase is the backbone of nearly every TSD app, so its momentum and funding runway are good news for stability. More to the point: "agents deploy most new databases" is the exact wave Nash is already riding. The platform he's standardized on is now the default substrate for AI-built software — that's a selling point, not just plumbing.

Feature June 1, 2026

Nvidia jumps into the PC with the RTX Spark "N1X" superchip

At Computex, Nvidia unveiled the RTX Spark (N1X) — an Arm-based PC superchip with up to 20 CPU cores and a 6,144-core Blackwell GPU sharing memory, built on TSMC's 3nm process. It ships this fall in Windows laptops from Dell, HP, Asus, Lenovo, MSI and Microsoft, and pushes Nvidia squarely into Intel/AMD/Qualcomm/Apple territory; AMD, Intel and Qualcomm shares fell on the news.

So what for TSD: Nothing to buy now, but local on-device AI is coming to mainstream laptops. Worth tracking for a future "runs offline / on your own machine" angle if a privacy-sensitive client ever asks.
