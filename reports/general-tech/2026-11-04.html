◆ Patch and plan

Advisory Nov 3, 2026

Node.js will ship security releases for 22.x, 24.x and 26.x on or about Nov 11; highest severity is HIGH

The Node.js project posted its standard advance notice: security releases for the 26.x, 24.x and 22.x lines on or shortly after Wednesday, Nov 11, with the highest-severity issue in each line rated HIGH. No vulnerability count and no CVE IDs are published yet, which is normal for a pre-alert. End-of-life lines are also affected and will not be patched. Current releases are v26.13.0 (Latest LTS, Oct 28), v24.22.2 (LTS, Oct 28) and the v27.0.0 alpha.

So what for TSD: Patch instruction: on Nov 11, bump the Node version in every project's engines field and .nvmrc, redeploy on Vercel so builds pick up the patched runtime, and update local Node with nvm or Homebrew. Vercel's build image follows the LTS lines, so a redeploy is the client-site fix. Add it to the site-care checklist alongside the Next.js patch from yesterday.

Exploited Nov 3, 2026

CISA adds the WordPress core update-process RCE (CVE-2026-119977) to its Known Exploited Vulnerabilities catalog

CISA's Nov 3 alert adds one CVE: CVE-2026-119977, a time-of-check to time-of-use race condition in WordPress core's update process, exploitable without authentication with high attack complexity. It was fixed in WordPress 7.1.4 on Oct 28; Wordfence scored it CVSS 8.1 and The Hacker News reported nearly 63,000 attack attempts in 24 hours shortly after disclosure. A KEV listing means exploitation in the wild is confirmed and federal agencies must patch on a deadline. Reporting on the affected range varies (one source says 4.7 through 7.1.3), so treat anything below 7.1.4 as exposed.

So what for TSD: Two moves. First, any client or prospect site still on WordPress needs to be on 7.1.4 today; check with a single request to /readme.html or the admin dashboard. Second, this is the cleanest migration hook of the quarter: "your site's core updater is on the government's actively-exploited list" is a true sentence Grant and Bishop can say to every WordPress shop in Gastonia.

Follow-up Nov 2–3, 2026

Next.js: the seven Nov 3 advisories now carry GHSA IDs; 16.4.5 and 15.5.29 are the fixed versions

The releases page lists v16.4.5 and v15.5.29, both published Nov 3, with seven Moderate advisories: cross-tenant disclosure in 'use cache' via unstable_cache (GHSA-mfr8-8qww-v76h), cache leak across root param values (GHSA-vc7v-qv4w-wrv8), cache poisoning of shared fallback shells (GHSA-vvgp-ww4w-46vf), cross-user cache disclosure with binary args (GHSA-rhh4-g77r-r9qj), cross-client response injection in self-hosted apps that forward fetched responses (GHSA-pc58-hwjq-p385), an SVG rejection bypass in image optimization (GHSA-7qx7-33qx-rqx2), and HttpOnly cookie exposure via an internal header on Edge runtime routes (GHSA-f3mh-rxg3-f5g2). 15.5.29 backports only the last three. v16.4.4 on Nov 2 swapped jsonwebtoken for fast-jwt and fixed a Turbopack CSS hot-update bug. The 16.5 canaries pin Tailwind 4.3.3 in create-next-app. Nothing shipped for React, Tailwind or Vite in the window.

So what for TSD: Four of the seven are cache leaks across tenants or users, which matters for any app that caches per-client data (a multi-tenant Concierge, a client portal). Run npm ls next across every repo and confirm 16.4.5; any app still on 15 needs 15.5.29 and a note that it only gets three of the seven fixes.

◆ Platform moves on Nash's stack

Vercel Nov 2–3, 2026

Vercel ships Security Review (public beta, free until Nov 10), standalone Vercel CI, vercel doctor and vercel.toml

Security Review reviews source code for vulnerabilities on every GitHub push, including force pushes to production branches, and posts findings to a Vulnerabilities dashboard with project, branch, commit, suggested fix and an AI-generated severity. It adds a GitHub check per commit and PR review comments, and "Fix with Vercel Agent" opens a pull request that does not merge without approval. It is Pro and Enterprise only, billed at the Vercel Agent rate (provider inference at cost plus $0.25 per million tokens), free until Nov 10. Findings are also available via vercel security vulnerabilities in CLI 65.10.0 or later.

Also new: Vercel CI no longer needs a linked Vercel project (vercel ci enable from a clone; private GitHub repos only for now), vercel doctor diagnoses CLI version, login, team, project link and vercel.json, vercel.toml is now an accepted config format, Vercel MCP accepts OAuth Client ID Metadata Documents, and Tencent Hy4 is on AI Gateway at half price.

So what for TSD: If the TSD team is on Pro, turn Security Review on in the team's Agent settings this week and let it run on every client repo for free through Nov 10; the findings become the first "security review" line item in a Managed AI retainer. Run vercel doctor once on the laptop; the Bisque deploy-identity saga would have been a two-minute fix with it.

Cloudflare Nov 3, 2026

Cloudflare: new AI Gateways require authentication, Agents SDK 0.33 is a one-way upgrade, and a new Zero Wire vulnerability hub

New AI Gateways created through the API now have authentication on by default; passing authentication: false returns HTTP 400, and once enabled the setting cannot be turned off from the dashboard or API. Existing unauthenticated gateways keep working, but requests need a valid Cloudflare API token once authentication is on (Workers bindings stay pre-authenticated). Agents SDK v0.33.0 upgrades to Pi 1.5, with session.watch() replacing session.events(); Pi 1.4 cannot read Pi 1.5 conversations, so there is no rollback. Radar launched Zero Wire, a hub of plain-language briefings on critical Internet vulnerabilities with "Needs attention" grouping, remediation steps and RSS feeds. WAF rules were updated for three PHP out-of-memory CVEs.

Elsewhere in active exploitation: a CVSS 10 Node-RED flaw (CVE-2026-58115, missing authentication on the HTTP interface) is being used to drop Linux bots and webshells on instances without adminAuth, and Barracuda warned of two critical flaws that chain to root across its ESG, load balancer, WAF and archiver appliances.

So what for TSD: If any TSD project proxies LLM calls through a Cloudflare AI Gateway, new gateways need a token in the client. Subscribe to Zero Wire's RSS feed; it is a free version of the CVE check this brief does every morning. Any client or home box running Node-RED without adminAuth is a one-request takeover.

Earnings Nov 3, 2026

AMD, Super Micro and Arista all beat and raise, and Super Micro's 12.7% margin is the number to remember

AMD: record revenue of $13.4B, up 45% year over year; data center $8.5B, up 97% on EPYC and the MI450 launch; non-GAAP EPS $2.09 against about $1.95 expected; Q4 guidance about $17B, plus or minus 3%, against a $16.2B consensus. AMD says Anthropic, Meta, Microsoft, OpenAI and Oracle Cloud are running workloads on the first Helios rack systems. Shares rose about 7% to 8% after hours. Super Micro: fiscal Q1 net sales $19.9B, about four times a year ago, with a GAAP gross margin of 12.7%, down from 17.5% last quarter; operating cash flow was negative $434M against $8.6B of debt and convertibles; the full-year guide is $72B to $82B. Arista: revenue $3.66B, up 58.5%, the fastest growth since its IPO; non-GAAP EPS $1.20 against a $1.06 to $1.08 guide; Q4 guide $3.9B to $4.0B.

So what for TSD: Supply keeps expanding on every layer (GPUs, servers, switches), which is the long-run pressure that keeps token prices falling for the products TSD sells. Super Micro's thin margin and cash burn are the honest counterpoint when a client asks whether the AI buildout is a bubble: demand is real, and the middlemen are not all making money on it.
