No fresh CVE hit the Next.js/Vercel/React/Supabase stack in the last 48 hours. Housekeeping — the kind that breaks a build at the worst moment if you upgrade blind.

◆ The defaults moved — read before you upgrade

Breaking Jul 8–9, 2026

npm v12 disables install scripts by default

GitHub shipped npm v12 with preinstall, install and postinstall lifecycle scripts, implicit node-gyp native builds, and git/remote-URL dependencies all disabled by default. They no longer run on npm install unless you explicitly allow them. It is a direct response to 2025's roughly 455,000 malicious npm packages, most of which weaponized exactly those install hooks.

The upside is real supply-chain safety. The trap is that plenty of legitimate packages — native modules, Prisma, sharp, some Supabase tooling — depend on those scripts to build. Upgrade a project to v12 without allow-listing them and the build can fail, or worse, appear to succeed while skipping a native compile.

So what for TSD: Do this proactively on one project before it bites a Vercel deploy. Upgrade a low-stakes repo to npm v12 first, run npm approve-scripts to review and allow the trusted build scripts, commit the updated manifest, and confirm the Vercel build still produces a working native compile. Only then roll it across client repos. Pin npm in CI until you've done that pass so a runner doesn't silently jump to v12 mid-week.

Breaking Jul 9, 2026

Supabase changes a self-hosted auth path — hardcoded endpoints break

As of July 9, the self-hosted Supabase default API_EXTERNAL_URL now includes an /auth/v1 path prefix, and SAML SSO routes moved from /sso/saml/* to /auth/v1/sso/saml/*. Separately, Postgres log_connections now defaults to off for new cloud projects. Managed-Supabase clients have nothing to do beyond knowing connection logging is quieter now; self-hosted setups are the ones exposed.

So what for TSD: If any client runs self-hosted Supabase auth, the /auth/v1 change will break reverse-proxy rules and hardcoded auth/SAML endpoints the moment you pull the new image. Audit those configs and env vars before upgrading. If everything you run is managed Supabase, this is a non-event — note it and move on.

◆ Security & hardware

Patch Jul 9, 2026

Three critical command-injection CVEs in Ubiquiti UniFi

Ubiquiti disclosed CVE-2026-50746 in UniFi Connect (CVSS 10.0), plus command-injection flaws in UniFi Talk and UniFi Access (both 9.9), all allowing network-adjacent command injection. Patches are available. It is the third Ubiquiti disclosure in three days — the vendor has posted 14 new critical CVEs since July 7.

So what for TSD: UniFi gear is everywhere in small offices. If you or any client you've done work for runs a UniFi controller, patch it now and get the management UI off the public internet. This is worth a one-line heads-up to any client whose network you've touched — small effort, real goodwill, and it's the kind of thing that keeps you the person they call.
Threat-Modeling.com — Vuln Intelligence, Jul 9
New Jul 10, 2026

Broadcom and OpenAI unveil a custom inference chip

Broadcom and OpenAI unveiled "Jalapeño," a custom inference chip, continuing the top of the market's push to design its own silicon and lean less on Nvidia. It lands against a jittery week for chip stocks — Micron fell roughly 13% in a session on doubts about whether AI capex pays off — even as SK Hynix pulled off a record $26.5B Nasdaq IPO and committed billions to ASML EUV tools.

So what for TSD: No direct build impact, but the "AI capex may not pay off" narrative going mainstream is useful framing. When an SMB client asks whether AI spend is a bubble, you can point to the fact that the hyperscalers are still committing to custom silicon and record fabs — the infra bet isn't slowing, which is different from any single stock's week.
