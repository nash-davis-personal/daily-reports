◆ Your stack

Security Checked Nov 28

No new advisory for Next.js, React, Tailwind or Supabase

Searches of the Next.js blog, Vercel bulletins and Supabase changelog found nothing new after the Nov 3 Next.js security release. That release fixed seven issues, including cache leaks and poisoning in use cache and an HttpOnly cookie exposure on Edge routes, in 16.4.5 and 15.5.29. A later 16.4.6 compresses route handler responses and fixes a Turbopack dev memory issue. Vercel's bulletin page also lists Better Auth fixes for 12 advisories in 1.7.16 and 1.8.0-beta.5.

So what for TSD: Run npm ls next better-auth on every client repo today. Anything below Next 16.4.5 (or 15.5.29) or Better Auth 1.7.16 gets bumped and pushed before Cyber Monday traffic.

◆ Chips and security

Supply Reported Nov 26

Nvidia tells partners to stop shipping servers to Malaysia, Singapore, Thailand and Indonesia

The Financial Times reported, and TechCrunch, Forbes and Reuters followed, that Nvidia told manufacturing partners including Dell and Super Micro to halt shipments of servers carrying its chips to the four countries. The pause has no stated end. It follows a US Commerce Department rule that requires licenses for advanced chips and servers going to those countries and closes a gap that let Chinese companies rent Nvidia computing from data centers there. Reuters linked the move to scrutiny of Megaspeed, a Singapore-based partner.

So what for TSD: Nothing you rent sits in those regions. The thing to watch is GPU prices: less capacity in Asia can push up cloud GPU and inference prices in the US. Quote AI retainers with a pass-through clause for model costs.

Patch Nov 2026

GnuPG warns of a critical GPGME double free reachable through a malicious OpenPGP key

GnuPG disclosed and patched a double free in GPGME's read_status() and read_colon_line() functions. A crafted OpenPGP key could crash an app or expose its data. GPGME is the library that mail clients, package tools and some backend services use to call GnuPG.

So what for TSD: Probably none of your Vercel projects use it. Run updates on any self-hosted box or Mac mini that runs mail, backups or signing scripts.
The Hacker News

◆ Cool builds

Dev tools Nov 25

tabc runs Docker containers in a browser tab with no Linux VM

Farid Zakaria published tabc, which runs container images inside Chromium tabs using a Linux kernel compiled to WebAssembly. It is an experiment and not production tooling, but it shows that real Linux workloads can run on the client.

So what for TSD: Worth watching for demos. A prospect could click a link and run a working copy of their new back office in a tab without any server cost. File it for later.
