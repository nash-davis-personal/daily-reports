◆ Security first

Exploited Oct 2026

Cisco patches an exploited Secure Email Gateway zero-day

Cisco fixed CVE-2026-76519, a path-traversal flaw in the Advanced Malware Protection feature of Secure Email Gateway. An attacker with no login sends an email with a crafted attachment through the gateway and can write files to the appliance and then run commands as root. It affects gateways with File Reputation enabled and assigned to a mail policy and Content Scanner Tools older than 25.3.0.5525. Cisco's PSIRT confirmed exploitation this month and hasn't shared attack details. A separate SEG SQL-injection bug, CVE-2026-76461, was exploited in September.

So what for TSD: Most SMB clients don't run Cisco mail appliances, but a medical group or credit union might. If you manage IT-adjacent work for anyone with one, send them the advisory today. It's also a clean, real example for the security checkup pitch.

Breach Notified Oct 13

Meta: one stolen credential, internal GitHub repos copied

Meta is notifying about 1,500 people, mostly US employees, after an outside group used one employee's stolen credentials to reach some internal GitHub repositories and copy product code plus a small amount of personal data. Meta says about 99% of what was taken was business data, much of the personal-looking data was synthetic test data, and no Meta product was vulnerable. It rotated exposed secrets and added scanning for personal data committed by mistake.

So what for TSD: Same failure mode applies to a one-person studio: your GitHub account holds every client repo. Check that hardware-key 2FA is on, audit personal access tokens and deploy keys, and make sure no client .env or test data with real names ever landed in a repo.

Next.js v16.4.2 · Oct 15

Next.js 16.4.2 is a stability release; the Oct 21 deadline is what matters

16.4.2 backports Turbopack fixes (snapshot consistency, dependency-graph garbage collection, lazy dynamic-import chunk collisions, realpath handling) and docs. No new advisory shipped with it. The two critical advisories from Oct 14 (RCE in the Image Optimization API with SVGs, and RCE in use cache functions returning typed arrays) are fixed in 16.4.1 and 15.5.28. Security support for 15.x ends October 21. On the React side, 19.0.9, 19.1.10 and 19.2.9 shipped Oct 14 alongside those fixes.

So what for TSD: Bump anything on 16.4.1 to 16.4.2 at your next deploy; there's no rush. The real job is the 15.x client list: anything still there after Wednesday stops getting security fixes.

◆ Your stack: Vercel and Supabase

Vercel Oct 15

Vercel Daemons (beta) and Vercel Drives (GA)

Vercel Daemons runs long-lived processes with no HTTP server: queue consumers, workflow workers, Celery or BullMQ workers, self-hosted CI runners. Each one is a container on Fluid compute built from your Dockerfile, deployed with the app, with a set instance count per region and automatic restarts. Pricing wasn't in the announcement. Vercel Drives, now GA, is persistent storage you mount into a Vercel Sandbox; files outlive the sandbox and a Drive can be forked for parallel workers. Also on Oct 15: Bring Your Own Cloud on AWS went GA, and Vercel Connect can now reach IP-restricted providers through Secure Compute static IPs.

So what for TSD: Daemons removes the main reason to run a side server next to a Vercel app. The booking-automation and call-processing jobs that now sit on cron hacks or a separate box could live in the same project. Check pricing in the docs before moving anything client-billed.

Vercel Oct 15

Token Pass: $80 of open-model credit for $30 a month

Vercel's early-access Token Pass gives Pro teams $80 a month of AI Gateway credit for $30, starting with GLM 5.3 and Kimi K3. Zero data retention is on by default with US and EU inference. Unused credit expires monthly, and requests stop when the credit runs out, with no overage charges. The AI Gateway also added Meta's Muse Spark Open, Liquid AI's d1-ultra and a free stealth model called Cat Jam.

So what for TSD: A hard-capped, discounted bucket is a good fit for bulk background work (summaries, tagging, content drafts) where an open model is good enough. The no-overage rule also makes it safe to hand a client's experimental agent a fixed monthly budget.

Supabase Oct 12–15

supabase-js 2.118 and a TLS cipher cutoff on Nov 10

supabase-js 2.118.0 (Oct 15) leaves computed fields out of select('*'), resolves no-argument RPC overloads for typegen output, and adds content-encoding on Storage uploads. Supabase will disable an outdated set of TLS 1.2 CBC ciphers on project HTTP APIs on November 10; it says under 0.0001% of traffic uses them.

So what for TSD: The select('*') change can quietly drop a computed column a page relies on. Read the diff before bumping on any client app that uses computed fields. The cipher change only hits very old clients, like a legacy device or kiosk calling the API.
