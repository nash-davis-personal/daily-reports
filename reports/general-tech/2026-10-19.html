◆ Patch status

Security Oct 14 release

Next.js out-of-band security update: two critical RCEs and one high DoS

Next.js 16.4.1 (Active LTS) and 15.5.28 (Maintenance LTS) fix three issues. GHSA-673q-mjm6-r5xr (critical): unauthenticated RCE for App Router apps using Cache Components when a use cache function returns multiple typed arrays; no known workaround. CVE-2026-96889 / GHSA-2464-fhr4-w9xw (critical): RCE in the Image Optimization API with SVGs through sharp on glibc-based Linux; workaround is sharp 0.35.5 or later. GHSA-p3m5-59mp-jv5r (high): crafted requests to an App Router app with at least one Server Action can pin the CPU and cause denial of service; Pages Router and apps without Server Actions are not affected.

Netlify and Pantheon both tell customers to upgrade and redeploy. React also published matching advisories (patched lines include 19.0.9, 19.1.10, 19.2.9 and 19.3.1 per Pantheon). I found no newer advisory since Oct 14. Next.js 15.x leaves Maintenance LTS on Wednesday, Oct 21, per the Oct 18 edition.

So what for TSD: Patch instruction: in every client repo run npm ls next sharp react. Move 16.x to next@16.4.1 and 15.x to next@15.5.28 (or plan the jump to 16 before Wednesday), then redeploy. A lockfile bump with no redeploy leaves the live site vulnerable.

Supabase Check dates

Supabase: legacy API keys and a new Postgres pipelines alpha

A Supabase-focused security guide quoting the docs says the legacy anon and service_role keys keep working until the end of 2026 and recommends switching to sb_publishable_ and sb_secret_ keys now. A third-party copy of the October Supabase update also lists pipelines that stream Postgres data to BigQuery, ClickHouse, DuckLake and Snowflake in public alpha, and agent-driven backend setup through an MCP server. Both come from secondary pages; confirm on Supabase's own docs.

So what for TSD: Put "rotate to the new Supabase key format" on the client maintenance checklist for November; it is a small job to sell as part of a retainer. The pipelines alpha is irrelevant to current SMB projects.

◆ Hardware and infrastructure

Hardware Oct 19

NVIDIA RTX Spark PCs go on sale from six makers

NVIDIA announced global availability of RTX Spark systems from ASUS, Dell, HP, Lenovo, Microsoft and MSI, starting at $2,599. The chip pairs a Blackwell RTX GPU with a Grace CPU, up to 128GB unified memory and up to one petaflop of FP4 AI performance. NVIDIA says agents and coding tools including GitHub Copilot can run on the device with data kept local. The source gives no token-speed or supported-model figures, so the real-world benefit is unproven.

So what for TSD: A $2,599 box with 128GB is the first sensible hardware quote for a client who wants private document search without a cloud vendor. Wait for independent benchmarks before pricing anything around it.

Finance Oct 14–15

CoreWeave's bonds trade like distressed debt

CoreWeave shares fell about 15.5% to $65.78 on Oct 14 and another 8.3% to about $60.36 on Oct 15, the lowest since May 2025. Its 9.625% notes due 2032 yielded about 14.8% and traded below 80 cents on the dollar, and credit-default-swap spreads went above 1,000 basis points. Reported debt is roughly $50–52B. CEO Mike Intrator called the selloff irrational and pointed to a contracted backlog above $104B. Figures come from aggregator reports; check filings before relying on exact numbers.

So what for TSD: Nothing to do today. If GPU-cloud capacity gets repriced or a neocloud struggles, hosted inference could get cheaper or less reliable. Keep model providers swappable behind the Vercel AI Gateway.
