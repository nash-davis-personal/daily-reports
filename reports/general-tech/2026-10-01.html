◆ Your stack

Patch Sept 30

Next.js shipped its September security release: 16.3.8 and 15.5.27

The fixes postponed last week over an upstream dependency are now available. The headline bug is a high-severity server-side request forgery in Image Optimization (CVE-2026-94483): an attacker who controls an allow-listed remote URL can make your server fetch internal addresses. Apps with no images.remotePatterns configured are not affected.

Five medium-severity issues ride along. Two are cache-poisoning bugs in SSG and ISR pages, one of which only hits self-hosted Pages Router apps and does not affect Vercel deployments. One lets metadata image routes ignore dynamicParams in webpack builds. Two involve 'use cache': a cache-key bug with root params, and Draft Mode content leaking into regular responses when Cache Components is on. A low-severity bug lets a malicious website read project paths, source snippets and logs from the MCP endpoint that next dev exposes on your machine.

So what for TSD: Run npm install next@16.3.8 (or next@15.5.27) in every TSD and client repo today and redeploy. Prioritize any site with images.remotePatterns set, any site using Draft Mode with Cache Components, and your own laptop, since the dev-server leak applies whenever you run next dev and browse the web.

Platform Sept 30

Vercel stopped caching responses that vary on Cookie, and renamed Edge Requests

Vercel's CDN no longer caches a response whose Vary header includes Cookie. The response is still served; it just won't be stored. "Edge Requests" are now called "CDN Requests" with no change to pricing, limits or metering. Vercel Agent can also install private npm packages using a team NPM_TOKEN, and Sandboxes can connect to Secure Compute networks. These come from a changelog aggregator; the entries on vercel.com were not opened individually.

So what for TSD: If any client route sets Vary: Cookie and you were counting on it being cached, it now hits the function every time. Check cache-hit rates on your busiest pages this week and watch function usage on the next invoice.

Release Sept 30

Supabase released Middleware 1.0

It is a type-safe engine for per-request logic: you write units with defineMiddleware and chain them with pipeline(). CORS and feature-flag middleware ship built in, along with stable server middleware for Supabase auth, client helpers and OAuth discovery. It runs anywhere fetch runs, including Supabase Edge Functions, Vercel Functions, Cloudflare Workers, Deno, Bun and Node 22 or newer, and plugs into Hono, H3, Elysia, NestJS and TanStack Start. It is on npm and JSR and follows semver from here. Details are from a changelog aggregator.

So what for TSD: Useful for Edge Functions and standalone API workers where you hand-roll auth checks today. It does not replace the proxy.ts pattern in your Next 16 apps, so leave those alone.

◆ Security

Breach Sept 29–30

An autonomous AI agent breached a security nonprofit by chaining two Zammad zero-days

The Dutch Institute for Vulnerability Disclosure says an attacker used two previously unknown flaws in the open-source Zammad ticketing system (CVE-2026-102489 and CVE-2026-102490) to hijack sessions, run code and escalate to root "in seconds." An AI agent then ran the rest of the intrusion on its own, choosing each next step itself. DIVD called it "loud and very, very messy": the agent even disrupted its own interception attack by password-spraying. Data was taken before network segmentation stopped it from moving further. The agent left written explanations of its decisions, which let DIVD reconstruct the attack. Zammad 7 is the safe version.

So what for TSD: Sloppy attackers moving at machine speed still get in when an internet-facing tool is unpatched. For every client, list the self-hosted or third-party tools exposed to the internet (ticketing, booking, forms, admin panels) and confirm who patches each one. If a client runs Zammad, upgrade it to 7 or take it offline.

Incident Oct 1

MetaMask disclosed a security incident in its staking infrastructure

MetaMask says part of its infrastructure is affected and that it is exiting the affected Ethereum validators in its non-custodial staking operation, including validators in the Lido protocol, with the last exits expected by the end of Oct. 7. It says it has found no immediate threat to users' wallets. It has not said what happened, how the attackers got in, or whether internal data was accessed. The investigation is ongoing.

So what for TSD: No action for client work. If you or a client hold assets through MetaMask staking, read the official notice and expect delays while validators exit.

◆ Chips, hardware & space

Earnings Sept 30

Micron reported a $54.23B quarter and guided to $61.5B

Fiscal fourth-quarter revenue was $54.23 billion against $11.32 billion a year earlier, ahead of the $51.49 billion analysts expected. Full-year revenue reached $133.19 billion, up from $37.38 billion. Adjusted earnings were $33.42 a share. Micron guided the current quarter to about $61.5 billion. CNBC reports data-center revenue rose roughly eleven-fold. Memory is the part of an AI server that every model vendor needs more of, and Micron says supply is tight.

So what for TSD: Tight memory supply is one reason model prices may stop falling as fast as they have. Don't promise clients that AI running costs will keep dropping. Price retainers on today's token costs and treat any future drop as margin.

Hardware Sept 30

Apple is reported to unveil a smart-home hub on Oct. 13

Bloomberg's Mark Gurman reports Apple plans to show a home hub with a 6-inch display on Oct. 13, alongside a new HomePod mini and Apple TV 4K. The hub mounts on a wall or sits on a stand, recognizes who is using it by voice or face, and runs on the Siri AI platform that entered beta in September. So what for TSD: Nothing to build yet. If it ships, a voice-first screen in the kitchen becomes another place people ask for a plumber or a salon. Keep client business listings, hours and booking links accurate, because assistants answer from that data.
