◆ Security — do this first

Patch now Disclosed June 2026

"Agentjacking": a crafted Sentry error report can run code inside your AI coding agent

Tenet Security disclosed an attack that exploits the gap between Sentry's open event ingestion — anyone with the project DSN can post a payload — and the Sentry MCP server, which hands those events to AI agents as trusted system output. A malicious error event gets read by Claude Code or Cursor as a legitimate diagnostic step and executes attacker-controlled code, exposing environment variables, Git credentials, private repo URLs, and developer identity, with no phishing or prior compromise. Researchers found 2,388 orgs with injectable DSNs and achieved an 85% success rate in testing, including a Fortune 100 company's agent. Sentry acknowledged the issue June 3 but declined a root fix.

So what for TSD: You use Claude Code every day, so this is your problem too. Action this week: (1) inventory which MCP servers your agents can read from; (2) treat any that ingest external data — error trackers, ticketing, email, scraped web — as untrusted prompt-injection surfaces; (3) if any TSD or client project exposes a public Sentry DSN, rotate it and lock ingestion; (4) keep a human gate on any agent step sourced from third-party event data.

Next.js coordinated security release: be on 15.5.18 or 16.2.6, not an older minor

The Next.js and React teams disclosed 13 advisories — denial of service, middleware/proxy bypass, SSRF, cache poisoning, and XSS — patched only in 15.5.18 and 16.2.6. Earlier 15.x and 16.x minors will not be patched, so affected projects must upgrade to a patched minor rather than waiting for a backport. Named CVEs include SSRF via crafted WebSocket upgrade requests (CVE-2026-44578) and a Pages Router i18n issue (CVE-2026-44573).

So what for TSD: Run a quick sweep across the fleet — every Next.js app (tsd-modernization-app, the client sites, the demo repos) should report 15.5.18+ or 16.2.6+. Vercel auto-deploys mean the fix ships the moment you bump and push. If any repo is pinned to an older minor, that's a same-day upgrade, not a maybe.

◆ Your stack: Supabase key migration

Heads-up Through 2026

Supabase legacy API keys deprecate by end of 2026 — move to publishable/secret keys

Supabase is retiring its legacy anon/service_role API keys by the end of 2026 in favor of the new sb_publishable_… and sb_secret_… format. It's not an emergency, but every TSD project on Supabase will eventually need the swap, and doing it deliberately beats a scramble in December.

So what for TSD: Add "rotate to new Supabase key format" to the maintenance backlog for every Supabase-backed app (the portal, Cohors, GrantWell, the RAG demos, the renters funnel). Batch it into the next time you're already touching each repo's env vars so it's free work, not a separate project.

◆ Hardware & the broader buildout

Chips June 2026

Intel 18A-P enters risk production; Samsung and SK Hynix sample HBM4E

Intel's 18A-P process node moved into risk production with reported interest from Apple and Google, a real sign of life for its foundry ambitions. In memory, Samsung and SK Hynix are accelerating their rivalry by shipping seventh-generation HBM4E samples — the memory that feeds AI accelerators. Analysts peg the AI-chip market near $500B in 2026 inside a roughly $975B total semiconductor year.

So what for TSD: No direct action — this is the supply side of why inference keeps getting cheaper and why "power, not chips" is the new bottleneck. The practical read for a builder: keep assuming token costs trend down over the next year, which makes always-on AI features (concierge, receptionist) cheaper to run and easier to price as retainers.
