◆ AI agents keep leaking through their own trust

Security September 24

"SalesBleed": three Agentforce flaws let a fake lead hijack a trusted agent

Zenity Labs disclosed three vulnerabilities in Salesforce Agentforce exploitable through Web-to-Lead, Salesforce's public lead-capture forms. An attacker plants hidden instructions in a submitted lead; the payload sits dormant until an employee asks an Agentforce agent to process that lead, at which point the agent silently exfiltrates CRM data or impersonates a trusted Slack-connected agent to phish coworkers — no click required. Zenity reported it to Salesforce on June 1; Salesforce shipped fixes for all three by August 19, and says it found no evidence of exploitation before the patch.

So what for TSD: Front Desk and Concierge are built to accept text from strangers by design. Audit every action your agents can take off unverified input (send email, update a record, follow a link) and make sure nothing a customer types can silently trigger a privileged action.

Privacy September 22

Z.ai open-sourced ZCode after it silently uploaded users' full repos

An independent developer traced abnormal disk activity in Z.ai's ZCode coding assistant to a background process that packaged an entire workspace — full .git history, LFS cache, reflogs and global configs — encrypted it, and uploaded it to Alibaba Cloud storage whenever a user was logged in. One company said the uploads included database passwords and employee data (a claim it later retracted). Z.ai apologized, blamed a repository-indexing feature, disabled the upload mechanism, deleted the cloud storage, and open-sourced the client.

So what for TSD: Before recommending or embedding any third-party coding agent for a client, check what it phones home with. A background upload of a repo containing a client's .env secrets is a trust-ending mistake TSD can't afford to make once.

Update Vercel Weekly, Sept 21

Vercel's AI Gateway added Claude Fable 5.1 and per-user spend budgets

The AI Gateway now offers Claude Fable 5.1 behind one API key with automatic fallbacks, spend tracking and request traces, and adds user-scoped budgets alongside existing team, project and key limits. Separately, Secure Compute and Static IP builds now start 64% faster (6.7s down to 2.4s), and open-weight models handled the majority of Gateway tokens for the first time in August as average price-per-token fell 23.2%.

So what for TSD: If you're billing usage-based AI features to SMB clients, turn on per-client spend caps in the Gateway now — it's a one-line change that prevents a runaway agent loop from becoming your problem.
