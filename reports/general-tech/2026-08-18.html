◆ The day the pipeline stopped

Outage Aug 17, 2026

GitHub degraded worldwide for about eight hours

Impairment started around 13:40 UTC. Within the hour GitHub confirmed degraded API requests, Actions and webhooks; issues and pull requests followed, and Copilot joined around 14:31 UTC. General web and API traffic ran roughly 20 percent errors, while archive downloads and raw repository content failed at about 50 percent. SAML and OIDC authentication, SCIM and Team Sync were also hit, which is the part that locks people out rather than merely slowing them down.

GitHub identified the component at 16:36 UTC and had the API back to normal by 19:01 UTC, though recovery was not linear: git operations degraded again afterward, the API briefly regressed, and Copilot authentication problems outlasted everything else. A root cause has not been published.

So what for TSD: Your deploys ride GitHub. When Actions is at 50 percent error rate you cannot ship a client hotfix, which is a problem specifically on the day a client site is broken. Two cheap mitigations: keep the Vercel CLI path working and rehearsed as the emergency deploy route that does not touch GitHub, and stop treating a green CI run as the only gate you have. Add a one-line local verification you can run when Actions is unavailable. Neither takes an afternoon and both pay for themselves the first time this recurs.
InfoWorld · BleepingComputer · XenoSpectrum
New Aug 17–18, 2026

Cursor opened the Origin beta, and Vercel already deploys from it

Cursor put Origin into beta for paid users: code hosting built into the editor and pitched at "agent scale" rather than as a GitHub clone. It handles the codebase view, pull request review and merges, and integrates CI and deployment providers including Vercel, Buildkite and Depot. Existing GitHub repositories sync in, so trying it does not require abandoning anything.

Vercel's own changelog lists the other half: deploying Cursor Origin repositories is in public beta for Pro and Enterprise, with a preview deployment spun up for every pull request and a production ship on merge. The launch landing on the day GitHub spent eight hours degraded was either very good timing or very good instincts.

So what for TSD: Worth an experiment on one throwaway repo, and worth nothing more than that for now. The interesting property is that your agents would be reviewing and merging in the same surface where they write, which removes a handoff you currently pay for in context. The disqualifying property is that a beta code host from a startup is not where client source code lives, especially when your closing differentiator is that the client owns the source day one. Sync a personal project, see whether the Vercel preview flow is actually faster, and keep client work on GitHub until Origin has a year behind it.

◆ Your stack

Pricing Aug 13–17, 2026

Vercel cut AI Gateway pricing on two frontier models and turned on Encrypted Client Hello

GPT-5.6 Sol is 50 percent off on the Vercel AI Gateway from August 17 through September 18. Gemini 3.7 Flash landed on the Gateway at half price on August 13, and GLM 5.2 is free for eve agents through August 27 via Blackbox. Separately, Encrypted Client Hello is now supported across the Vercel CDN as of August 14, and there is a one-click upgrade path for deployments still pinned to deprecated Node.js versions.

On security, nothing new has landed for Next.js, React or Vercel this month. The July 2026 release is still the line: 16.2.11 on Active LTS and 15.5.21 on Maintenance LTS, covering nine SSRF, bypass and denial-of-service CVEs. Applications on 13, 14 or earlier 15.x branches never got equivalent fixes.

So what for TSD: Two concrete jobs. Run the one-click Node upgrade on any client project still on a deprecated runtime before Vercel forces it during an unrelated deploy. Then take the 30-day GPT-5.6 Sol discount as a free evaluation window: route a non-critical path in TSD Concierge through it via the Gateway, measure answer quality and latency against your current model, and you will know by mid-September whether it belongs in the stack at full price. Also confirm every client repo is on 16.2.11 or 15.5.21, since the July advisory is a month old and an unpatched SSRF is not less dangerous for being quiet.

◆ Hardware, money and breaches

IPO Aug 18, 2026

Unitree priced its Shanghai IPO at about 61 billion yuan and lists tomorrow

Unitree Robotics priced at 150.8 yuan per share, roughly $22.40, valuing the company near 61 billion yuan. It sold about 40.44 million shares, 10 percent of enlarged capital, raising close to 6.1 billion yuan or roughly $904 million. Retail demand oversubscribed the offering more than 8,000 times. It debuts on the STAR Market on August 19 as the first onshore-listed humanoid robot company in mainland China.

Revenue grew at a 226.8 percent compound annual rate from 2023 to 2025 and net profit reached 278 million yuan in 2025, but profit fell 54.6 percent in the first quarter of 2026 on higher marketing and R&D spend. The debut is expected to set the valuation comp for 30 to 50 peers preparing Hong Kong listings.

So what for TSD: No delivery implication, and that is fine. The signal to take is the shape of the demand: retail money oversubscribing a hardware robotics offering 8,000 times is the same appetite that makes "we use AI" a selling phrase to your SMB clients right now. That window is worth using while it is open, and it is worth remembering that a Q1 profit decline on marketing spend is what the bill for that enthusiasm looks like.
