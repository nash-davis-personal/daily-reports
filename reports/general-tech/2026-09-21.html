Security Disclosed September 17–18

Plugin4Shell: zero-click RCE in Claude Code, Codex, Copilot and Gemini CLI

AIR Security disclosed a high-severity flaw in how the four most popular coding agents install plugins. Marketplaces pin a plugin to a reviewed commit SHA; the agent checks out that SHA but never verifies the checkout actually resolved to it. An attacker who controls the plugin's repository can make the resolution land on malicious code while the pin still appears honored. Because Claude Code and Codex update installed plugins in the background by default, no click, approval or reinstall is required — hence zero-click.

The blast radius is the developer's own machine. Plugins inherit the permissions of whoever runs the agent: local source, cloud credentials, SSH keys, internal repos, production access, secrets. Anthropic fixed it in Claude Code 2.1.179 and OpenAI in Codex 0.146.0. Microsoft had no GitHub Copilot fix out at disclosure, and Google is reported to be leaving the deprecated Gemini CLI unpatched.

So what for TSD: Run claude --version on every machine today and make sure you are at or above 2.1.179 — the changelog has the line at 2.1.278, so a normal auto-updated install is fine, but a pinned CI image or an old laptop may not be. Then audit installed plugins and drop any whose repo you do not personally trust, because SHA pinning was the thing making third-party plugins safe and it did not work. If a client's dev team runs Copilot, tell them the flaw exists and that the fix was not shipped at disclosure.

◆ Nash's stack

Breaking change Effective September 23

Supabase removes the Management API logs.all endpoint

Supabase announced on July 23 that the Management API's logs.all endpoint would be removed on September 23, 2026, with callers migrating to the new ClickHouse-backed logs endpoint. That date is Wednesday. Anything still hitting the old path — a monitoring script, a client dashboard widget, a cron job that pulls error counts — starts failing rather than degrading.

In the same stretch Supabase added Health Check Advisors on September 18, which surfaces error rates across Auth, Storage, Edge Functions and the Data APIs with a severity level and a link straight to the investigation view. There is no new Next.js security advisory this window; the August release remains the floor at 16.3.3 on Active LTS or 15.5.24 on Maintenance LTS.

So what for TSD: Grep every project for logs.all before Wednesday — rg "logs\.all" ~/Documents/Projects takes ten seconds and a silent Thursday-morning breakage in a client's ops dashboard costs an afternoon. While you are in there, turn on Health Check Advisors for each client project; it is free monitoring you can put on a retainer report without writing any code.

Platform September 17–18

Vercel: private npm in v0, sub-second artifact deploys, GLM 5.3 FlashX on the Gateway

Four items from the Vercel changelog worth knowing. v0 can now read environment variables to install private npm packages, so an internal component library works inside v0 instead of being stripped out on every generation. Static artifacts deploy through the CLI in under a second. Turbo build machines can be enabled per deployment rather than per project, which turns a blanket cost into a targeted one. And Zhipu's GLM 5.3 FlashX is available through AI Gateway under the same consolidated key.

Enterprise teams on Flexible Commitment also got Spend Management budgets with email alerts, webhooks and optional pausing of production deploys. Yesterday's briefing covered the fifth item in that batch, experimental WebMCP in mcp-handler.

So what for TSD: The v0 change is the one with money in it. Push TSD's reusable pieces — booking widget, concierge chat embed, the standard site shell — into a private npm package, and v0 output starts arriving already on-brand instead of needing a rewrite. That is the difference between v0 as a toy and v0 as the first hour of every client build.

Regulation September 21

Ireland's DPC fined Google €403 million over location data

The Data Protection Commission closed an inquiry opened in 2020 after complaints from several European consumer-rights organisations, and imposed administrative fines totalling €403 million (about $463 million). Investigators examined three features — Web & App Activity, Location History and Location Accuracy — across the period from 25 May 2018, when GDPR took effect, to 4 February 2020. Deputy Commissioner Graham Doyle framed the failure as users being unable to know their location was being used to target ads or infer their interests. Google has six months to bring the processing into compliance.

So what for TSD: The finding is about consent clarity, not about location tech being illegal, and that same test applies to the tracking a small business bolts onto its site. Pair this with the OpenAI __obi item in today's AI briefing and you have a clean two-slide case for a paid privacy-and-tags review: what loads, what it collects, what the banner says.

Hardware September 20

iFixit opened the iPhone 18 Pro: a new thermal package and an unrepairable aperture

The A20 Pro moves to a package that sits the silicon die side by side with memory rather than stacking it, taking the memory out of the SoC's thermal path so the chip couples directly to a vapor chamber with three times the surface area of the iPhone 17 Pro's. That is the engineering behind the sustained-performance and faster-charging claims.

The variable aperture is six blades about the thickness of a human hair, driven by electromagnets independent of the stabiliser. One blade flew out during disassembly. A stuck aperture will likely mean replacing the whole main camera assembly. iFixit also damaged the plastic frame around the display on three of four units, and gave both Pro models a provisional 7 out of 10 for repairability.

So what for TSD: Mostly context, with one practical edge: sustained thermal headroom on flagship phones is what makes on-device capture and real-time video features viable for client apps. If a client wants a camera-heavy mobile experience, the hardware is getting out of the way faster than the repair story suggests.

Robotics September 21

About 7,000 humanoid robots sold worldwide last year

Reuters reviewed International Federation of Robotics data ahead of its official release: roughly 7,000 humanoid robots were sold globally in 2025 for industrial and professional service use, and many of those went to research institutes and companies buying them to collect training data rather than to do productive work. For scale, about 542,000 industrial robots were installed in 2024 and roughly 199,000 service robots sold for transport, hospitality and cleaning.

So what for TSD: Useful calibration when a client brings up robots taking over. The deployed number is tiny and mostly experimental, while the software side — agents, voice, scheduling — is where the actual near-term automation money is. That is the business Nash is already in, and the gap between the two numbers is the argument.
