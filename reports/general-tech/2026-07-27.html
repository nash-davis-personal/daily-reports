Stack watch Jul 27

No new advisory to patch — the July 20 security release is still the current line

Next.js has published nothing since the July 20 security release, and the Vercel changelog has not moved since July 24 (WAF for Blob in beta, 30-minute workflow steps, Claude Opus 5 on AI Gateway). The July 20 release remains the one that matters: eight CVEs including a high-severity App Router denial of service via Server Actions (CVE-2026-64641), a middleware bypass on Turbopack builds with a single locale (CVE-2026-64642), and two SSRF paths (CVE-2026-64645, CVE-2026-64649).

Patched versions are 16.2.11 on Active LTS and 15.5.21 on Maintenance LTS. Vercel now preannounces these on a monthly cadence, so the next one is predictable rather than a surprise.

So what for TSD: Run npm ls next across every client repo today and confirm each is at 16.2.11 or 15.5.21. The middleware bypass is the one that quietly voids auth checks, and any site you built with Turbopack and a single locale is exposed until it is patched.

Breaking Jul 21–23

Supabase sets two dates: logs API removal September 23, Envoy gateway from August 9

Supabase is moving log querying to a ClickHouse-backed system. The Management API analytics/endpoints/logs.all endpoint gets removed on September 23; the path becomes analytics/endpoints/logs, queries must convert to ClickHouse SQL dialect, every source now lives in one unified logs table filtered by source_name, and nested field access moves from metadata arrays to a flat log_attributes map. Separately, self-hosted Supabase switches its default API gateway from Kong to Envoy starting the week of August 9, flagged as a breaking change.

Supabase also opened Pipelines in public alpha on July 21 — managed change-data-capture streaming Postgres changes to BigQuery in near real time, with initial table copy, incremental replication and automatic schema-change detection, priced at $0.053 per hour per active pipeline during alpha.

So what for TSD: Grep your projects and any client automations for logs.all now — anything that scrapes Supabase logs for a dashboard or an alert breaks silently on September 23. Neither of these is a security fix, which is exactly why nobody gets around to them; that gap is a billable retainer line, and it is today's best bet in Money Moves.

◆ Security & the developer economy

Effective today Jul 27

GitHub halves public bug bounty payouts because AI-generated reports buried the triage queue

Starting today, GitHub cuts public bug bounty payouts by at least half at every severity level. Critical findings drop from a $20,000–$30,000-plus range to a flat $10,000, while a permanent invite-only VIP tier pays $30,000 and up with faster responses and direct access to the security engineering team. Reports filed before today, including everything already sitting in the triage queue, keep the old terms.

GitHub's stated reason is the flood of low-effort and AI-generated submissions now swamping bounty programs. The two-tier structure is an explicit bet that paying proven researchers more and everyone else less produces better signal.

So what for TSD: This is the first big platform to formally price in AI slop, and the same dynamic is coming for anything with an open intake — contact forms, quote requests, support inboxes. When you pitch AI intake triage to a client, this is the concrete story to point at.

Exploited Jul 23

Check Point patches a SmartConsole auth bypass already being used in attacks

CVE-2026-16232 is an authentication bypass in the Check Point SmartConsole login process, CVSS 9.1, confirmed exploited in the wild against what the vendor calls a small number of customers. An unauthenticated remote attacker can obtain an application login token and authenticate to the management server with full administrative privileges, then modify security policies and configurations. It affects Check Point Security Management and Multi-Domain Security Management — the servers that push policy to the firewalls.

Rapid7 recommends hunting for compromise even after the hotfix, particularly where the management server has been reachable from the internet, reviewing admin, SmartConsole, API and application-token activity against the published indicators.

So what for TSD: Not your stack, but it is the stack at the larger clients you want — anyone with a real IT vendor probably runs Check Point somewhere. Forwarding this to a prospect's office manager with one plain-English sentence is a legitimate, no-pitch reason to be in their inbox this week.
