◆ Patch first, everything else after

Critical Aug 26, 2026

Tomorrow's Next.js release fixes one critical vulnerability across both supported majors

Under the security release process Next.js announced in July, the team pre-announced on August 20 that August 26 brings a single critical severity fix, shipping as 16.3.3 on the 16.x line and 15.5.24 on the 15.x line. The advisory covering impact, affected versions and upgrade instructions publishes with the release. Nothing about the vulnerability itself is public before then.

The advance notice exists so teams stage the upgrade before disclosure hands attackers a map. That window closes tonight. This briefing has now flagged the date four editions running, and today is the last one where the flag is still useful.

So what for TSD: Run the inventory today, not tomorrow morning. For every client project, record the Next major and exact minor, then run the patch bump locally and confirm the build passes before the advisory exists. Anything on 16.x goes to 16.3.3, anything on 15.x goes to 15.5.24. Do the boring dependency check now so Wednesday is a version bump and a deploy rather than a day of debugging under pressure, and remember Wednesday also carries PCE and Nvidia earnings, so it is a bad day to be improvising.

◆ Your stack shipped a good week

Platform Aug 24, 2026

Vercel environment variables now distinguish Config from Secret

Environment variables carry a type in the dashboard and the CLI. Config values remain readable after they are set. Secret values are write-only, so once you save an API key nothing can read it back out through the UI or the CLI. Vercel shipped this alongside a batch of runtime work: Bun functions now support packages up to 5GB and a 30-minute maximum duration, elastic build machines read Turborepo cache data to prevent tier downgrades and underprovisioning, and v0 apps can now connect to more than 100 third-party services through Vercel Connect.

So what for TSD: Go mark every provider key across the client projects as Secret this week, especially the Supabase service-role keys and the Anthropic and OpenAI keys. The reason is specific to how you work: you hand clients dashboard access and you point coding agents at these projects, and write-only means neither a curious client nor an agent with CLI access can exfiltrate a key that is already set. It also changes your own runbook, because you can no longer read a key back to copy it elsewhere, so store the canonical copy in your password manager at the moment you create it.

SDK Aug 25, 2026

Vercel's Chat SDK gained Notion and XChat adapters

Shipped today: the same bot you run on Slack, Discord and Teams can now take part in Notion page and block comment discussions, and Chat SDK added support for XChat, X's encrypted messaging platform. Chat SDK is the open-source TypeScript library Vercel released in February for building a chat bot once and deploying it across platforms, and the Notion adapter carries webhook HMAC verification, streaming edits, conversation history and file uploads.

So what for TSD: This is a productisable offer sitting on a library you already have installed. A Notion-resident agent that answers from a client's internal docs is the same RAG pipeline as Concierge with a different front door, and plenty of Charlotte SMBs run their operations in Notion. Build one against your own vault first, screenshot it answering a real question, and hand that to Grant and Bishop as a second thing to sell into accounts that already bought a website.

◆ Provenance you did not ask for

Privacy Aug 25, 2026

Paint and Photos embed a server-issued GUID in images generated on your own machine

Researcher Xusheng Li reverse-engineered the pipeline and The Register followed up today. When Cocreator generates an image on a Copilot+ PC, the Stable Diffusion inference runs locally on the NPU, but the prompt is still sent to Azure for a safety check and the service returns a GUID. That GUID is then encoded into the pixels themselves as an invisible watermark under Microsoft's InvisMark scheme, and named in a signed C2PA soft-binding assertion in the file manifest. The feature requires both a Microsoft account and an internet connection despite the local generation.

The two layers matter. Stripping file metadata does not remove the pixel watermark, and the identifier ties the image back to the account that made it. The likely driver is Article 50 of the EU AI Act, whose transparency rules took effect on August 2 and require AI-generated content to carry a detectable machine-readable mark.

So what for TSD: Do not run client marketing images through Paint or Photos Cocreator. An image on a client's homepage would carry an identifier traceable to your Microsoft account, which is a disclosure you never agreed to make on their behalf. Keep generation on the tools you already control, and when a client asks whether their site imagery is AI-generated, the honest answer now needs to cover what is embedded in the file as well as how it was made. If you ever sell into an EU-facing client, Article 50 is worth reading properly rather than inheriting someone else's compliance decision.

◆ Silicon and succession

Chips Aug 24, 2026

Xiaomi announced a 3nm phone chip that matches Apple single-threaded and beats it multi-threaded

The XRING O3 is built on TSMC 3nm with LPDDR6 and uses a ten-core all-high-core design, dropping the efficiency cores conventional phone SoCs rely on. Xiaomi claims Geekbench 6.5 scores of 3,945 single-core and 15,221 multi-core, up 31% and 61% over the XRing O1, and 5.22 million on AnTuTu, the first flagship SoC past five million. Testing channel Geekerwan reported it well ahead of current Android flagships on energy efficiency.

The comparison worth holding lightly is the Apple one. Daniel Lemire's read is that the O3 roughly matches Apple cores single-threaded and is much faster multi-threaded, with the caveat that Apple's next processor is close and the edge may be short-lived. These are vendor-supplied benchmark numbers until independent testing lands.

So what for TSD: Nothing to do this week, and one thing to watch. If Android flagship silicon is genuinely at parity, on-device inference for a phone-based client app stops being an iPhone-only assumption in about a year. Keep building web-first, since that bet gets stronger rather than weaker when every phone can run a small model locally.

Business Sept 1, 2026

Tim Cook hands Apple to John Ternus next Tuesday

Apple announced in April that Cook would become executive chairman and that John Ternus, senior vice president of hardware engineering, becomes CEO effective September 1. Ternus is 51, close to the age Cook was when he took the job, and has spent nearly his entire career at Apple, running AirPods, Mac, iPad and iPhone hardware since 2013. August 24 marked fifteen years since Cook replaced Steve Jobs, and The Information reported the company held a farewell celebration this week.

Bloomberg reports the product calendar does not pause for the handover. A new Mac mini with M5 or M6 silicon is expected within days, ahead of the September iPhone event, with an OLED iPad mini by late October and new AirPods later in the year.

So what for TSD: A hardware engineer running Apple is mildly good news for anyone whose delivery machine is a Mac, and irrelevant to anything you ship this quarter. The practical note is the Mac mini refresh: if a build machine or a local inference box is on your list, waiting a week costs nothing and the current generation gets cheaper the day the new one lands.
