◆ Patch & secure

Patch now CVE-2026-45659

Actively exploited SharePoint RCE lands on CISA's KEV list

CISA added a Microsoft SharePoint Server remote-code-execution flaw (CVE-2026-45659, CVSS 8.8) to its Known Exploited Vulnerabilities catalog after confirmed exploitation, with a federal patch deadline of July 4. The bug is a deserialization-of-untrusted-data RCE: an authenticated attacker with only Site Member permissions can run code on the server — no admin needed.

So what for TSD: None of your builds run SharePoint, so there's no direct action. But if any client hosts an on-prem SharePoint/Microsoft server, flag it — this is the kind of thing that becomes a ransomware entry point within days. Use it as the hook for a paid "are you patched?" security check.

Your stack Next.js / RSC

The Next.js advisory to actually confirm is patched

No fresh Next.js or Vercel advisory dropped this week. The one that still matters for TSD is the May 2026 coordinated release, which fixed 13 advisories including a high-severity React Server Components denial-of-service (an upstream RSC issue, CVE-2026-23870). Vercel's guidance was blunt: patching is the only complete mitigation, and WAF rules can't reliably block it.

So what for TSD: Same bug class as the SharePoint story — untrusted input deserialized on the server. Confirm every client Next.js app is on the patched release; a specially crafted request to any App Router Server Function can spike CPU and take a site down. Run npm ls next across your repos this week.

◆ The compute buildout

New entrant Jul 1

Meta stands up a cloud business and sells its spare compute

Meta said it will launch a cloud business and resell excess computing power; the stock rose nearly 9% on the July 1 news. It's a new hyperscale-adjacent supplier entering a market where Alphabet, Microsoft, Amazon and Meta are collectively on track to spend $635–665B on AI infrastructure in 2026.

So what for TSD: More compute supply and more competition among sellers points the same direction — cheaper inference over time. That's a tailwind for margins on anything you run on client behalf. It doesn't change your stack today, but it strengthens the case for locking clients into fixed-price AI now while your unit costs trend down.

Silicon 2026

OpenAI's custom chip and a still-hot semiconductor market

OpenAI revealed a custom "Jalapeño" inference chip (July 1), the latest lab to move to in-house silicon to cut inference cost. The broader chip market stays frothy: ~$10.7B has gone into semiconductor startups in 2026, Cerebras IPO'd last month after a $1B pre-IPO round, and industry sales are projected to hit ~$975B for the year.

So what for TSD: Background, not action. The signal is durable: the whole industry is racing to make inference cheaper, which keeps pushing API prices down. Build assuming today's per-token cost is a ceiling, not a floor.
