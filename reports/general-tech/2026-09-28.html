◆ Patch your stack

Security Sept 25 · rollout Sept 28

Supabase's Postgres 15.19 / 17.11 closes 44 CVEs, and existing projects must upgrade by hand

New Supabase projects provision on the patched versions starting today, and the upgrade button opens for existing projects. It won't happen automatically. Four changes can bite: ltree indexes on multibyte/ICU databases can silently return incomplete results until reindexed; data encrypted with pgcrypto's legacy ciphers (blowfish, cast5) will fail to decrypt after the upgrade unless re-encrypted first (CVE-2026-14663); btree_gist float indexes holding NaN values need a reindex; and custom operators with non-built-in selectivity estimators now need superuser, which breaks dump/restore (CVE-2026-2004).

Supabase published SQL detection queries for each case. Separately, Supabase Logs is moving to usage-based pricing (ingest plus query volume) with metering-only through early 2027; Supabase says over 90% of projects stay inside the included limits.

So what for TSD: Patch instruction: this week, run Supabase's detection queries against every client project, fix anything they flag (REINDEX INDEX CONCURRENTLY, re-encrypt legacy pgcrypto data), then upgrade from the dashboard. Do the smallest client first so you learn the process on a project that can afford it.

Security Lands Sept 30

Next.js ships nine security fixes Wednesday, including one critical

The scheduled release publishes Next.js 16.3.7 and 15.5.27 on Sept. 30 with full advisories: one critical, two high, five medium and one low. The details stay embargoed until then. It follows the Sept. 22 out-of-band fix for the critical next/og ImageResponse RCE (CVE-2026-94545, fixed in 16.3.6).

So what for TSD: Patch instruction: if any client repo is still below 16.3.6, upgrade today for the ImageResponse RCE. Then on Wednesday bump everything to 16.3.7 (or 15.5.27), let Vercel build previews, and promote once they pass. The TSD apps use proxy.ts with no middleware.ts; read the advisories for anything touching that request path before you promote.

◆ Space and silicon

Launch September 28

Starship Flight 14 attempts SpaceX's first orbital flight this morning

The FAA cleared the flight late Saturday. The 75-minute window opens at 8:15 a.m. ET from Starbase Pad 2, with backups Sept. 29 and 30. Ship 41 carries 26 Starlink V3 satellites, the first operational V3 units, and plans about six orbits at roughly 275 km over just under ten hours. Neither booster nor ship will be caught; both are planned to splash down. It's the program's first revenue flight after 13 suborbital tests. The outcome wasn't known when this briefing was filed.

So what for TSD: No action. If V3 deploys cleanly, faster Starlink is a real fallback for clients in spotty coverage (rural contractors, job-site trailers), and that matters when a phone receptionist depends on the connection.

Chips September 28

A TSMC affiliate's new Singapore fab opened with its capacity already sold out

Vanguard International Semiconductor inaugurated its first advanced 300mm plant in Singapore on Monday, built in under two years, with capacity fully booked before volume production begins in early 2027. It's already planning a second Singapore fab. The demand is data-center components for the AI buildout.

So what for TSD: Hardware stays tight into 2027. For clients buying gear (POS terminals, laptops, a new server), quote with a buffer on price and lead time.

◆ Dev tools

AI Gateway September 27

Fireworks' Ember-1 landed on Vercel's AI Gateway as a free two-week research preview

Ember-1 is a coding and agent model built on Kimi K3 that Fireworks says produces about 40% fewer reasoning tokens at comparable quality. It has a 1M-token context, image input, tool calling, implicit prompt caching, and zero-data-retention options. Use it as fireworks/ember-1 through the AI SDK, or point Claude Code or Codex at it via npx vercel ai-gateway setup.

So what for TSD: Free for two weeks, so it's worth an hour on a real Concierge eval set against your current model. Fewer reasoning tokens is margin on a retainer, but only if answer quality holds on actual client questions.
