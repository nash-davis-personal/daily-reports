◆ Your stack

Security status Aug 1

Nothing new to patch — the July 21 line is still current

No new Next.js, React or Supabase advisory has landed since the July 21 security release, which shipped 16.2.11 and 15.5.21 and covered App Router denial of service, middleware and proxy bypasses, server-side request forgery, cache confusion, an Image Optimization SVG DoS, internal Server Function endpoint disclosure and unbounded Server Action payloads. That release is the one that matters, and Vercel has committed to a regular patch cadence with advance notice, so the next one is predictable rather than a surprise.

The follow-up releases on July 25 were maintenance. 16.2.12 backported TypeScript 7 support and doc fixes. 15.5.22 went the other way and now rejects TypeScript 7.0 or newer with an explicit error rather than failing in a confusing place.

So what for TSD: Run npx next --version across every client repo and confirm 16.2.12 or 15.5.22. The one that will bite you is the 15.5.22 TypeScript guard — if any project has drifted onto TypeScript 7, the build stops with an error rather than a subtle break, so find it on your own time instead of during a client deploy window.

Platform July 31

Vercel closed the month with Passport, AI Gateway budgets, and a new MCP spec version

Eight entries landed on July 31. Passport lets you protect Vercel deployments with your own identity provider across multiple enterprise auth systems. AI Gateway Spend Budgets cap spend for a whole team or a single project, with email alerts and defaults that new projects and keys inherit automatically. A new AI Gateway Logs page breaks down individual requests by cost, token usage, duration and provider fallback, with filters. Vercel's MCP implementation moved to the 2026-07-28 specification with improved authorization and a stateless core.

The rest: workflow run search in observability, filterable by workflow, environment, deployment ID, region or custom parameters; the Chat SDK Microsoft Teams adapter picked up message reactions, native ephemeral messages, author emails via Microsoft Graph and custom token factories; DeepSeek V4 Flash is running updated weights on AI Gateway with better agent-task behavior; and Poolside's Laguna S 2.1 got a capacity bump on both paid and free tiers.

So what for TSD: Do the spend budget first — it is the single highest-value five minutes on this list, because an agent loop on a client project can burn a month of margin overnight and you currently have nothing between you and that bill. Set a team cap and a per-project default now. Passport is the other one with revenue attached: client staging behind a real identity provider instead of a forwarded preview link is a legitimate line item on a Managed AI retainer, and it removes the awkward conversation about who has the password.

Tooling July 30

GitHub put its Copilot SDK agent inside Visual Studio and VS Code

GitHub's July releases put an Agent preview built on the Copilot SDK — the same SDK behind the Copilot CLI — into both Visual Studio and VS Code, selectable from the agent picker. GitHub's framing is that it gets more tasks right on the first attempt with less back-and-forth, and that responses are shorter. The Agents window, in public preview, got a redesigned layout, faster review flows and better handling of multiple concurrent sessions. Copilot CLI added conditional sandbox bypass, Ctrl+G editing for freeform answers, and a web OAuth login flow as the default on local terminals.

So what for TSD: The convergence is the signal, not the feature list. Every vendor is landing on the same shape — one agent SDK, a CLI, an editor surface, and a multi-session review window — which is the shape you already work in. No reason to switch, but the multi-session review pattern is worth stealing: when you run parallel agents on a client build, you need one place to review their output, not four terminal tabs.

◆ Security and identity

Acquisition July 30

Okta bought Permiso for just under $200 million to watch what AI agents do after login

Okta agreed to acquire Permiso Security in an almost all-cash deal worth nearly $200 million, expected to close in Q3 of Okta's fiscal 2027. Permiso is a Palo Alto identity-security platform that detects threats across human, non-human and agentic identities in multi-cloud environments. It came out of stealth in 2022, was co-founded by former FireEye executives Paul Nguyen and Jason Martin, and had raised about $29 million total — so the exit multiple is telling.

The strategic read is that identity vendors are moving past verifying who logged in and toward continuously monitoring what users, applications and agents do once they are inside. Okta is betting that machine identities outnumber human ones fast enough to justify a platform.

So what for TSD: Enterprise buyers are being trained right now to ask "what can this agent reach, and who is watching it?" That question will arrive at your SMB deals within a year, in a cruder form. Get ahead of it cheaply: every agent you deploy gets a named service account, a scoped credential, and an activity log the client can actually read. It costs you an hour per deployment and it answers the objection before the prospect learns to raise it.

◆ Silicon and the money behind it

Markets July 29–31

Chip stocks shed over a trillion dollars, then the hyperscalers guided capex higher anyway

The late-July semiconductor selloff took more than $1 trillion off the companies powering the AI buildout, with Nvidia, SK Hynix, Samsung, Micron, AMD and TSMC each losing north of $100 billion. The stated fear was that AI infrastructure spending is peaking faster than expected. TSMC's July 16 results had beaten on profit and revenue but came with 2026 capex guidance raised to $60–64 billion, at least $4 billion above the prior forecast, which Morgan Stanley attributed partly to equipment cost inflation and read as a margin problem.

Then the buyers spoke. Amazon, Microsoft, Meta and Alphabet collectively guided to $720–745 billion of 2026 capital spending, and Amazon rose 15% on July 31 on earnings that highlighted its chip business. The market is pricing a spending peak the spenders are not describing.

So what for TSD: A capex fight between chipmakers and cloud buyers is not your problem, but the direction it settles is. Three-quarters of a trillion in committed 2026 buildout means inference capacity keeps growing and per-token cost keeps falling, which is exactly the assumption your Managed AI retainer margins depend on. Nothing in this week's tape argues for repricing upward. Keep pricing on outcomes.
