Release 16.4 ◆ Oct. 6

Next.js 16.4: Cache Components recommended everywhere, agent upgrades, React 19.3

The Next.js team now recommends Cache Components for every app. New projects from create-next-app have it on by default, and it becomes the default model in Next.js 17. The model is the 'use cache' directive plus Partial Prefetching, enabled with cacheComponents: true and partialPrefetching: true. Two additions close earlier gaps. export const ensureStatic on a page or layout fails the build if dynamic content sneaks into a route you meant to keep static, with 'shell', 'prefetch' and 'navigation' levels. New navigation() and prefetch() functions from next/cache let you leave expensive content out of a prefetch until the user actually navigates.

For upgrades, npx next@canary upgrade --agent=latest checks the installed version, picks a target, and hands a coding agent the migration guides, codemods and verification steps. experimental.agentUpgrade defaults to 'security' and nudges you during next dev and next build when a release fixes a known vulnerability in your version. An experimental agent-feedback flow drafts bug reports for you to review; nothing is sent until you click send, and it needs telemetry on. Across all apps: Turbopack's disk cache is 20–25% smaller, server HMR compiles only what a request needs, production bundles shrink through shorter CSS Module class names and export mangling, and React 19.3 brings stable View Transitions and Fragment Refs. The experimental Rust React Compiler uses 30% less memory and compiles 15% faster.

So what for TSD: Run the agent upgrade on one demo site first and time it. For marketing sites, add ensureStatic = 'navigation' to the root layout so a stray dynamic component can never add compute cost on Vercel. Leave proxy.ts as it is. Hold existing client apps off Cache Components until you have migrated one end to end.

Platform Oct. 6–7

Vercel: four new models on AI Gateway, a billing break on blocked traffic, time-based flags

AI Gateway added Claude Haiku 5.5, OpenAI's GPT-6 Luna Decisions, Mistral Large 4 and Google's Nano Banana 2.1 image model on Oct. 6 and 7, plus confidence-based fallbacks that escalate a decision to a second model when the first is unsure. A stealth model called Glyph Cluster is free through the gateway for now. Microfrontends Routing no longer bills for requests the Vercel Firewall denies, challenges or rate limits. Vercel Flags now accept timestamp attributes, so a rule can switch on at a set date.

So what for TSD: If Concierge already calls models through AI Gateway, trying Haiku 5.5 is a one-line model ID change (anthropic/claude-haiku-5.5). Timestamp flags are a clean way to schedule a client's seasonal banner or promo without a deploy.
