PatchOct 14

Next.js out-of-band security update: two Critical, one High

The Next.js team announced on Oct 8 that it would publish an out-of-band security update on Oct 14 covering three vulnerabilities in upstream dependencies. Two of the fixes were postponed from the September security release because of upstream coordination. Full advisories, affected versions and upgrade instructions publish with the release. For context, May 2026 brought twelve fixes and August brought two critical flaws that Vercel shielded on its platform.

So what for TSD: Patch instruction: check nextjs.org/blog and the GitHub security advisories today, then bump Next.js on every client and demo project and redeploy. Run npm audit across repos. Vercel has blocked earlier flaws at the platform layer, so hosted apps are likely partially covered, but upgrade anyway. I could not confirm the advisory IDs or versions before this ran, so read them before you act.

PlatformOct 5

Vercel: Sandbox Secure Compute, AI Gateway adds MAI models

Per the Oct 5 Vercel Weekly, Vercel Sandbox can now connect to a team's dedicated network with static IP egress and private AWS VPC access. AI Gateway added Microsoft MAI models alongside GPT-6.1 Sol and Claude Sonnet 5.5, and the agent skills ecosystem reportedly reached one million skills.

So what for TSD: Static egress IPs matter when a client's database or API only allows allow-listed addresses. It also gives you one gateway to compare models per client.

◆ Security and hardware

SecurityOct 12

Ledger confirms a hardware implant in wallets sold by a reseller

Ledger told customers who bought devices from Malaysian reseller CryptoBilis in the past three months not to set them up. A device examined by a former Mt. Gox CEO had a small circuit board with a microcontroller, antenna, LTE chip and e-SIM hidden under the screen padding. On-chain researchers estimate about $90M to $93M drained from 315 wallets starting around Oct 9. Ledger says its own systems and direct sales appear unaffected.

So what for TSD: Supply-chain tampering at a reseller is a pitch for clients who buy hardware through third parties (POS terminals, routers). Tell any client holding crypto to buy hardware wallets direct.

VulnsOct 12

Critical CVEs in Cisco, Atlassian and Veeam

Check Point's Oct 12 report lists Cisco NX-OS (CVSS 9.8, improper access control), Atlassian Data Center products (9.3, unauthenticated file access that can expose admin credentials) and Veeam Backup & Replication (9.4, remote code execution before build 12.3.2.4934).

So what for TSD: Low direct exposure for a web studio. If a client runs self-hosted Jira, Confluence or Veeam, send them the patch notice. That is a free touch that builds trust.
Check Point report
IncidentOct 12

Retail and public-sector breaches keep coming

Denmark disclosed unauthorized access to its Central Register of Persons through a private supplier, affecting about 8.8 million people. ASOS was hit using stolen employee credentials. Ahold Delhaize took systems offline, and Danfoss refrigeration controllers were abused to defrost fridges at French supermarkets.

So what for TSD: Both the Denmark and ASOS cases came through a supplier or stolen credentials. Turn on MFA and review vendor access for every client site you manage.
