◆ Your stack

Security Status as of Nov 24

No new advisory for Next.js, React, Tailwind or Supabase; the Nov 3 fixes are still the line to be on

The Next.js security advisories page and blog show nothing after the Nov 3 release, which shipped 16.4.5 and 15.5.29 with fixes for seven issues, mostly in caching, image optimization and Edge cookies. Write-ups disagree on whether one of the seven is rated High. The React Server Components advisory GHSA-xqc2-xf4c-x3h3 (CVE-2026-126187, rated 9.5) also still stands; React and Vercel report no exploitation. One write-up notes that 14.x is not covered by the October or November fixes.

So what for TSD: Run npm ls next react-server-dom-webpack in each client repo and bump anything below 16.4.5 or 15.5.29. Any client still on Next 14 has no patch for these, so put the upgrade on their next invoice.

Deadline Removal Dec 1

Supabase removes the Hono, H3, Elysia and NestJS adapters from @supabase/server on Dec 1

The Supabase changelog lists the four framework adapters as deprecated with removal on Dec 1, 2026. The same changelog shows the Supabase CLI moved to v3.0.0 on Nov 2, with npm, Scoop, the Linux packages and the setup-cli GitHub Action installing v3 by default; v2.122.1 keeps a v2 channel for anyone who needs it.

So what for TSD: Your Next.js apps do not use these adapters, but any Hono edge function or side service does. Grep every repo for @supabase/server before Monday. Also check any CI job that uses supabase/setup-cli: it now pulls v3 unless you pin a version.

◆ Dev tools

Launch Nov 23

Claude Ship brings agent review, fixes and policy-based approvals to GitHub pull requests

Code Review is generally available; PR Steward and Claude Approvals are in beta for Claude Team and Enterprise customers on GitHub. Approvals only signs off on changes that match a policy the team writes and sends the rest to a person. The General AI briefing has the full write-up.

So what for TSD: Start with dependency bumps. A tool that reviews and approves a Next.js patch release across a dozen client repos turns a lost evening into a few minutes of reading.

The 8-K reinstates Huang as president, CEO and director effective Nov 22. So what for TSD: No action. It removes one source of uncertainty under the model vendors you resell.
