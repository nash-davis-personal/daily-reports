◆ Patch this first

Security Jul 20–21, 2026

The first scheduled Next.js security release published: nine CVEs across App Router, rewrites, image optimization and the fetch cache

Yesterday's brief said not to upgrade to a version number read secondhand, because the release had slipped twice and npm's tags still pointed at the July 1 builds. It is out now. Upgrade paths:

npm install next@16.2.11 for the 16.2 Active LTS line, npm install next@15.5.21 for 15.5 Maintenance LTS. The same fixes are in v16.3.0-canary.92 and v16.3.0-preview.7, and will be in 16.3.0 when it goes stable.

The four high severity issues: CVE-2026-64641, crafted requests against App Router apps with at least one Server Action cause CPU exhaustion that blocks every other request in the same process. CVE-2026-64642, App Router apps built with Turbopack and a single locale in config.i18n.locales can have middleware or proxy bypassed, taking any auth check in that layer with it. CVE-2026-64645, a rewrites() or redirects() rule whose external destination hostname is built from request input can be pointed at an arbitrary host — SSRF for rewrites, open redirect for redirects. CVE-2026-64649, a Server Action on a custom server that forwards or redirects a request can be steered to a malicious host when the attacker controls Host headers.

The five mediums cover SVG-driven CPU exhaustion in the Image Optimization API when self-hosting with remote images enabled, unbounded Server Action payloads on the Edge runtime, unauthenticated disclosure of Server Function endpoint IDs, and two fetch-cache confusion bugs where a request body can return another request's cached response.

So what for TSD: Do this today, not this week. Run npx npm-check-updates or bump next directly in every client repo, redeploy, and spot-check the build. CVE-2026-64642 is the one to check by hand: if any project uses Turbopack with exactly one locale configured and enforces auth in middleware or proxy.ts, treat that site's protected routes as having been open until you deploy. CVE-2026-64645 is worth a grep too — any rewrite or redirect destination assembled from a query param or header is the exact shape being described.

Security Jul 17–21, 2026

wp2shell went from advisory to mass exploitation in four days, and the payload is a persistent webshell

The chain pairs CVE-2026-63030, a REST API batch-route confusion in WordPress core, with CVE-2026-60137, a SQL injection in WP_Query. Together they give an unauthenticated attacker remote code execution against a stock WordPress install with no plugins. Affected: 6.9.0 through 6.9.4, and 7.0.0 through 7.0.1. Fixed in 6.9.5 and 7.0.2, with forced automatic updates enabled.

As of July 21, exploitation in the wild is confirmed by multiple research teams, public proof-of-concept code is circulating, and observed activity includes webshell deployment, malicious plugin uploads and credential theft, traced across at least thirteen IP addresses in several countries. Industry telemetry cited by TechCrunch put vulnerable WordPress sites in the tens of millions early this week; one vendor found 60% of WordPress-using organizations had at least one vulnerable instance when the CVEs published, and 25% had a vulnerable server facing the internet.

So what for TSD: This is a phone call, not a newsletter item. Any prospect or past client still on WordPress is either patched by auto-update or already compromised, and a forced core update does not remove a webshell that landed before it. Offer a fixed-fee compromise check — confirm core version, diff the plugin directory, look for files modified since July 17, check for unknown admin users — and let the result open the rebuild conversation. ◆ The chip tape turned, at least for memory

Markets Jul 21, 2026

Memory names ripped higher into the Alphabet, Tesla and IBM reports

The Roundhill Memory ETF gained 11.7% Tuesday, its strongest session in more than a month. Western Digital rose about 9%, SanDisk about 8%, Micron about 7%, with SK Hynix's US listing up roughly 7% as well. The move is positioning rather than news: traders are betting the next two weeks of big-tech results reinforce AI capex rather than cut it.

The fundamentals underneath are not subtle. Micron's fiscal Q3 revenue was $41.5B, up 346% year over year. Western Digital guided fiscal Q4 revenue growth of 36% to 44%. That runs against last week's tape, when the Philadelphia Semiconductor Index fell into a bear market and TSMC's capex raise to $60–64B knocked the sector down.

So what for TSD: No trade here, and none is being suggested. The operating signal is that memory pricing is being set by AI demand, which flows into the cost of every server, laptop and phone your clients buy. If you are quoting anything with a hardware line item this year, do not carry a 2025 price into a 2026 proposal.

◆ Where the venture money went this week

Funding Week of Jul 21, 2026

Robotics and edge inference took the largest checks in a 122-round week

Monumental raised $32M in Series B for construction robotics that automate physical building work. Quadric.io raised $46M in Series C for programmable general-purpose AI inference processor IP aimed at on-device machine learning. Hyperion Robotics took $7.4M for robotic microfactories and the software to run them, and Ravee Optics raised $6M in seed for ultra-compact laser communication terminals for space.

The pattern across the week's 122 disclosed rounds is consistent with the first half of the year: capital is crowded into AI, defense and infrastructure, and increasingly into the physical layer rather than another chat application.

So what for TSD: Edge inference silicon getting funded is the long-term reason not to build a business on top of a single hosted model's pricing. Nothing changes this quarter. It does mean the "run it locally for pennies" option gets more real every year, which is another argument for pricing retainers on outcomes rather than per-message inference cost.
