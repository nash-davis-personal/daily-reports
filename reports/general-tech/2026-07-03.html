◆ On Nash's stack

Feature Next.js 16.3 Preview

Next.js 16.3 adds Instant Navigations and a persistent Turbopack cache

The 16.3 Preview brings Instant Navigations (Stream or Cache to make a route change instant, or Block to opt out) and Partial Prefetching — a reusable per-route shell cached on the client so a click renders immediately while the rest streams in, giving multi-page apps an SPA feel. Turbopack picks up memory eviction, a persistent build cache, Rust React Compiler support, and import.meta.glob. There's also an AI-facing pass: bundled docs, Skills, browser introspection, and more actionable errors.

So what for TSD: Free perceived-speed win for client sites. Test Instant Navigations on a demo (the marketing front-door or a client portal) — snappier page-to-page transitions read as "premium build" to an SMB owner, at zero design cost. Keep it on a preview branch until 16.3 goes stable before shipping to a paying client.

Feature Supabase · Jun 2026

Supabase Auth ships beta passkeys (WebAuthn)

Supabase added passwordless, phishing-resistant passkeys to Supabase Auth in beta — users register biometrics, device PINs, or security keys, and admins manage them via Dashboard, CLI, and Management API. Separately, Supabase moved the default self-hosted Docker image from Postgres 15 to Postgres 17 (existing PG15 users can pin or upgrade in place with rollback).

So what for TSD: Nash already hand-rolled native passkeys on the TSD client portal. If Auth now supports them first-class, he can likely simplify that custom code and lean on the platform — less to maintain, same phishing-resistant login. And it becomes a clean upsell: "passwordless sign-in for your customers" is now a checkbox, not a project.

◆ Security — stay patched

Incident Jul 2, 2026

DHS confirms a breach of its Homeland Security Information Network

The Department of Homeland Security confirmed hackers breached the Homeland Security Information Network, the platform used to share sensitive information among federal, state, local, and private-sector partners. It lands amid a hot cyber-M&A market — more than 50 acquisitions involving Israeli security startups in H1 2026, with AI now the strategic driver of those deals.

So what for TSD: Not Nash's system, but the prompt is: when a federal network gets breached, a client's WordPress or unpatched Next.js app is a soft target too. Do a 15-minute pass across live projects — confirm every app is above the React2Shell patch floor (Next.js ≥16.0.10 / ≥15.5.7), dependencies current, and secrets rotated on any app that predates December's fixes.

◆ Where the money is going

Money H1 2026

A record $510B venture half, still AI-led — chips, infra, dev tools

Global venture funding hit $510B in H1 2026, a record for any half-year, overwhelmingly on AI-related deals. Recent rounds skew to the picks-and-shovels: SiFive raised $400M for custom chip designs, TwelveLabs $100M for video-intelligence models (with AWS as preferred cloud), and Oxmiq Labs $35M for AI hardware under ex-Intel chief architect Raja Koduri. Capital is concentrating in semiconductors, developer infrastructure, security, and labor-saving software.

So what for TSD: This is demand weather, not a stock tip. Record money into AI infra means more, cheaper capability flowing down to builders — and a rising tide of SMBs who now expect an "AI answer." The businesses funding this can't sell to a Gastonia HVAC shop; TSD can. Watch for the cheaper tools these rounds produce and fold them into the delivery stack.
