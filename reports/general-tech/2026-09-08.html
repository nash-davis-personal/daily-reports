◆ Patch and hunt

Critical CVE-2026-75650 ◆ Sept 4–7

StyleSmuggler: unauthenticated RCE in every current Magento and Adobe Commerce build

Dutch e-commerce security firm Sansec observed active exploitation starting September 4 and published an early advisory on September 5 specifically because stores were being compromised while it wrote. The flaw abuses Magento's template system through PHP code injection, triggered while generating a "Payment Transaction Failed Reminder" email, and requires no authentication at all. It affects every current version including the latest 2.4.9 release. Adobe published an emergency hotfix on September 7 and the bug is now tracked as CVE-2026-75650 with a CVSS score of 10.0.

The payloads seen in the wild are a Rust-based Linux backdoor that beacons to an external server and waits for instructions, and a PHP dropper that writes a web shell capable of executing arbitrary PHP. The first identified victim was running 2.4.6-p15 with the July and August 2026 security patches fully applied — fully maintained stores were compromised as easily as neglected ones.

So what for TSD: Apply Adobe's September 7 hotfix (APSB26-146) to any Magento or Adobe Commerce site TSD touches today, then treat every one of them as potentially breached: look for unexpected Rust binaries, new PHP files under pub/ and var/, outbound connections from the web user, and admin accounts you did not create. Then make the call to any client on Magento — a same-day "we checked your store, here is what we found" message is the highest-trust outreach available this week, and it is a natural opener for a migration conversation off Magento entirely.

Breach CVE-2026-63077

JetBrains Cadence was breached through an unpatched TeamCity flaw on its own server

Attackers began operating on the JetBrains Cadence server on August 8, the company discovered it on August 23, and took the server offline on August 24. The entry point was CVE-2026-63077, a critical TeamCity vulnerability JetBrains had already patched in its shipping product but had not applied to the Cadence server. The threat actor reached data in a 2024 server backup and obtained access that could have exposed storage holding current Cadence users' email addresses, project source code and credentials. Confirmed exposed personal data covers usernames, real names, email addresses, last-login timestamps and last-accessed IP addresses.

JetBrains has invalidated all access tokens used by the Cadence plugin in PyCharm and is telling organizations to rotate and revoke everything used with the service: AWS IAM credentials, source-control tokens, package and container registry credentials, Slack tokens, webhooks, API tokens, SSH and deployment keys, and service-account credentials.

So what for TSD: If any TSD project ever ran through Cadence, rotate now — Supabase service keys, Vercel deploy tokens, GitHub PATs, any API keys committed to a pipeline. The broader lesson costs nothing to adopt: the vendor shipped the patch and skipped it on their own infrastructure. Run the same audit on TSD's own boxes and self-hosted tooling this week.

◆ Hardware, trade and the cost of building

Trade effective September 8

Canada's counter-tariffs on 700+ US products took effect today

Canadian counter-tariffs of 15%, 25% and 50% on more than 700 US-made products came into force today, covering roughly $27.6 billion in imports from the United States. The targeted categories are steel, dairy, appliances, farm equipment, pulp and paper, and electronics, with duties on US steel and aluminum doubled to 50%. Negotiations collapsed in August after each side accused the other of bad faith. Separately, Washington is reported to be weighing new duties on semiconductors and an expanded set of products made alongside them, including laptops, data-center servers and gaming hardware.

So what for TSD: Two direct effects. Any client selling into Canada — the import/ceramics retail account especially — needs their checkout, shipping copy and landed-cost math reviewed this week, and that review is a billable same-week job. And if TSD needs a machine, a GPU box or client hardware in the next quarter, buy before the semiconductor duties land rather than after.

Apple's foldable arrives tomorrow, and there is no base iPhone this year

Apple's "Surprise and shine" event runs September 9 at 10am PT from Apple Park. Expected: iPhone 18 Pro, iPhone 18 Pro Max, Apple's first foldable iPhone, Apple Watch Series 12, Apple Watch Ultra 4 and possibly new AirPods.
