◆ Security: patch the stack, watch the new attack surface

Heads-up 2026 DBIR

AI-driven exploits pass credential theft as the top breach cause

Verizon's 2026 Data Breach Investigations Report finds AI-driven exploits have become the single leading cause of breaches — ahead of stolen credentials. In parallel, security researchers reported attackers manipulating AI-powered support systems to take over accounts, a reminder that an AI agent with access is itself an attack surface.

So what for TSD: Your concierge and receptionist agents touch real client systems. Treat every tool/connector an agent can call as a privilege to scope tightly — least-privilege keys (now easier with Claude's Workload Identity Federation), input validation on anything that reaches a function, and no secrets in client repos. This is also a sellable line: "we build AI that's hardened against the #1 breach vector of 2026."

Patch Next.js 16.2.9

Next.js patch baseline still 16.2.6+ / 15.5.18+

No new Next.js security advisory landed this cycle — the June releases (16.2.8 and 16.2.9, both June 9) were housekeeping to fix npm dist-tags. The action item from the May coordinated release of 13 advisories (DoS, SSRF, middleware bypass, cache poisoning, XSS; CVE-2026-23870) still stands: anything below the patched lines is vulnerable.

So what for TSD: Run a one-line audit across every client repo — npx next@latest --version won't tell you the installed version, so check each package.json and bump anything under 16.2.6 (or 15.5.18 on the 15.x line). Patching is the only complete fix; a WAF rule won't cover it.

Threat Jun 2026

Ransomware crews are targeting education providers

A Resecurity investigation details a surge of ransomware against schools, learning platforms, and edtech vendors; a June hit on GSF, which runs schools across several countries, encrypted core systems and disrupted classes for tens of thousands. Resecurity expects edtech breaches to roughly double year-over-year.

So what for TSD: Direct tailwind for the Columbia IBC education lead and any local private-school pitch — "secure, modern, and you own the code" lands hard right now. Lead education conversations with data handling and access control, not just the chatbot.

◆ Dev economics

Pricing Live Jun 1

GitHub Copilot's metered billing is biting

Copilot's shift to usage-based "AI Credits" (1 credit = 1 cent, billed on input/output/cached tokens by model) is producing 10x–50x cost increases for power users running agentic sessions, per developer reports. Pro stays $10/mo with 1,500 credits; a new Copilot Max tier launched at $100/mo for heavy users. Microsoft's in-house Project Polaris model is slated to replace GPT-4 Turbo as Copilot's default in August.

So what for TSD: Two takeaways. First, watch your own AI tool spend — agentic coding can quietly run a metered bill into real money; track it. Second, this is a sales opening: small software teams getting hit with meter shock are a prospect list for a "cut your AI tool spend" audit (see today's Money Moves).
