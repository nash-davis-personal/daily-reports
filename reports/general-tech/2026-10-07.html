◆ Your stack

Next.jsSept. 30

Next.js September security release: SSRF, cache poisoning, info disclosure

The Next.js team disclosed seven vulnerabilities fixed on Sept. 30 in 16.3.8 and 15.5.27. They include an SSRF through Image Optimization when an allow-listed remote URL is attacker-controlled (CVE-2026-94483; not affected if images.remotePatterns is unset) and a cache-poisoning flaw where a self-hosted Pages Router app using SSG or ISR can have a page cache entry replaced with another route's content (CVE-2026-94543; apps on Vercel are not affected). Other fixes cover Draft Mode leakage and a dev-server MCP endpoint leak. Next.js now publishes security releases monthly, so expect the next one around late October.

So what for TSD: Run npm i next@16.3.8 (or 15.5.27 on the 15 line) on every client project this week, starting with any self-hosted ones. Check each site for images.remotePatterns. This is separate from the Windows RCE covered Oct. 6.

SupabaseOct. 2

Supabase patches a Next.js RCE in its realtime-js example and rebuilds Storage listing

Supabase's Oct. 2 release notes include a fix for a Next.js remote-code-execution issue in the realtime-js example, plus Functions now sending a Blob or File with its own content type. Separately, a Storage overhaul replaces the prefixes table and its six triggers with a hybrid skip-scan algorithm and cursor pagination, with object listing reported up to 14.8x faster on tables of 60 million-plus rows. Supabase is also listed as a Tailwind CSS partner. Reminder from the Oct. 6 edition: the Data API grants change takes effect Oct. 30.

So what for TSD: If any client app was seeded from the realtime-js example, bump Next.js and re-check. The Storage speedup only matters for very large buckets; the Oct. 30 grants change is the one with a deadline.

Next.jsEarly Oct.

Canary builds: Suspense fallback fix and React Compiler memoization options

Early-October canaries fix a Suspense fallback triggered by URL updates, stop suspending client params on shallow URL updates, and add options to preserve React Compiler memoization. Canary only; not for client production.

So what for TSD: Nothing to ship. Read the notes if a client site shows flicker on filter or tab URL changes.

◆ Security and chips

SecuritySept. 28 – Oct. 2

Edge and mail gear exploited: Citrix, Cisco SD-WAN, Zimbra, Apache, ModSecurity

A weekly roundup lists active exploitation of Citrix NetScaler RCE zero-days (Sept. 28), a Cisco SD-WAN critical bug (Oct. 1), Zimbra unauthenticated code execution (Oct. 1), Apache HTTP Server request smuggling (Oct. 2) and ModSecurity WAF bypasses (Oct. 1), plus an OpenSSL high-severity fix (Sept. 30) and Linux kernel local privilege escalation CVE-2026-72018. The roundup gives few CVE ids, so check vendor advisories for specifics. A GitHub Copilot CLI flaw that lets prompt injection steal developer secrets, and LibreOffice CVE-2026-63277 (malicious spreadsheet runs code on open, fixed Oct. 5), were also reported this week.

So what for TSD: If any client runs Zimbra mail, Apache or a self-managed VPN, send them a patch note; it is a cheap retainer touchpoint. Update LibreOffice on your own machine.

ChipsOct. 1

California company owner arrested over alleged $300M GPU server smuggling to China

Greg Lui, owner of Earthmade Computer Inc., was arrested Oct. 1 after a three-count indictment returned Sept. 29. Prosecutors allege he helped smuggle more than $300 million of export-controlled servers containing US-made GPUs to China between 2023 and 2024. He faces export-control conspiracy, smuggling and money-laundering conspiracy charges. These are allegations.

So what for TSD: Export enforcement is tightening, which keeps GPU supply and cloud GPU pricing tight. Keep client AI on API calls rather than owned hardware.
