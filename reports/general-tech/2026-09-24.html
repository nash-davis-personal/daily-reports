◆ Nash's stack, this week

Breaking September 22

Critical RCE in Next.js's next/og — patch to 16.3.6 or 15.5.26 today

Vercel published GHSA-vcvr-r3jv-pc5j and shipped an out-of-band release: Next.js 16.3.6 (Active LTS) and 15.5.26 (Maintenance LTS). The bug is in the Node.js ImageResponse implementation inside next/og — improper escaping in the SVG output that Satori generates could lead to remote code execution, traced to vulnerabilities in Satori's own upstream dependencies (fixed via GHSA-wx4j-mvgx-mqwp). Affected range is Next.js >=16.2.0 <16.3.6. Next.js 15.x is not affected by the RCE itself; 15.5.26 ships related hardening only.

The narrow but important detail: this only hits the Node.js ImageResponse path. Apps generating OG images on the Edge runtime are not affected. That still leaves anyone on the Node runtime — which is the default for most self-hosted or non-Edge Vercel deployments — exposed on any 16.2.0–16.3.5 build.

So what for TSD: Tonight: run npm ls next across every client repo and the daily-reports/portfolio repos. For anything on 16.2.0–16.3.5, run npm install next@16.3.6 and redeploy; for 15.5.x, bump to 15.5.26. Specifically check any site using dynamic OG-image generation (next/og) for social cards — that's the exposed surface, and it's a common feature on marketing/landing pages TSD ships for SMB clients. If a site doesn't use next/og at all, the patch is still cheap insurance — apply it anyway.

Breaking September 23

Supabase killed the logs.all Management API endpoint

As scheduled, Supabase removed the analytics/endpoints/logs.all Management API endpoint on September 23 and moved log querying to a new ClickHouse-backed analytics/endpoints/logs endpoint. The new endpoint takes ClickHouse SQL only and returns every log source through one unified table instead of Supabase's old per-source tables, filtered with a source_name column. Anyone hitting the old endpoint via a script, integration, or custom tool gets a hard break, not a deprecation warning. Dashboard Logs Explorer users are unaffected. Supabase's own MCP server needs to be on v0.10.0 or later to point at the right endpoint automatically.

So what for TSD: If any client automation, uptime check, or custom admin panel Nash built queries Supabase logs programmatically (rather than through the dashboard), it silently broke this week. Grep client repos for "logs.all" and check any MCP-based tooling is on server v0.10.0+. Low blast radius, but it's exactly the kind of quiet cutover that turns into a support ticket from a client three weeks from now if it's not checked proactively.

◆ Chips, silicon, and what it costs to build

New September 22

Qualcomm's first 2nm chips are built around on-device AI agents

At the Snapdragon Summit, Qualcomm unveiled the Snapdragon 8 Elite Gen 6 and 8 Elite Extreme Gen 6 — the first mass-market mobile chips on TSMC's 2nm process and the first to push a phone CPU past 5GHz. Both center on FlexCache, a new cache architecture aimed specifically at cutting latency in the orchestration loops that autonomous on-device AI agents run. The Extreme variant can run a 30-billion-parameter mixture-of-experts model entirely offline. Qualcomm claims 13% more CPU performance and 44% more GPU performance over last year's 8 Elite Gen 5. Devices from Motorola, OnePlus, Xiaomi and iQOO ship later this year; the bulk of the 2027 flagship class (Galaxy S27, OnePlus 16) lands Q1 2027.

So what for TSD: Not an immediate build item, but it's the leading edge of a real trend: capable local inference on the device a client's customer is already holding. Filed for later — if TSD ever ships an on-device or hybrid version of the receptionist/concierge products for offline-tolerant use cases, this is the hardware generation that makes it plausible without a server round-trip.

◆ Space and payments infrastructure

Feature September 21–23

Starship stacked for its first true orbital flight, targeting September 28

SpaceX rolled Super Heavy booster B21 to the pad at Starbase on September 21 and stacked Starship S41 on top September 23 — the first flight of the fully integrated stack, pending FAA orbital-license approval, no earlier than September 28. The mission would deploy 26 Starlink V3 satellites, each rated at roughly 1 Tbps of added capacity — about 10x a V2 Mini satellite — for 26 Tbps added to the constellation in a single launch.

So what for TSD: Nothing to act on directly, but Starlink capacity is the thing worth tracking for any rural NC client (detailing routes, chambers outside the Charlotte core) where broadband is the bottleneck for booking software or a phone AI receptionist to even work reliably. A 10x capacity jump per satellite eventually shows up as cheaper, more available rural connectivity.

Feature September 23

SoFi moved its entire card program onto stablecoin settlement, live

SoFi took its full debit and credit card program off pilot and onto production stablecoin settlement through Mastercard's network on September 23, projected to process over $25 billion in annualized volume. Settlement runs through SoFiUSD, a bank-issued, dollar-redeemable stablecoin from SoFi Bank; transactions are recorded on-chain, but merchants don't need to hold stablecoins or change anything — funds land in a standard SoFi Bank account with 24/7 no-fee withdrawal. Both companies say cross-border payments and remittances are next.

So what for TSD: This is the exact pain point Nash flagged as a bottleneck in his own payment rail — a real bank-and-network-backed stablecoin settlement product just went live at scale, not as a crypto-native experiment. Nothing to switch to yet since SoFiUSD isn't a merchant-facing product, but it's worth a look in a few months once smaller processors start offering similar rails, since faster settlement with no card-network float would directly help a cash-thin one-person studio.
