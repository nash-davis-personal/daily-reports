◆ Patch this

Security Due Jul 20, 2026

The first scheduled Next.js security release was due today and had not landed when this was filed

Vercel announced on July 13 that it is formalizing a monthly Next.js security-release program, and that the first scheduled release would arrive on July 20 with patch releases for the 16.2 and 15.5 lines fixing 4 high and 5 medium severity vulnerabilities. CVE details are to be published in a follow-up post once the patch is live.

As of filing, nextjs.org/blog still shows the July 13 announcement as the most recent post, and the GitHub releases page shows only v16.3.0-canary.90 (July 20) — a canary, not the security patch. The exact patched version numbers are not yet public. A devops-daily.com article circulating the versions "16.2.6 and 15.5.18" is describing the May 7, 2026 release, not this one.

So what for TSD: Check nextjs.org/blog again before you stop working today. When the post lands, run npm ls next across every client project, upgrade anything on 16.2.x or 15.5.x to the named patch, and redeploy. Four high-severity issues is enough that "I'll do it next sprint" is the wrong call. Do not upgrade to a version number you read in a third-party blog post — take it from Vercel's advisory only.

Supply chain Jul 14–15, 2026

AsyncAPI's npm organization was compromised through its release pipeline

Microsoft Threat Intelligence documented a compromise of four core AsyncAPI GitHub repositories. Five package versions across four package names were republished within roughly 90 minutes, each carrying the same injected loader with import-time payload delivery — meaning the malicious code runs when the package is imported, not just at install.

Separately, jscrambler packages were compromised on July 11 via stolen publishing credentials. Two independent registry compromises inside a week.

So what for TSD: Import-time payloads defeat the "I don't run install scripts" defense. Pin dependencies with a committed lockfile on every client project, and treat any unexplained dependency bump in a PR as suspicious until you've read the diff. If AsyncAPI tooling is anywhere in your stack, check installed versions against Microsoft's advisory. This is also the argument for keeping client dependency trees small — every package you add is a publishing credential you don't control.

◆ Your stack, incrementally better

Platform Jul 17, 2026

Vercel made Sandbox egress free and added cache-reason logs

Data downloaded by Vercel Sandbox is now free. Runtime logs now surface cache reasons, showing why a given response was or was not cached. Vercel also optimized CDN caching and deploys for immutable static assets, and the Chat SDK gained native Slack agent support.

So what for TSD: The cache-reason logs are the practical win. Next time a client says "the site feels slow," you can point at the actual cache decision instead of guessing — that turns a vague complaint into a fixable line item, and it's the kind of thing worth screenshotting into a Managed AI retainer report to make the retainer feel concrete.
Vercel changelog
Platform July 2026

Supabase shipped a TanStack DB sync layer and turned off connection logging by default

@supabase-labs/tanstack-db (alpha) syncs TanStack DB collections with Supabase tables over PostgREST and Realtime. Realtime Broadcast now handles binary payloads. As of July 9, Postgres log_connections defaults to off for new projects, and existing Free and Pro projects are being migrated.

So what for TSD: The log_connections change is the one that could bite. If you have ever debugged a client's connection-pool problem by reading connection logs, that signal is going away on existing projects too. Note it now so you're not confused later. The TanStack DB alpha is worth a look for anything with heavy local state, but alpha means don't put it in a client build yet.
Supabase — July developer update

◆ Business & money

Markets Jul 15, 2026

Anthropic's bankers are scheduling investor meetings ahead of a possible October listing

Goldman Sachs, Morgan Stanley and JPMorgan are lining up investor meetings for what could be an October debut; Anthropic filed its S-1 confidentially in June. The last private round was reported at $65B raised at a $965B valuation, and a trillion-dollar debut is reportedly the banker base case.

Treat the valuation projections as banker talk rather than fact.

So what for TSD: Two effects. An S-1 forces public disclosure of Anthropic's revenue mix and enterprise concentration, which is free market research on what AI buyers actually pay for. And a listed Anthropic means more pressure to monetize the API — worth modeling what a 20% price move in either direction does to your per-client inference cost before you sign anyone to a fixed-price retainer.
