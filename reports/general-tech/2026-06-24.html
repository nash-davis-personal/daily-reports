◆ Security — patch these

Critical CVE-2026-8461 · fixed in FFmpeg 8.1.2 (June 17)

"PixelSmash" turns a single video file into remote code execution

FFmpeg shipped 8.1.2 with an urgent fix for a critical heap out-of-bounds write in its MagicYUV lossless-video decoder, nicknamed PixelSmash and rated CVSS 8.8. Exploitation needs no user interaction — opening a file in VLC, streaming via Jellyfin or Kodi, or merely letting a Linux file manager generate a thumbnail can trigger it. Researchers confirmed crashes against Kodi, mpv, ffmpegthumbnailer, Jellyfin, Emby, Nextcloud, Immich, PhotoPrism, and OBS, and demonstrated full RCE against Jellyfin. The blast radius is huge because FFmpeg is embedded in hundreds of downstream apps.

So what for TSD: Your daily-podcast pipeline shells out to FFmpeg, and so does any image/video tooling you run. Action today: ffmpeg -version on every machine and CI runner that touches media; if it's below 8.1.2, upgrade. On macOS that's brew upgrade ffmpeg. If a build can't be bumped right away, the interim fix is disabling the MagicYUV decoder. Never let an uploaded or untrusted video hit an unpatched FFmpeg.

Memory leak CVE-2026-47729 · disclosed June 23

"Squidbleed" — a 29-year-old proxy bug, found with help from a Claude model

Researchers disclosed Squidbleed, a heap over-read in the Squid proxy that can leak other users' cleartext HTTP requests — credentials, sessions — from shared memory, in the style of Heartbleed. The bug traces to a 1997 FTP-parsing change and is still live in Squid's default config. The notable part for builders: it was surfaced with the aid of Claude Mythos Preview, a concrete example of frontier models finding decades-old vulnerabilities humans missed. The fix landed in the Squid 7.x line; the cleaner mitigation is to turn FTP support off, which most modern networks don't need anyway.

So what for TSD: You almost certainly don't run Squid, so this isn't a patch chore — it's a positioning signal. AI-assisted vulnerability discovery is real now, and it cuts both ways: defenders and attackers both get it. Worth folding an automated security-review pass into your own pre-deploy routine, since the bar for "what a tool can find" just moved.

◆ Chips & hardware

Hardware Computex preview

A 240W PCIe card claims to run 700B-parameter models locally

Taiwan's Skymizer showed the HTX301, a PCIe add-in card with up to 384GB of standard LPDDR4/LPDDR5 memory that claims to run 700B-parameter model inference at roughly 240W — under half the ~600W of an Nvidia RTX PRO 6000 Blackwell or AMD MI350P. It leans on cheap, mature memory and process nodes rather than cutting-edge silicon. Numbers are vendor-stated and unproven in the wild; a fuller preview is due at Computex, where model compatibility and software-stack maturity will get scrutiny.

So what for TSD: If on-prem inference at a power budget a small office can run pans out, it changes the pitch for privacy-sensitive SMB clients — law offices, clinics, anyone who won't send data to a cloud API. Don't build on it yet (vendor claims, no independent benchmarks), but it's a card worth tracking for a future "your data never leaves the building" Managed-AI offer.
