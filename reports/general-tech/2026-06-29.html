Supply chain Attack Jun 24 ◆ reported Jun 26

"Miasma" npm worm poisons 20+ more packages, hunts developer secrets

The self-propagating Miasma campaign claimed new victims late June 24: attackers compromised a maintainer account ("czirker") and pushed poisoned updates into 20-plus packages across the Leo Platform / RStreams ecosystems in a fully automated push reported to finish in under three seconds. The payload scrapes developer secrets and credentials. It follows the @mastra AI-framework compromise (June 17, a typosquat dropper that exposed 1.1M+ weekly downloads) and the earlier Red Hat package hit.

So what for TSD: Action this week. Commit your lockfiles, install with npm ci only (never a bare npm install that floats versions), and be suspicious of brand-new patch releases of transitive dependencies. If Mastra is anywhere in your projects, audit it now. A scraped .env on a client build is your worst-case day.

Carryover Patched May 6–7

No new stack CVE — but the May Next.js upgrade is the real backlog

Nothing new hit Next.js, React, Vercel, Tailwind, or Supabase inside the window. The last big coordinated Next.js/React advisory was patched May 6–7 in 15.5.18 and 16.2.6. Node.js also shipped a multi-line security release June 18 (22.23.0 / 24.17.0 / 26.3.1) covering two HIGH CVEs in WebCrypto and TLS.

So what for TSD: If any client project is still on a pre-May Next.js, you're carrying unpatched advisories — bump to 16.2.6 (or 15.5.18 on the older line) and bump Node to the current patch. Do it between deliveries, not mid-build. And confirm RLS is on for every Supabase project; the "RLS off = public database" mistake keeps burning teams.

◆ What's new on your build stack

Preview Jun 25–26

Next.js 16.3 previews Instant Navigations and a built-in agent toolset

Vercel previewed Next.js 16.3 across two posts. The headline is Instant Navigations + partial prefetching: cache a per-route shell on the client so a click renders instantly while the rest streams in. The other half is an agent layer — version-matched docs via AGENTS.md, first-party Skills, an Agent Browser with React state introspection, actionable errors with paste-ready fix prompts, and a slimmer MCP server. Preview only for now.

So what for TSD: Instant Navigations is a near-free perceived-speed win on the SMB sites you ship — exactly the kind of polish that makes a small-business site feel premium. The agent tooling is built for your Claude Code workflow. Worth a preview branch on one project; don't put it on a client production build until it's stable.

Framework through Jun 2026

TanStack Start keeps surging as the client-first React alternative

TanStack Start — the type-safe, client-first full-stack React framework — is now near 6M weekly npm downloads off its stable 1.x, described as the fastest-growing full-stack JS framework, with roughly 15% React-dev adoption. Its "additive, opt-in server" model is a genuinely different bet from Next.js for app-like, interactive builds.

So what for TSD: Worth a weekend eval for your more app-like client work (dashboards, internal tools). It is not a Next.js replacement for content/SEO sites — keep those on Next. Knowing both lets you pick the right tool per pitch.
