◆ Patch list for your stack

Security Nov 3

Next.js ships seven security fixes in 16.4.5 and 15.5.29

The top issue, rated High by Next.js, can serve one tenant's cached data to another when an app calls the same use cache function directly and through unstable_cache. Other fixes cover cross-user cache poisoning, HttpOnly cookie exposure on Edge routes, shell poisoning and response injection on self-hosted apps, and an SVG bypass in image optimization.

Most of the cache issues need Cache Components. A third-party report says npm's latest tag has since moved to 16.4.6, a bug-fix release.

So what for TSD: Patch instruction: run npm install next@latest on 16.x apps, or npm install next@15.5.29 on 15.5 apps, then redeploy. Confirm the deployed version on each client site, and prioritize anything multi-tenant or using Cache Components.
Next.js security release Report on 16.4.6
Critical Oct 14, CVE Nov 10

The critical React and Next.js RCEs now have public exploit code

Next.js 16.4.1 and 15.5.28 fixed two unauthenticated remote code execution flaws on Oct 14: one in use cache functions returning typed arrays, and one in image optimization with SVG on glibc Linux. The related React flaw received CVE-2026-126187 on Nov 10, with a CVSS of 9.5.

As of a Nov 11 update, neither Vercel nor React had reported exploitation, and public proof-of-concept repositories existed for both Next.js flaws. React describes the trigger conditions as rare.

So what for TSD: Patch instruction: after upgrading, run npm ls sharp react-server-dom-webpack react-server-dom-turbopack. You want sharp 0.35.5 or later and a patched React Flight build. A 15.5 lockfile can keep an old sharp, so check it directly.

Exploited KEV Nov 3

CISA confirms attacks on a WordPress core upgrade flaw

CVE-2026-119977 is a race condition that can let an unauthenticated attacker run code while a full core upgrade is in progress. It affects WordPress 4.7 through 7.1.3, and version 7.1.4 fixes it. Patching does not undo a compromise that already happened.

So what for TSD: If you still manage any WordPress site, update it and run wp core verify-checksums today. Many of your prospects run WordPress, so this is also a timely reason to call them.
