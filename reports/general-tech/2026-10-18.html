◆ TSD's stack

Patch status Oct 14–18

Nothing new to patch; Next.js 15 support ends Wednesday

The last Next.js and React security releases landed October 14 (React Server Components RCE, image optimizer RCE with SVGs, use cache RCE, Server Functions DoS). Nothing new has been published since. Next.js 16.4.2 shipped October 15 as a set of Turbopack and docs backports, and the canary line is at 16.5.0-canary.17 as of October 17. The 15.x line leaves Maintenance LTS on October 21, so future security fixes will skip it.

So what for TSD: Run a final pass on every client repo: confirm production is on 16.4.1 or later (16.4.2 is fine). Any repo on 15.x gets its upgrade merged and deployed by Tuesday night. Don't chase canary.

Database Oct 16

PostgreSQL 19 slips to about November 19 after AI review floods the team with defects

The PostgreSQL Global Development Group pushed v19 GA from late September to around November 19 and reverted 8 to 10 significant features, now slated for v20. Peter Eisentraut said LLM-assisted code review found serious architectural defects in some features plus a long tail of edge cases. SQL Property Graph Queries is the one named casualty. He noted the features weren't written with AI; the AI was used to review them.

So what for TSD: No action for Supabase projects, which run managed Postgres versions and won't jump to 19 for a while. Worth knowing for planning: don't promise a client any v19-only feature this year. The story itself is a good proof point for AI code review on client repos.
The Register
Platform Oct 17

Vercel AI Gateway adds a Sessions view with per-conversation cost and cache hits

AI Gateway logs now group requests into sessions and show cost, models, providers, cache hit rate and which coding agent or app ran each one. Session affinity, on by default for text and chat, sends each turn to the provider that served the last one so more of the prompt stays cached. Apps can group requests themselves by sending a sessionId or x-session-id header. Vercel also added DeepSeek V4.1-Flash-1017 to the Gateway the same day.

So what for TSD: If client chatbots or the RAG concierge route through AI Gateway, pass a session ID per visitor conversation. You get per-conversation cost, which is the number you need to price usage-based retainers honestly.

◆ Security

Exploited Reported Oct 14–17

Nextcloud's built-in Collabora server is being used to plant web shells

CVE-2026-110447 (CVSS 9.2) is an unauthenticated flaw in richdocumentscode, the built-in CODE Server app for Collabora Online in Nextcloud, versions 26.4.302 and earlier. The fix, 26.4.303, shipped September 11; public reports of active exploitation surfaced October 14 to 17. Standalone Collabora, Docker, package installs and Nextcloud AIO are reported unaffected. Disabling the app is not enough; it must be updated or removed, and patched servers should be checked for leftover PHP files, new admin accounts and scheduled tasks created after September 11.

So what for TSD: If any client self-hosts Nextcloud for file sharing (common at small law, accounting and medical offices), check the app version this week. It's a small paid fix and a reason to ask what else they host.
Tech Insider

◆ Chips, power and permits

Infrastructure Oct 16–18

San Francisco pauses data centers; Microsoft walks from a UK site with no grid power until the 2030s

Mayor Daniel Lurie signed a 45-day citywide moratorium on new data center development on October 16 after a unanimous Board of Supervisors vote. The Planning Department must study impacts and draft controls; the pause could extend to about 22 months. On October 18 the Telegraph reported Microsoft withdrew from anchoring Nscale's Loughton, Essex site, planned for about 23,000 Nvidia chips, after UK Power Networks said grid capacity won't arrive until the early-to-mid 2030s. The FT counted 47 or more large US projects delayed, withdrawn or blocked this year.

So what for TSD: Compute supply stays tight, which keeps frontier API prices from falling as fast as the hype suggests. Build client products so the model can be swapped, and price AI retainers with room for cost swings.
SF Standard Telegraph FT
Trade Oct 16

Taiwan moves to make AI chip smuggling to China a crime

Economic Affairs Minister Kung Ming-hsin confirmed that AI servers and advanced chips will become controlled commodities, with unauthorized shipments to any Chinese buyer treated as a criminal offense under the Foreign Trade Act. Today's rules require permits only for named firms like Huawei and SMIC. A legislator has drafted the amendment. Taiwan made its first smuggling arrests in May.

So what for TSD: No direct impact on TSD. It's one more reason Chinese open-weight models keep getting more efficient per chip, which is why cheap options like DeepSeek keep showing up on AI Gateway.
Startup Fortune (citing Bloomberg)
