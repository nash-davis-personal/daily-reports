Critical CVE-2026-15748

Forminator Forms lets an unauthenticated attacker upload a PHP file

Forminator Forms, the wpmudev contact/payment/custom form builder with more than 600,000 active installs, carries an unrestricted file upload in its handle_file_upload function. File-type validation is insufficient, so an unauthenticated attacker can upload an executable file and get code execution. It is rated CVSS 9.8 and affects every version up to and including 1.56.1. The fix, 1.56.2, shipped July 31, 2026. Exploitation requires the site to have a form containing both a File Upload field and a Select field, which is a common combination on a quote-request form.

The gap between the patch and the attention is the problem: SecurityWeek estimated more than 300,000 sites were still on a vulnerable release when the issue got wide coverage this week.

So what for TSD: Do this before anything else today. For every WordPress site you touch, host or inherited during a rebuild, check the Forminator version and get it to 1.56.2 or later. If a site is vulnerable, updating is not the whole job — assume upload and check wp-content/uploads for stray PHP files before you call it clean. This is also the cleanest cold-outreach line Grant and Bishop have had in weeks: a Charlotte SMB running an unpatched quote form is one scan away from a defaced site, and a paid audit-and-migrate off WordPress is exactly the conversation you want to be in.

Critical Aug 17, 2026

GitLab patched a GraphQL flaw that lets anonymous attackers delete projects

GitLab released an out-of-band security update on August 17, outside its normal twice-monthly cadence, for CVE-2026-19478. A code-injection issue in a GraphQL directive lets an unauthenticated attacker remotely modify or delete public projects and user data under certain conditions. CVSS 9.4, remote, low attack complexity, no privileges, no user interaction. Patched versions are 19.2.4, 19.1.6, 19.0.8 and 18.11.11; every self-managed CE and EE release from 18.2 up to those versions is affected. The same release fixed CVE-2026-19650, a CVSS 7.1 CSRF in the GraphQL multiplex query handler that could let an unauthenticated attacker run mutations through GET requests.

GitLab.com and GitLab Dedicated already run patched builds, so SaaS users have nothing to do.

So what for TSD: You're on GitHub, so this is not your emergency. It is worth knowing for one reason: if a prospect or a client's internal IT runs self-managed GitLab, mentioning this by CVE on a call is a thirty-second credibility deposit that costs you nothing.

Vercel shipped Slack, a Microsoft connector, Algolia and free audio models

Five things landed on the Vercel changelog Wednesday. Vercel for Slack entered public beta, covering collaborative coding, production investigations and secure remediation actions from inside Slack. Vercel Connect added a managed connector for Microsoft that registers a Microsoft Entra app automatically and mints delegated and application tokens. So what for TSD: Two immediate uses. And free speech-to-text on the AI Gateway for 30 days is a real window: run TSD Front Desk's transcription through Fish Audio behind the Gateway, measure word error rate against your current path on actual Charlotte accents and shop-floor background noise, and you will know whether your voice margin can improve without a provider contract.

◆ Power and photons for the buildout

New Aug 19, 2026

TerraPower's reactor handles spiky AI load with a tank of molten sodium

TerraPower's Natrium design is a 345-megawatt molten-salt-cooled reactor, and its pitch for data centers is a storage trick rather than a reactor trick. US reactors run at maximum output about 92.5% of the time and can only adjust roughly 5% per minute, which is a poor match for AI training loads that slam up and down. Instead of throttling, Natrium keeps generating flat out and dumps surplus heat into a large vat of molten sodium, then pulls that heat back to raise extra steam when demand spikes. The expensive equipment stays busy during the troughs.

The first reactor is under construction in Wyoming and a second plant is expected to break ground in 2027. Meta agreed in January to buy eight Natrium plants. TerraPower says it will announce its first dedicated data-center project this year, customer unnamed.

So what for TSD: No direct action, but it's the strongest tell yet on where inference prices go. Utilities and hyperscalers are solving load-following with thermal storage, which is a long, capital-heavy fix — meaning per-token costs have a floor set by physics and permitting, not by model efficiency alone. Price your Managed AI retainers with a usage band and a stated overage rate rather than flat unlimited.

New Aug 19, 2026

Relativity Networks raised $22M to send data through vacuum instead of glass

Relativity Networks closed $22 million on SAFE notes led by Rhapsody Venture Partners, Bell Ventures and Faster Than Glass LLC, alongside a $40 million follow-on order from an unnamed hyperscaler. Its hollow-core fiber carries light through a vacuum channel rather than solid glass, cutting transit from roughly 5 microseconds per kilometer to 3.5 and pushing closer to the speed-of-light limit. CEO Jason Eichenholz frames the payoff as geography: a campus can spread about 50% further before latency becomes the binding constraint, which is what multi-site AI training needs.

So what for TSD: Nothing to build on. File it under the same heading as the reactor story — the AI buildout's remaining bottlenecks are electricity and the speed of light, and both are getting priced in.
