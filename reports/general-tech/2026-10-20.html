SecurityOct 14 / Oct 16

Next.js: be on 16.4.1 or later (15.5.28 on the 15.x line); 16.4.2 is the new LTS

The Oct 14 out-of-band release fixed three issues: a critical unauthenticated RCE in `use cache` functions that return typed arrays (GHSA-673q-mjm6-r5xr, no workaround), a critical image-optimization RCE through an upstream library on untrusted SVGs (GHSA-2464-fhr4-w9xw), and a high-severity Server Actions DoS (GHSA-p3m5-59mp-jv5r). Vercel reports no in-the-wild exploitation. Next.js 16.4.2 followed on Oct 16 with Turbopack module-resolution and chunk-collision fixes. Yesterday's edition reported that 15.x support ends this Wednesday (Oct 21); see the link to that edition below.

So what for TSD: Patch instruction: bump every Next.js client site to 16.4.1+ (15.5.28 if you must stay on 15.x), redeploy, and confirm the version in the build log. Prioritize sites that use `use cache`, Server Actions, or `next/image`/`next/og` with user-supplied SVGs. Then plan the 16.x move before 15.x support ends.

SupabaseOct 5 – Oct 12

Supabase: TLS cipher retirement Nov 10, adapter removal Dec 1, scoped tokens now GA

Supabase will retire four TLS 1.2 CBC cipher suites on its HTTP APIs (Auth, Data API, Storage, Realtime, Edge Functions) starting Nov 10 at the earliest; TLS 1.3 is unchanged and direct Postgres, poolers and the Management API are not affected. Fewer than 0.0001% of recent connections used them. Separately, the Hono, H3, Elysia and NestJS adapters in @supabase/server are removed Dec 1. Scoped personal access tokens went GA Oct 6, and OrioleDB is in public beta on paid plans (no SLA, not for production).

So what for TSD: Modern browsers and Node versions already speak TLS 1.3, so most client sites are fine. Check anything old that calls a Supabase API (legacy kiosks, old POS or IoT boxes). Swap your CLI and CI personal access tokens for scoped ones this week.

VercelOct 16–17

Vercel AI Gateway shows per-session cost, and adds DeepSeek V4.1 Flash

AI Gateway request logs are now grouped into sessions showing cache hit rate, cost, turns and the coding agent per conversation. DeepSeek V4.1 Flash (1017) is available with image input, spend tracking and request traces. Turborepo 2.11.9 added `turbo exec` and faster cache and lockfile handling.

So what for TSD: Route client AI features through the Gateway so you can show a client exactly what each conversation cost. That feeds a usage-based retainer and gives you an early warning when Gemini 4 Argon's price steps up Dec 1.
