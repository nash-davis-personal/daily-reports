◆ Your stack

Security Checked Nov 23

No new advisory for Next.js, React, Tailwind or Supabase over the weekend

I checked the Next.js releases page, the React and Tailwind release pages, the Supabase changelog and Vercel's security bulletins this morning. The newest stable Next.js is still 16.4.6 from Nov 9 to 10. React's newest is 19.3.1 from Oct 14, Tailwind's is 4.3.5 from Nov 6, and Supabase's latest changelog entry is custom OIDC providers on Nov 17. Vercel's newest bulletin is the Better Auth release from Nov 3.

One small flag: Vercel's Workflow kit 4.8.17, dated Nov 20, bumps undici to 7.30.2 and zod to 4.6.7 to pick up security fixes. No CVE numbers are listed.

So what for TSD: If every client site is already on Next.js 16.4.5 or later, or 15.5.29 or later, you have nothing to do today. If any site still sits below those, patch it first, because public exploit code for the older React and Next.js flaws was reported last edition.

Vercel Nov 20

Vercel Functions now accept request bodies up to 20MiB

The old ceiling was 4.5MB. The new limit is in public beta. You opt in with the environment variable VERCEL_SUPPORT_LARGE_REQUEST_BODY=1, and the project's functions must use the 4GB performance memory setting. It covers the Node.js, Python and Bun runtimes and Routing Middleware. The Edge runtime keeps the 4.5MB cap and returns a 413 error above it.

So what for TSD: A quote form that takes a few phone photos can now post straight to a function with no signed-upload step. Keep direct-to-Supabase-Storage uploads for anything larger or for clients on small plans, since the 4GB setting costs more per invocation.
Vercel changelog
Vercel and Next.js Nov 22 to 23

A deploy check for missing feature flags, and a safer image optimizer in Next.js canary

Vercel added a Deployment Check on Nov 23 that fails a production deploy when a flag is declared in code and missing from the project. It needs FLAGS_SECRET set and is available on all plans. Next.js 16.5.0-canary.61, published Nov 22, adds experimental support for a package named @next/safe-image-optimization and recovers from an unreadable Turbopack cache at startup.

So what for TSD: Skip the canary on client work. The flag check is worth turning on only for projects that already use Vercel Flags.

◆ Security and big tech

M&A Nov 23

CrowdStrike agrees to buy Zscaler in an all-stock deal near $43.9 billion

Reuters reported the agreement this morning. It follows Palo Alto Networks' Nov 18 agreement to buy Applied Compute, a platform for running open-weight AI models, for $4.5 billion in stock. Security vendors are merging endpoint, network and AI tooling under fewer roofs.

So what for TSD: Your SMB clients do not buy either product. The useful takeaway is that larger customers will soon ask any vendor, including a web studio, how its AI features are secured. Have a one-page answer.
Reuters via WHTC Palo Alto Networks release
Chips Nov 23

US intelligence chief confirms an investigation tied to Nvidia chip exports

CNBC reports that Director of National Intelligence Jay Clayton said the US is investigating Megaspeed, a Singapore data center operator, and a former executive there. The Commerce and Justice departments said the probe began in 2024 over possible export-control violations. Megaspeed says it operates lawfully. No wrongdoing has been established.

House committees have scheduled closed-door interviews with Jensen Huang, whom CNBC describes as Nvidia's former chief executive, and general counsel Tim Teter for Dec 1 and 2. Reuters lists his abrupt departure among last week's pressures on the stock. Nvidia shares were up about 8.7% in premarket trading after a 14% drop on Friday.

So what for TSD: No direct effect on your work. It is one more reason GPU supply and pricing may stay unsettled into 2027, which feeds the cost point in today's AI brief.
CNBC Reuters via WHTC
Breach Nov 20, updated Nov 23

GL.iNet says attackers used its cloud management service to plant malware on routers and KVM devices

The company has blocked the cloud attack path, and it says that step does not clean devices already infected. Owners need the security firmware: 4.11.1 or later on models including the GL-MT3000 and GL-MT6000, and 1.10.3 or later on its KVM line. The notice gives a process string to look for, crond -i /tmp/.log.

So what for TSD: These travel routers are common with remote workers and small offices. If you or a client runs one, update the firmware today, then change any password that crossed it.
