◆ Anthropic ships the "managed Claude" layer

New Jun 18

Enterprise-managed MCP connectors, starting with Okta

Organizations can now provision MCP connectors through an identity provider so end users get connectors wired up automatically on first login — centralized authorization across Claude chat, Claude Code, and Cowork on Team and Enterprise plans. The same day, Anthropic moved Workload Identity Federation to general availability: keyless, OIDC-based auth across API endpoints, SDKs, and Claude Code, with service-account and Admin API support.

So what for TSD: This is how Claude becomes a "managed AI" a client's IT can trust. When you sell a Managed AI retainer, "your team gets zero-touch, keyless access we provision once" is a real enterprise selling point — and WIF means you can stop shipping long-lived API keys in client deployments.

Feature Jun 18

Artifacts land in Claude Code

Claude Code can now turn session work into live, shareable visual pages — PR walkthroughs, dashboards, incident pages — that update automatically and keep version history. In beta for Team and Enterprise. Claude Design also picked up /design-sync, direct canvas editing, and connectors for Adobe, Canva, and Vercel.

So what for TSD: A built-in way to hand clients a polished artifact out of a build session instead of a Loom and a paragraph. Use Artifacts to ship "here's exactly what changed and why" pages with deliverables — it raises perceived value at zero extra effort.

◆ The agent-tooling race

New Jun 2026

OpenAI ships AgentKit; Google's I/O stack targets builders

OpenAI released AgentKit — a set of tools to build, deploy, and optimize agents — alongside its Agents SDK orchestration framework. Google's I/O builder lineup includes Jules (an async coding agent competing with Claude Code and Codex), ADK 1.0, Veo 3 in the Gemini API, and a preview of a next-gen Gemini with a 2M-token context window.

So what for TSD: Every major lab now hands you agent scaffolding for free, which commoditizes "we built an agent." Your moat isn't the framework — it's the wedge: a specific SMB workflow (front desk, concierge, booking) wired to a real business with citations and a money-back guarantee. Keep selling the outcome, not the plumbing.

◆ Price pressure from open weights

Context Jun 16

GLM-5.2 vs Claude Opus 4.8: cheaper vs better

A published head-to-head puts open-weight GLM-5.2 well under Claude Opus 4.8 on price while Opus still leads most performance categories. The open-weight tier keeps closing the gap on "good enough" tasks.

So what for TSD: For high-stakes client-facing work (a concierge that quotes prices, a receptionist that books jobs), stay on the model that's right — a wrong answer costs a client. But for internal batch jobs (summarizing, drafting, classifying corpora), a cheaper model can cut your own COGS. Route by stakes, not by habit.
