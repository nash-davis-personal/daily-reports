◆ Claude and your daily tools

Policy Reported Oct 31

Anthropic confirms a Claude Code rule against recreating someone else's specific game

After developers reported refusals, an Anthropic spokesperson pointed reporters to a statement from Anthropic's Addy Osmani: two sentences were added to Claude Code's prompt on Opus 5.5 "to steer it away from recreating someone else's specific game." Original games, genre games and games built from a user's own designs are meant to keep working. Renaming a copy reportedly doesn't get around it, and the rule runs on Anthropic's side, so there is nothing local to change.

Developers also report refusals on crash-dump analysis, anti-cheat and other reverse-engineering work. Anthropic has not confirmed that those come from this rule. Osmani reportedly asked people to report cases where Claude refuses work on projects they own. Tom's Hardware first wrote up the reports before Anthropic responded.

So what for TSD: Client sites and AI products are original work, so day-to-day delivery shouldn't change. Where you'll feel it is a brief like "make it work like competitor X." Write prompts around the client's own brand, content and requirements, and if Claude refuses legitimate work on a client's own codebase, send that refusal to Anthropic. They asked for those reports.
WindowsForum (Oct 31) · Tom's Hardware · Tech Insider (unconfirmed claims)
SDK v3.42.0 · Oct 31

OpenAI's Python SDK adds agent compaction settings and keypad-tone commands for phone calls

Release 3.42.0 adds settings for agent context compaction, agent session review and tool settings, experimental agent "time awareness," SIP DTMF commands and delivery events (the keypad tones behind "press 1 for…"), better WebSocket recovery, and markup overlays for image edits.

So what for TSD: DTMF support in a major SDK means phone agents that can send and hear keypad presses are now standard plumbing. That matters for Front Desk: it can navigate a client's existing phone tree or hand callers a "press 1 to book" fallback. Compare it with what Vapi already exposes before switching anything.

◆ Security

Fixed Oct 31

A shared ChatGPT link could run attacker code in a logged-in session

Researchers at Parameter chained three pieces: a MathLive message listener that accepted messages from any sender, a YouTube-hosted script the content security policy allowed, and a Preview feature. The result could read private conversations. It was reported Oct 18 and fixed by Oct 26, with a $5,000 bounty. Parameter reported no exploitation in the wild, and users don't need to do anything.

So what for TSD: Concierge is an embedded widget too. Make sure every message listener in it checks event.origin, and keep your CSP script allowlist short. A trusted big-name host on that list was one link in this chain.
The Hacker News (Oct 31)
