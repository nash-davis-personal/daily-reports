◆ The phone-agent stack got cheaper and more managed

New September 10

GPT-Live-1 arrives in the API at $0.05 a minute

GPT-Live-1 is OpenAI's full-duplex voice model, now available to developers. Full duplex means it keeps listening while it talks: a caller can cut in mid-sentence and the reply stops and adapts, and the model can pause or call a tool in the middle of the exchange. It launches with 12 voices across accents and languages, with custom voices through sales. Concurrency scales with spend tier, from 25 simultaneous sessions on Tier 1 to 500 on Tier 5.

The $0.05 per minute covers the voice front end only. Any backend model, tool or service the conversation reaches is billed separately, so the all-in number depends on what the agent does behind the voice. For comparison, independent pricing breakdowns this year put all-in AI receptionist costs at roughly $0.09 to $0.36 a minute across the major voice platforms once speech, model, voice and telephony are stacked.

So what for TSD: This is a new benchmark for TSD Front Desk's cost of goods, and possibly a simpler architecture. Before Monday, stand up one test line on GPT-Live-1 alongside the current Front Desk build and run the same ten scripted calls through both: a caller who interrupts, a caller who changes the appointment time halfway through, a caller with background noise. Log latency, how often it talks over people, and the true per-minute cost including telephony and the backend model. Coverage describes telephony support; confirm the exact SIP or phone path in OpenAI's docs before you promise a client anything. If it wins on interruption handling, that is the feature an HVAC owner notices on the first call.

Platform September 10

The Agents API puts OpenAI's managed Codex harness behind one call

OpenAI opened the Agents API as a public beta for all developers. It exposes the same harness that runs Codex: the loop that coordinates model calls, tools and context, lets a main agent split work across subagents with separate context, and compacts earlier context automatically in long sessions. The harness is built on the open-source Codex codebase, so the orchestration logic is readable. It supports MCP servers, custom functions and built-in tools such as web search, and loads tool definitions only when they are needed.

Execution runs in an OpenAI-hosted sandbox, on your own infrastructure through codex exec-server, or in one of nine partner sandboxes: Blaxel, Cloudflare, Daytona, DigitalOcean, E2B, Modal, Oracle, Runloop and Vercel. There is no separate fee; you pay for tokens, tools and container time. Vercel published a same-day guide for running Agents API apps on Next.js, Functions, Queues and Sandbox.

So what for TSD: The orchestration you would otherwise hand-build for a long-running client agent, like a Booking Bridge flow that checks availability, holds a slot, texts the customer and waits for a reply, is now a managed service on a platform you already deploy to. The trade is lock-in. Keep every client tool behind your own MCP server so the same tools work under the Agents API or the Claude Agent SDK, and choose the model per job. Run one internal prototype on Vercel Sandbox this month so you know the shape before a client asks for it.

◆ Coding got cheaper and math got stranger

Model September 10

Cognition's SWE-2 lands within a point of Fable 5.1 on coding

Cognition released SWE-2, post-trained from Moonshot's Kimi K3 with reinforcement learning that trains medium, high and max effort levels in one run. It scores 50.0% on FrontierCode 1.1 Main, about a point behind Anthropic's Fable 5.1, and Cognition says it costs 64% less to run at that score. It also beats xAI's Grok 4.6 and comes within a few points of GPT-6 Astra at roughly a quarter of the price. It is live in Devin Desktop and the Devin CLI and rolling out to Devin Web. Cognition has not published a per-token price.

The same day, reporting on Cognition's finances put Devin near $900M in annualized revenue with gross margins around 50%. A frontier-adjacent coding model built on a Chinese open-weight base is how Cognition protects that margin.

So what for TSD: The cost of a competent second coding agent keeps falling, and the benchmark numbers are Cognition's own until independent runs land. Do not re-tool mid-semester. Give SWE-2 one real, bounded ticket from a client build, such as a form refactor with tests, and compare its diff and time against what you ship with Claude Code today. If it holds, it becomes a cheap reviewer on low-risk work.

Research September 8

OpenAI published a Navier-Stokes blowup proof, and a priority fight came with it

OpenAI released a 165-page proof, with a Lean formalization that machine-checks each step, showing finite-time blowup in the three-dimensional Navier-Stokes equations: a configuration where a vortex tightens and spins faster without limit while the fluid's energy stays bounded. The Wall Street Journal reported the work used up to 10,000 agents in parallel over about 88 hours, on an unreleased model OpenAI describes as significantly more capable than GPT-6 Astra, at a compute cost in the millions of dollars. OpenAI says it will not claim the $1M Millennium Prize.

Two caveats matter. The result includes a smooth forcing term, so it does not settle the Millennium Problem in its classic form. And NYU mathematician Tristan Buckmaster suggested the system may have drawn on private research stored in Codex; OpenAI says the related work addressed the forced Euler equations, a distinct problem, and now credits it as concurrent. Epoch AI separately reported that every Tier 4 FrontierMath problem has now been solved.

So what for TSD: Nothing to build this week, but the method is the lesson. The headline result is trustworthy to the degree a checker verified it, and the checker was Lean. Apply the same rule to agent output in client work: generated code is accepted when tests and type checks pass, and never on the strength of a confident summary. The privacy question in the Buckmaster episode is also worth one sentence in your client contracts about which AI tools can see their data.

◆ Ads, audits and distillation

Business September 10

Amazon is selling ChatGPT ad space to its own advertisers

Amazon announced a U.S. pilot that lets select advertisers extend Amazon DSP campaigns into ChatGPT. Amazon sets up and manages the campaigns; OpenAI's ad system decides which eligible ads show and where. Placements are labeled text or image units beneath ChatGPT's answers and are kept out of the answer itself. CNBC reports OpenAI's ad business recently reached a $1B annualized run rate, and Delta Vacations is among the first participants. Amazon had been the leading retail advertiser on ChatGPT from April through August, per Sensor Tower data cited by CNBC.

So what for TSD: Your clients will start asking whether they should advertise in ChatGPT, and OpenAI's self-serve Ads Manager has been open to U.S. businesses since May. Have a real answer ready: pick one client with a clear local offer, run a small capped test, and measure booked calls against what the same budget does on Google. A measured result from a Charlotte business is worth more in a sales conversation than any article on the topic.

Policy September 9

California created the first U.S. framework for auditing AI systems

Governor Newsom signed SB 813 and AB 1405. SB 813 sets up independent verification organizations that can assess AI systems for compliance with state law and creates a California Artificial Intelligence Standards and Safety Commission to write voluntary safety standards. AB 1405 creates a state registry for AI auditors with independence rules modeled on accounting; starting in 2029, no one can conduct a covered AI audit in California without registering. Coverage notes frontier labs and AI hiring tools fall in scope.

So what for TSD: Your clients are in North Carolina, so nothing binds you today. The direction is still clear: AI that screens people, especially job applicants, is heading toward mandatory third-party audits. Stay out of hiring-screening builds for SMB clients unless the client carries the compliance work, and keep writing down what each deployed agent can touch, since that document is what any future auditor asks for first.

Security September 8

NSA, FBI and CISA named six Chinese AI firms in a distillation advisory

A joint advisory, AA26-251A, says China-based AI companies have run industrial-scale knowledge distillation against U.S. frontier models since at least late 2024, pulling billions of tokens across millions of queries from Claude, GPT, Gemini and Grok. It names DeepSeek, Moonshot AI, Alibaba, MiniMax, StepFun and Z.AI, describes distillation as the core of their development strategy, and says the campaigns likely ran with the Chinese government's knowledge. China rejected the accusations and warned of possible retaliation, per the South China Morning Post.

So what for TSD: This lands one day after yesterday's brief suggested testing DeepSeek V4.1 Flash for Concierge margins. The test is still worth running, with one rule: use the open weights through a U.S.-hosted provider, confirm which provider actually serves the model behind AI Gateway, and send no client personal data to a China-hosted endpoint. If federal restrictions follow this advisory, a client build wired to DeepSeek's first-party API turns into a migration you do for free.
