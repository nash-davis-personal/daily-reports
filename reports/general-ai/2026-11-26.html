◆ What AI costs to run

Limits Nov 26

OpenAI fixes a GPT-6.2 billing error, so ChatGPT usage caps arrive sooner

GPT-6.2 Sol began rolling out to paid ChatGPT tiers (Plus, Pro, Business, Enterprise) this week, with older GPT-5.6 models retiring in December. Notebookcheck reports that a billing error at launch had discounted Astra and Sol usage against plan limits. With the fix, users hit caps up to 40% sooner on Astra and 25% sooner on Sol, and OpenAI granted a one-time reset. Only one outlet has reported the cap numbers so far.

So what for TSD: Clients running staff on ChatGPT seats will feel this as "it stopped working mid-afternoon." That is a clean opening to pitch API-based tools with a fixed monthly budget, which TSD controls and can cap.
Notebookcheck India Today (rollout)
Engineering Nov 25

Anthropic rewrites its Messages API from Python to Rust, with Claude agents doing much of the work

Anthropic published a post-mortem on moving the Messages API to Rust. Agents ported code and ran the new service in production shadow mode, comparing its outputs against the Python version before cutover. Anthropic reports about 70% less CPU per request, more than 80% less memory, and roughly 20% faster median time to first token. These are the vendor's own numbers.

So what for TSD: Shadow mode is the safe way to let agents migrate a client's legacy site or backend: run the new version beside the old one and diff the results before switching. Borrow the method for the next WordPress or PHP rebuild quote.
Anthropic
Alpha Nov 25

OpenAI starts an alpha of Private Inference for API prompts

Sam Altman announced an alpha test that processes API prompts inside hardware enclaves, so the prompt is shielded from the operator during inference. Details on pricing, models and general availability were not given. Coverage is thin and secondhand so far.

So what for TSD: Nothing to build on yet. File it with Vercel's audited zero-retention tier from yesterday: both point to a "private AI" tier medical, dental and legal clients will ask about in 2027.
Sulat

◆ Chips and supply

Policy Nov 25–26

Nvidia halts server shipments to four Southeast Asian countries as the remote-access rule takes hold

Commerce's interim final rule on remote access to advanced chips, issued Nov 16, adds license requirements for data centers anywhere that sell meaningful compute to China-headquartered firms, and new license needs for Indonesia, Malaysia, Singapore, Thailand and Brazil. The National reports Nvidia has stopped shipments to Malaysia, Singapore, Thailand and Indonesia while licenses are sorted out. CBS separately reported Chinese-linked firms leasing B300 servers through partners in the region. Congress has Nvidia's Jensen Huang scheduled to testify Dec 1 and Dec 3.

So what for TSD: No direct effect on Claude or OpenAI API prices this week. The thing to watch is whether tighter chip supply shows up as rate limits or price changes from the labs in December.
The National Sidley (rule summary) CBS

◆ Research claims and trust

Research Nov 25

Google posts six math papers produced with Gemini 4-based agents

Google's "Cogentic" papers include a claimed subexponential factoring algorithm and a claimed break of the square-root barrier for the log-rank conjecture. Lean 4 formal proofs are promised; peer review is pending. This lands a day after OpenAI's unreviewed matrix-multiplication preprint, and Scott Aaronson posted a skeptical note about lab "bombshells" that can't yet be checked.

So what for TSD: No business impact until a proof is verified. Do not cite either lab's math claims in client pitches.
OfficeChai Scott Aaronson
Trust Nov 25–26

Apple pulls MiniMax's Talkie, and a researcher says MiniMax user links were exposed

Apple removed Talkie, a MiniMax companion chatbot with about 11 million monthly users, from the global App Store after a child-safety investigation. Separately, Reuters reports Dragos researcher HD Moore found that unidentified parties accessed confidential MiniMax user links from July to November. OpenRouter removed three providers in response.

So what for TSD: If any TSD build routes through OpenRouter, check which providers it can fall back to and pin the allowed list. Cheap open models served by unknown hosts are a data-handling risk for client data.
9to5Mac Reuters
