◆ Agents met the commercial world, and the commercial world said no

Breaking September 20–21

Amazon cut off Meta's Muse agent from buying

Amazon started blocking Meta's Muse assistant from making purchases on Amazon.com on the night of September 20, showing a Conditions-of-Use popup when the agent tries. That killed one of Muse's headline features twelve days after launch. Amazon's stated objections are specific: Meta never told it that Muse would browse the store, the agent does not identify itself when it does, and it appears to capture and store customer login credentials. Amazon says it asked Meta to leave Amazon.com out of the Muse experience and was refused.

Meta's response is that Muse "has no visibility into people's passwords or payment methods," and that credentials a user hands over "go into secure storage, so Muse can use them without seeing them." The awkward part is the commercial backdrop — Amazon products have been purchasable inside Facebook and Instagram since 2023, and Meta signed a multibillion-dollar deal in April to run agentic AI workloads on Amazon's cloud.

So what for TSD: Any agent feature that works by logging in as the user is a business-model risk, not just a security one — the site on the other end can revoke it overnight. Build client agents against APIs, webhooks and MCP servers you have permission to call, and when a client asks for "an AI that just buys/books it for me," price the integration work rather than promising browser automation that a vendor can block in a night.

Privacy September 20–21

OpenAI's __obi cookie follows ChatGPT accounts onto retail sites

Researcher Buchodi documented the mechanism end to end: a signed JWT issued by ChatGPT's backend is sent cross-site to bzr.openai.com, which sets a __obi cookie on .openai.com with SameSite=None and a one-year lifetime. Once the tag loads on a merchant site it reports the page being viewed, the product being searched and recent order data back to OpenAI. The investigation reproduced it on mobile and observed it firing on Chewy, Wayfair, ThriftBooks, Eventbrite, HelloFresh, Coursera and SeatGeek.

OpenAI's own cookie policy, updated September 10, lists __obi as an analytics cookie rather than an advertising one, which is the crux of the complaint: a user who turns off ad personalization still gets it. Findings were sent to OpenAI on September 14; support acknowledged the inquiry and said it would be reviewed internally, and the classification question went unanswered.

So what for TSD: Go look at what marketing tags your client sites actually load. If an OpenAI ads pixel got added by a client's agency or a Shopify app, it belongs in the cookie banner and privacy policy as advertising, whatever the vendor's own policy calls it. That is a billable 60-minute tag audit you can offer every existing client this week, and it is the kind of thing that makes a retainer feel cheap.

◆ The runtime layer is being poured in public

Release September 20–21

Google's AX orchestrator reached v0.3.0

AX — Agent Executor, Google's open agentic orchestrator — shipped v0.3.0, splitting the orchestrator into three services and moving task state out of Kubernetes custom resources into Redis Streams. The point of that change is throughput: custom resources are a terrible place to keep millions of short-lived tasks, Redis Streams is not. AX models agents as stateful graphs with explicit transitions, retries and checkpoints, keeps the orchestrator itself stateless, and pushes state into Redis, Postgres or GCS so it scales horizontally under Docker Compose or Kubernetes.

It is still early. Google is explicit that architecture and runtime are subject to change and that future versions will likely break compatibility with earlier ones.

So what for TSD: Worth reading, not worth adopting yet — pinning a client deployment to a pre-1.0 runtime that promises breaking changes is how you inherit unpaid migration work. But the design is the tell for where durable agents are heading: resumable graph state in Redis/Postgres. Nash already has Supabase Postgres in every project, so the same pattern (checkpointed agent runs in a table, orchestrator stateless on Vercel) is buildable now without the dependency.

Platform September 18–20

Huawei opened an Ascend-to-agent stack with a 5,000-asset MCP catalog

At HUAWEI CONNECT 2026, Huawei Cloud laid out a silicon-to-agent stack on Ascend hardware. openEuler contributed ThinkProcess ("ThinkPro") as the atomic unit of agent thinking and execution, with atomic-level APIs abstracting state management and hardware resources. Around it sits an Apache-2.0 core SDK with Python and Java kits, a distributed runtime, visual tooling, long-term memory components, and support for MCP and agent-to-agent protocols. The catalog carries more than 5,000 general MCP assets and more than 1,000 industry-specific ones. AICS, the managed cluster service, opens in China on September 30, with US and rest-of-world availability staggered through November and December.

So what for TSD: The detail that matters outside China is MCP's win. A Chinese silicon vendor building its entire agent story on the same protocol Anthropic published means MCP servers Nash writes for a client are a durable asset, not a Claude-specific one. Keep shipping integrations as MCP servers rather than bespoke function-calling glue.

◆ AI is now a measurable share of the world's code

Data September 21

AI-written code hit 17.25% of Linux kernel patches this month

The Lunduke Journal's running count puts AI-generated code at 17.25% of all Linux kernel patches so far in September, on a record 1,634 AI-authored submissions in a single week — more than 2,000 in the last 45 days. The kernel's AI commit-credit convention is what makes this countable at all, which is the useful part: this is a measured share, not a survey of what developers say they do.

The other side of the same trend is less cheerful. Tom's Hardware reports the kernel approaching 2,000 CVEs per release as AI bug hunters sweep 40 million lines of code, with maintainers describing themselves as completely overwhelmed by the volume of finds.

So what for TSD: Use the number in sales conversations — "a sixth of the Linux kernel's patches this month were written by AI" lands harder with a skeptical 55-year-old business owner than any benchmark chart. And take the maintainer half seriously in delivery: AI raises the volume of both code and findings, so the bottleneck in Nash's shop is review throughput, which is exactly what a second agent pass plus a short human checklist is for.
