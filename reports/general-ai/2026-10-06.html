◆ Agents & platforms

LaunchSept. 29

OpenAI DevDay: always-on agents on cloud computers

OpenAI launched "Dots," always-on agents that run on dedicated cloud computers with a browser and 4,000+ app integrations, plus a public preview of an Agents API with computer-use support and a $500/month "Pro 500" tier with faster inference. These details come from a newsletter summary of DevDay coverage; I did not open the primary OpenAI post, so check pricing and availability there.

So what for TSD: Clients will ask whether a hosted agent replaces what TSD sells. The answer to give: a per-client agent wired to their booking, CRM and phone, with source code they own. Keep a one-page comparison ready.

◆ Models & price

ModelOct. 4 per tracker; API Sept. 10 per other sources

DeepSeek V4.1 Flash: cheap, agent-capable

DeepSeek lists $0.15 per million uncached input tokens and $0.60 output off-peak, doubling at peak hours. Vendor-reported scores include 90.6 on Terminal-Bench 2.1 and 63.9 on HLE with tools versus 63.6 for Claude Opus 5; without tools it trails frontier models. Sources disagree on the release date (Sept. 10 API launch versus an Oct. 4 tracker entry), so treat the date as unconfirmed. Benchmarks are the vendor's own.

So what for TSD: Good candidate for high-volume, low-stakes jobs such as classifying inbound leads or summarizing call transcripts. Do not send client data to a China-hosted API; use a US-hosted route and check the client contract first.

VoiceOct. 1

Microsoft MAI-Voice-2.1 and streaming transcription

Microsoft AI released MAI-Voice-2.1 and a Flash variant (23 languages, claimed 150ms end to end, $22/$15 per million characters, on Azure and OpenRouter) and MAI-Transcribe-2-Streaming at $0.54 per audio hour, intro pricing through 2026. Latency figures are Microsoft's claims.

So what for TSD: TSD Front Desk lives or dies on response lag. Run the same scripted call through the current voice stack and the Flash model this week and compare lag and cost per minute.

OpenOct. 1

Cloudflare Clef and Amazon Strands Decider

Cloudflare released Clef (27B) and Clef-flash (9B) decision models, Apache 2.0, priced at $0.24/$0.09 per million input tokens, and Amazon released a 2B Strands Decider for local use. Vercel AI Gateway lists Laya from Convai free through Oct. 31.

So what for TSD: Small routing/decision models fit receptionist call triage (book, transfer, take a message) at lower cost than a large model. Worth a test, not a rebuild.

◆ Security & trust

SecurityOct. 3–6

Coding agents: hijacks, leaks, and automated exploits

An October roundup lists git config hijacks in seven coding agents, swapped plugin pins, sandbox escapes and 13,000 leaked screenshots. Separately, InfoQ reports a study where agents turned 87% of CVE descriptions into working exploits, and open-source maintainers report more vulnerability disclosures. Nvidia announced an Open Agent Safety Platform with OpenShell sandboxing.

So what for TSD: Patch windows are shrinking. Review which repos your coding agent can write to, pin plugin versions, and keep client secrets out of agent-readable env files.
