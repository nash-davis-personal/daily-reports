◆ Two labs cut flagship prices on the same day

New September 22

Claude Opus 5.5: cheaper, faster, and the new Claude Code default

Anthropic's Opus 5.5 lists at $4 per million input tokens and $20 per million output, down 20% from Opus 5, with cache-read pricing cut from $0.50 to $0.20 per million. Anthropic says typical workloads run about 40% cheaper overall because the model also needs fewer tokens to finish a task. A "fast mode" runs Claude Code and the API up to 2.5x faster at $8/$40 per million tokens.

On benchmarks it roughly matches Claude Fable 5.1 on general work but leads on agentic coding: 66.4% on Terminal-Bench 4.0 versus Fable's 55.8%, 89.9% on SWE-bench Pro, and 54.4% on FrontierCode versus 50.3%. It's Anthropic's first release since CEO Dario Amodei backed calls to "pace the frontier," and the company says it's the strongest model it has tested on its own automated behavioral audit, with external pre-release testing from Frontier Design and METR.

So what for TSD: Claude Code — the tool Nash uses to build everything, including this reports engine — now defaults to a model that's materially cheaper and needs fewer tokens per task. No code changes required, but it's worth re-running the cost math on TSD Front Desk and Concierge deployments this week: either drop what a client pays and win on price, or hold list price and keep the extra margin. Either way, check nothing hardcodes an older model ID.

New September 22

GPT-6 Sol and Luna: OpenAI's answer, same day, half the price

OpenAI expanded the GPT-6 family with Sol and Luna, priced at $2.00 per million input tokens and $10.00 per million output for Sol — roughly half of what the GPT-5.6 series cost. OpenAI says Sol makes about half as many factual errors as its predecessor on internal real-world conversation evaluations, reaching Astra-level reliability at a fraction of the cost. Both models shipped in GitHub Copilot, ChatGPT, and the API the same day as Opus 5.5.

So what for TSD: Two frontier labs cutting prices the same week, independently, is the signal that inference costs are falling faster than any client contract cycle. TSD's stack stays on Claude, but keep the model calls behind an adapter layer so if a client ever pushes back on cost, swapping in a cheaper GPT-6 tier for a low-stakes task is a config change, not a rebuild.

◆ Claude Code got two new front doors

Feature September 23

Claude Code cloud sessions are out of preview, with a credit to try them

Cloud sessions (formerly "Claude Code on the web") are now generally available for Pro, Max, Team, and eligible Enterprise plans. Tasks run on Anthropic-managed infrastructure in an isolated environment and keep working after the laptop closes — started from claude.ai/code, the mobile app, the desktop app, or claude --cloud in the CLI. Existing subscribers get a one-time credit — $100 on Pro, $250 on Max — that cloud sessions spend before falling back to normal plan usage; it must be claimed by October 7 and expires November 4.

So what for TSD: This matches his actual constraint — time-poor, class-interrupted days. Kick off a bug fix or a client feature from the phone between classes and let it keep running with the laptop shut; that's effectively an extra pair of hands during a school day. Claim the $250 Max credit before October 7 and spend it on a real client task this week, not a toy test.

Claude Marketplace unifies 2,000+ connectors and paid partner products

◆ An agent that found something real

Research September 23

Claude helped find a CRISPR-like enzyme system in bacteriophage DNA

Anthropic's wet-lab biology team, set up this spring, had Claude run 950 agents over 21 hours across 210 million tokens, analyzing more than 200,000 known bacteriophage reverse transcriptases. The search surfaced 3,500 candidate systems, 20 of which went to human lab review. One — a system Anthropic calls array-associated reverse transcriptases, or ART — shows DNA cutting-and-editing behavior reminiscent of CRISPR. Its actual function isn't determined yet; Anthropic published a preprint inviting outside labs to pursue it. CRISPR pioneer Feng Zhang called it a genuine example of AI-assisted discovery.

So what for TSD: Not a build opportunity, but a legitimate, verifiable, non-hype credibility line for sales conversations with skeptical SMB owners: the same company whose AI just helped surface a CRISPR-like gene-editing system is the model answering a client's phones and booking their appointments. Worth one sentence in the pitch deck, not more.

◆ Where the money's going

Funding September 22

Heidi Health raises $340M to graduate from scribe to supervised agent

Heidi — an ambient clinical-notetaking AI — raised $100M in Series C equity at a $900M valuation plus a $240M growth investment from General Catalyst's Customer Value Fund, for $340M total and $436.6M raised to date. The money funds a shift from pure transcription into "supervised agentic execution": Heidi Evidence has answered 10M+ point-of-care research queries since March, and the platform now handles roughly 2.8M patient interactions a week across 110 languages and 190 countries.

So what for TSD: This is TSD's own product roadmap playing out at a $900M scale instead of a $500/month retainer. Front Desk today answers and logs calls; the Heidi arc — notetaking is the wedge, supervised action is where the valuation (and the recurring revenue) shows up — is the exact pitch for the next tier of Managed AI retainers: booking, rescheduling, and follow-up under supervision, not just call logging. Use "notetaker becomes an agent that acts" as the line when pitching an upgrade to an existing client.
