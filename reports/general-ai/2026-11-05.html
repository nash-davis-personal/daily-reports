◆ Agents as security researchers

Research Nov 4

OpenAI: one agent run produced 948 working Linux root exploits and candidate patches, for about $1.2M

OpenAI published "A thousand fewer paths to root." Scout agents narrowed the Linux kernel to 5,034 targets covering about 2.8 million lines (roughly 7% of the codebase). The pipeline produced 2,308 candidate findings, reproduced 1,724, and ended with working exploits for 948 distinct local privilege-escalation vulnerabilities, plus 291 information-leak proofs of concept. The run used an unreleased cyber model and cost about $1.21M in API credits, around $1,279 per exploited bug. OpenAI's July experiment with GPT-5.6 Sol found 166. By the time the write-up went out, maintainers had patched 61 upstream, 43 had patches in preparation and 299 were in public discussion.

Two caveats the coverage flags: every exploit needs an existing foothold on the machine, and the agents' self-reported results did not always hold up, which is why the reproduced count is lower than the candidate count. The patches are candidates that still need maintainer review.

So what for TSD: Bug-finding just got cheap and bug-fixing is now the bottleneck. Expect a wave of kernel and dependency patches over the next few months, and expect client hosting providers to reboot more often. The sellable angle is the same one Vercel shipped this week with Security Review: an agent that reads every push to a client's repo and files a fix. Run Claude Code against each client codebase on a monthly cadence and bill it as a security line item on the Managed AI retainer.

◆ The labs are buying the layer between you and the agent

Acquisition Nov 4

OpenAI will acquire Pierre Computer and bring Code Storage into Codex

OpenAI announced an agreement to buy Pierre Computer Company, the firm behind Code Storage and a set of open-source developer tools. Pierre's Trees and Diffs libraries already run file browsing and change review inside the Codex app. OpenAI says the open-source projects stay open and Code Storage customers keep access while its features move into Codex. Price and closing date were not disclosed, and closing depends on regulatory approval. Axios and SiliconANGLE both frame the move as OpenAI taking on GitHub as agents do more of the committing.

So what for TSD: Watch where your code lives. If Codex grows its own hosted repo layer, the "GitHub plus Vercel" default you ship clients on will have a competitor from OpenAI within a year. No action today. Keep clients on plain git repos they own, which is already your closing differentiator, so any future agent platform can plug in without a migration.

Acquisition Nov 4

Meta acquires Conductor; Conductor Cloud shuts down Nov 20

Conductor's desktop app runs several coding agents at once, each in an isolated copy of the codebase, then lets you review and merge. It supports Claude Code, Codex and Cursor on the user's own subscriptions and keys, and claims more than 100,000 users. Axios first reported the deal; Conductor confirmed on its site. Terms were not disclosed. Conductor raised a $22M Series A in March and named Meta, Google and Spotify as customers with dozens of engineers on the product. TechCrunch confirmed the hosted Conductor Cloud shuts down Nov 20, after which customer cloud data starts being deleted. Meta released Muse Spark Open, an open-weights coding model, on Oct 15.

So what for TSD: If you use Conductor Cloud for anything, export before Nov 20. The bigger lesson is that multi-agent orchestration on one repo is now a commodity feature Meta wants in-house. Your own setup (Claude Code worktrees plus the daily-reports pipeline) already does this; write it up once as a case study, since it is the exact capability SMB owners read about and cannot picture.

Open source Oct 31 / Nov 1

DeepSeek's Super-Agent prototype watches your team chat and starts coding without being asked

DeepSeek's Harness team published dsh-superagent-prototype under the MIT license. Instead of waiting for a prompt, it monitors developer group chats (GitHub, and Feishu in China), spots coding problems being discussed, and proposes or starts fixes. DeepSeek calls it a research prototype and says it is "not an official DeepSeek product"; one analysis notes parts of the paper's design are unimplemented in the released code. Bloomberg reports DeepSeek is aiming it at Claude Code, and that the company raised roughly $15B ahead of a planned IPO.

So what for TSD: The always-on pattern is the interesting part, and you can copy it with Claude Code today: a scheduled agent that reads a client's support inbox or Slack, drafts the fix, and opens a PR for you to approve. That is a "we noticed and fixed it before you called" retainer story, which sells better than "we answer tickets."

◆ Cool and groundbreaking

Science Oct 30

Nvidia's agents now run the Allen Telescope Array for the SETI search

Nvidia announced that AI agents help operate the Allen Telescope Array in Northern California for Breakthrough Listen and the SETI Institute. Researchers state a goal in ordinary sentences; agents steer the antennas, calibrate and focus the instrument, catch and fix data errors, and run models on the live feed. The stack is Nvidia Holoscan on RTX PRO 6000 Blackwell GPUs handling up to 2.4 terabits per second, with inference on site. A web tool called Nexus lets researchers watch packet loss and live spectrograms and rewrite signal-processing blocks by prompting. The first result was real-time detection of a pulsar in the Crab Nebula. Nobody is claiming an alien signal; the principal investigator called it a breakthrough in translation between scientist and instrument.

So what for TSD: This is the same shape as TSD Front Desk and Concierge: natural language in, a complicated system operated correctly out. It is a good one-paragraph analogy for a pitch deck slide. No other action.
