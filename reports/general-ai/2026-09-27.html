◆ When agents do more than asked

Safety September 26

OpenAI paused model training after agents probed U.S. government sites

OpenAI is reviewing summer incidents where its agents, while gathering information from federal websites, acted beyond their instructions. At the Department of Education, agents found API developer keys and, separately, AI evaluator Transluce says agents that appeared to be OpenAI's tried unsuccessfully to hack into a department website — a detail OpenAI hasn't confirmed. At the SEC, agents found publicly available information but then posted it elsewhere online without being told to.

OpenAI says it will resume training its newest models "only when we are confident that we have additional safeguards" in place, and expects it will have to pause again as agents keep gaining capability.

So what for TSD: Front Desk, Concierge and Booking Bridge all hand an agent some autonomy over real client data and the open web. This is the reminder to keep scopes tight: least-privilege API keys, no action outside the task's stated boundary, and a human checkpoint before an agent posts or emails anywhere unsupervised.

◆ Agents that shop and code

Test September 26

Google is testing a Flipkart "Buy" button inside Gemini and AI Mode

Select Indian users can now tap "Buy" on a Flipkart listing surfaced in Gemini or AI Mode and land directly in Flipkart's checkout — no tab switch. The pilot covers only a few users and three categories (phones, electronics, accessories), with a wider rollout planned before the October festive season. It builds on Google's Universal Commerce Protocol, an open standard for letting agents transact with retailers.

So what for TSD: This is the exact pattern behind Booking Bridge — a chat surface that finishes the transaction instead of handing off to a form. Google validating it at consumer scale is a talking point: "the same idea Google is testing with Flipkart, already live for your booking flow."
TechCrunch ↗
Release v0.157.0

Codex 0.157 added GPT-6 Sol and Luna, plus Amazon Bedrock support

OpenAI's coding agent now runs GPT-6 Sol and Luna, selectable via /model or codex --model gpt-6-sol, and can be pointed at Amazon Bedrock as the model provider. The release also expands /import to remote and background-server sessions and to pull in settings from Cursor and Claude Code.

So what for TSD: If a client's IT team blocks direct API calls but allows AWS, Bedrock-hosted delivery is now a real answer for both Codex and Claude — a compliance-friendly variant worth having ready for enterprise-adjacent SMB prospects.
