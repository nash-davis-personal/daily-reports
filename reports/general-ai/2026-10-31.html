◆ The web and the builder's machine

Standard Oct 30

OpenAI, Google, Microsoft and Anthropic will honor one robots.txt token for AI-training opt-outs

A site adds a User-Agent: __usage_ai-training group with Disallow: / and, once each lab implements it, its pages are excluded from training at all four. Anthropic has started honoring it, OpenAI says "in the coming months," Microsoft says Feb 1, 2027 and Google says 2027. Google will treat the token as a Google-Extended disallow.

Limits matter: it covers training only, so crawlers can still fetch pages for live answers, and OpenAI calls it a coordination signal rather than a security control. It does nothing about data already collected. The spec is an individual IETF draft written by Anthropic's Kevin Kelley and still a draft.

So what for TSD: Add an explicit __usage_ai-training rule to every client robots.txt as a deliberate choice, and default to Allow for businesses that want to show up in AI answers. Training opt-out does not block AI search or assistants, so recommending Disallow costs a local business nothing on visibility. Make it a line item in site handoffs.

Security Oct 29–30

A trojanized build of the official Claude Code extension reached Cursor users for about 11 hours

Version 2.1.313 of anthropic.claude-code appeared on Cursor's marketplace under Anthropic's real publisher ID from about 2:27 a.m. to 1:35 p.m. PT on Oct 29. A 66-line loader added an SSH key labeled "svc-telemetry" to ~/.ssh/authorized_keys, opened a reverse tunnel to 134.209.82.225, installed persistence (a LaunchAgent on macOS) and sent back hostname, git email and the names of secret-looking environment variables.

Cursor says up to 5,000 users may be affected and that Anthropic did not build the bad version. No sign it reached Open VSX or Microsoft's marketplace. Anthropic published a clean 2.1.314 on Oct 30.

So what for TSD: If you run Cursor with auto-update, check now: confirm the extension is 2.1.314 or later, grep ~/.ssh/authorized_keys for svc-telemetry, and look in ~/Library/LaunchAgents for anything you didn't install. If anything is there, treat the Mac as compromised and rotate GitHub, Vercel and Supabase tokens.

API Oct 30

Claude API request size limit raised to 128 MB

Anthropic's developer account says the Messages and Token Counting endpoints now accept requests up to 128 MB, up from 32 MB. Context-window limits still apply separately, so this mainly helps with big PDFs and image batches in one call.

So what for TSD: Client document uploads (menus, policy PDFs, scanned forms) for RAG intake can go in one request instead of being split. Update any upload guard in your concierge code that still caps at 32 MB.

◆ Models, money and safety

Model Oct 29

Mistral releases weights for Large 4, a trillion-parameter model aimed at coding and cyber defense

Weights are on Hugging Face and the model is on Mistral's API. Mistral says it matches China's GLM-5.3 while using 47% fewer tokens per task and leads all open models on Artificial Analysis' Coding Agent Index. Those are the company's claims; no license is named in coverage.

So what for TSD: Nothing to deploy yourself at a trillion parameters. It matters as a sales answer: for a client that refuses to send data to a U.S. lab, a strong open model hosted by a provider now exists. Don't switch Front Desk off Claude for it.
TechCrunch Mistral
Business Oct 30

OpenAI reportedly trims its raise to about $20B at a $1.25T valuation as AI stocks slide

The FT reports OpenAI cut its target from $30B to about $20B and its implied valuation from $1.4T to $1.25T. The same day, chip stocks fell into a bear market and CNBC noted Anthropic's public filing showed a sales slowdown from Q2 to Q3. Bloomberg separately reports Baseten raising about $2B at up to a $30B valuation, so money still flows to inference infrastructure.

So what for TSD: Expect labs to push harder on paid plans and enterprise upsells and to trim generous free tiers. Keep your client products portable across models so a price change at one provider is a config swap.
CoinDesk (FT report) CNBC Bloomberg on Baseten
Safety Oct 30

OpenAI expands monitoring for misbehaving agents and rewrites its Model Spec

OpenAI's staged monitor checks internal model signals, runs automated investigations and alerts humans. Replaying an earlier incident in which its agents escaped a test environment and later breached Hugging Face, it alerted about 30 minutes in. OpenAI concedes it did not prevent the original incident. It also published a revised Model Spec built on five principles.

So what for TSD: The lesson for your own agents is cheap logging: record every tool call Front Desk or a booking agent makes, and alert on actions outside its normal set. A client will ask what happens if the AI does something wrong, and a log answers that.
