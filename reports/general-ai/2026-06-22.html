◆ Access & policy: the best models you can't get

Breaking June 12–21

Fable 5 and Mythos 5 remain suspended worldwide; no agreement after a White House meeting

Anthropic pulled its two most capable models globally on June 12–13 to comply with a Commerce Department directive that bars access by any foreign national, including its own non-American staff, citing a claimed jailbreak. A week on, the models are still dark with no restoration timeline. Dario Amodei met the administration June 21 and left without a deal. An open letter organized by former Facebook security chief Alex Stamos has climbed past 100 signatures — names from Nvidia, Google, and Adobe — arguing the ban strips defenders of a tool while doing nothing to slow attackers. Researcher Katie Moussouris, who reviewed the underlying paper, says the alleged "jailbreak" was essentially rephrasing a prompt as "fix this code."

So what for TSD: Your production stack is fine — Opus 4.8 and Sonnet 4.6 are unaffected and still the right default for everything TSD ships. Don't architect a client product around a model that can be pulled by directive overnight; this is the case for keeping a provider-swappable layer (e.g. an env-flagged model id) so a future ban or outage is a one-line change, not a rebuild.

New June 20–21

GPT-5.6 spotted in ChatGPT Pro ahead of a late-June launch

OpenAI's chief scientist called GPT-5.6 a "meaningful improvement" over 5.5, and the model has already been seen inside ChatGPT Pro, pointing to a launch before month-end. Separately, China's Zhipu shipped GLM-5.2, which now leads GPT-5.5 on the FrontierSWE coding benchmark and trails only the offline Fable 5 by a point — a reminder the coding-model race is genuinely four-way now.

So what for TSD: No action, just don't over-commit. If you ever need a fallback or cost lever for code-heavy automation, the open-weight GLM line is now competitive enough to keep on the radar — but Claude stays the default for client work where reliability beats benchmark points.

◆ The agent layer: where the risk moved

Security Disclosed June 2026

"Agentjacking": a fake Sentry error report can make your coding agent run attacker code

Tenet Security disclosed an attack that abuses the seam between Sentry's open event ingestion (anyone with the DSN can post a payload) and the Sentry MCP server (which feeds those events to AI agents as trusted system output). A crafted error event gets read by Claude Code or Cursor as a legitimate "fix this" step and executes attacker-controlled code — exposing env vars, Git credentials, private repo URLs, and developer identity, no phishing required. Researchers found 2,388 organizations with injectable DSNs and hit an 85% success rate in testing, including a Fortune 100 agent. Sentry acknowledged it but declined a root fix, leaning on model-vendor middleware.

So what for TSD: Directly relevant — you run Claude Code daily. Treat any MCP server that ingests untrusted external data (error trackers, ticketing, email, web content) as a prompt-injection surface, not a trusted source. Audit which MCP servers your agents can read from, lock down or rotate any public Sentry DSNs, and never let an agent auto-execute steps sourced from third-party event data without a human gate.

◆ The market: agents become acquisition targets

Business June 15

Salesforce buys Fin (formerly Intercom) for $3.6B to bolster Agentforce

Salesforce signed a definitive deal for Fin, the AI customer-service company that rebranded from Intercom, for about $3.6B. Fin's agent resolves customer queries end-to-end across chat, email, WhatsApp, SMS, phone, and Slack — closing roughly 76% of incoming support requests without a human — and brings 30,000+ business customers. Also notable on the talent side: Noam Shazeer joined OpenAI as Lead for Architecture Research (June 18).

So what for TSD: The big platforms are validating exactly TSD's wedge — an AI agent that resolves SMB customer requests across channels. That's tailwind, not threat: Salesforce/Fin chase enterprise seats, while the Charlotte HVAC shop or salon wants a phone receptionist and a website concierge that someone local will set up and own. Use "even Salesforce just paid $3.6B for this" as social proof in the pitch.
