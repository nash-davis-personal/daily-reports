◆ File integrity and macOS — the load-bearing fixes

Fix 2.1.181

Write/Edit producing 0-byte or truncated files on network drives and cloud-synced folders

Writes to network drives and cloud-synced folders could land as empty or partial files. Your entire working tree sits under ~/Documents, which is exactly the kind of cloud-synced location this hit. Silent truncation is the worst failure mode — you don't notice until a build breaks or a file is half-gone.

So what for TSD: Update to 2.1.181 before your next session. After updating, run a quick git status across active repos (praxis, the Next app, grant-tool) to confirm nothing was silently mangled in recent sessions.
Claude Code Changelog · 2.1.181
Fix 2.1.181

macOS open, osascript, and browser auth no longer fail with -600

An Apple Events entitlement was added so open, osascript, and browser-based auth flows stop erroring with -600. A companion opt-in, sandbox.allowAppleEvents, lets sandboxed commands send Apple Events on macOS when you want it.

So what for TSD: You drive computer-use and browser OAuth flows constantly (Vercel, Supabase, deploy logins). This removes a class of intermittent -600 failures that would otherwise eat time mid-deploy.
Claude Code Changelog · 2.1.181
Fix 2.1.181

Prompt caching now reads on custom ANTHROPIC_BASE_URL and Foundry

A per-request attestation token was changing every turn, so prompt caching never hit on custom base URLs or Foundry. Fixed. Standard claude.ai-authed sessions were unaffected.

So what for TSD: Only relevant if you route through a gateway or custom base URL. Your normal sessions already cached fine, so no action unless you've set ANTHROPIC_BASE_URL.

◆ Run control from the prompt

New 2.1.181

/config key=value sets any setting inline

Set any setting straight from the prompt — /config thinking=false, for example — and it works in interactive mode, in -p headless runs, and over Remote Control. No editing settings.json and restarting.

So what for TSD: Useful inside your scheduled tasks and overnight builds — flip a setting for one run via -p without committing a settings change. Tighten or loosen thinking/effort per job.
Claude Code Changelog · 2.1.181
New 2.1.181

Presence marker suppresses mobile push while you're at the machine

Point CLAUDE_CLIENT_PRESENCE_FILE at a marker file and mobile push notifications are muted while you're present. The bundled Bun runtime also moved to 1.4, and long paragraphs now stream line-by-line instead of waiting for the first line break.

So what for TSD: If you wire mobile alerts for your overnight scheduled tasks, this stops them buzzing your phone when you're already sitting at the Mac watching the run.
Claude Code Changelog · 2.1.181

◆ Agents and subagents behave

Improve 2.1.181

Mid-thinking connection drops auto-retry; subagent panel and depth limits tightened

API connection drops during thinking now retry automatically instead of dead-ending on "Connection closed while thinking." Foreground subagents now respect the same 5-level nesting depth cap as background ones, closing an unbounded-chain bug. The subagent panel also got cleaner: idle subagents auto-hide after 30s, the list caps at 5 rows with scroll hints.

So what for TSD: Your overnight multi-agent workflows (Gastonia demo blitzes, fleet audits) are exactly where a mid-thinking drop used to kill a run. Auto-retry plus the depth cap make those long unattended jobs more likely to finish clean.
Claude Code Changelog · 2.1.181
Fix 2.1.181

/recap and conversation forks no longer stick on the previous model

Right after a model switch, /recap and conversation forks were still using the old model. Subagent "Thinking" durations also stopped showing the parent's elapsed time, and blocked subagents now read "waiting" instead of a ticking clock.

So what for TSD: When you switch to Opus for a hard step then fork or recap, you now actually get Opus. Stops silent model downgrades on the work that needed the bigger model.
Claude Code Changelog · 2.1.181

◆ Startup stopped fighting you

Fix 2.1.181

A cluster of startup hangs, crashes, and slowdowns cleared

Several launch problems are fixed at once: a ~120ms-per-launch regression (from 2.1.169) when no MCP servers are configured; up to 15s of blank-terminal blocking on a slow account-settings fetch; a startup crash on corrupted null project entries in .claude.json; and a macOS TUI freeze at session start when Spotlight is busy reindexing. Long-running idle sessions also stopped losing history when another process ran the 30-day transcript cleanup.

So what for TSD: You open a lot of fresh sessions across many repos a day. Faster, non-hanging cold starts is small per-launch but compounds across a build-heavy day.
