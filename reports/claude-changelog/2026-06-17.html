◆ Reliability in long and remote runs

Fix 2.1.179

A dropped connection no longer torches the response

When the stream drops mid-response, Claude Code now keeps whatever it had already generated instead of replacing it with a raw connection error, and the spinner no longer gets stuck on "running tool." On flaky Wi-Fi or during a long agent turn, you keep the partial work and the session stays usable.

So what for TSD: The most common annoyance in your long build/agent sessions just got cheaper — a hiccup costs you a partial answer to re-prompt from, not a dead turn. No action needed beyond updating.

Fix 2.1.179

Remote background tasks report their real status

Background tasks in remote sessions were appearing stuck as "still running" between turns even after they finished. That's fixed, so the agents list reflects what's actually happening.

So what for TSD: You lean on background and scheduled work constantly — the daily reports, the macro brain, the trading tasks. A status list you can trust means you stop second-guessing whether a run actually completed.

◆ Subagent and input polish

Fix 2.1.179

Subagent transcript and focus bugs cleaned up

Two related fixes: Ctrl+O now actually shows the subagent's transcript while you're viewing a subagent, and clicking the prompt input now returns focus from the subagent/footer panel instead of leaving you stuck.

So what for TSD: You run multi-agent work (workflows, the macro and review fleets) routinely — being able to read a subagent's transcript and type again without fighting focus is real day-to-day friction removed.
