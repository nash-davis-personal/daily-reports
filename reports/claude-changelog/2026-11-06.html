◆ Reminder

Deadline Nov 30, 2026

Opus 4.8 fast mode removal is 24 days out

Carried from the 2.1.316 entry dated October 31: fast mode for Opus 4.8 was deprecated as of October 30, 2026 and will be removed on November 30, 2026. After removal, fast mode requests on Opus 4.8 return an error and do not fall back to standard Opus 4.8. The changelog says to migrate to Opus 5.5 to keep the speedup.

So what for TSD: Still open. Grep scheduled tasks, launchd jobs, and any client SDK code (Bisque, Studio C, Sonderwerks) for a pinned Opus 4.8 model with fast mode on, and move those to Opus 5.5 before the end of the month so nothing starts erroring on December 1.
