◆ The one action today

Upgrade 2.1.247 → 2.1.251

You are three releases behind, and the gap is the entire security batch you were briefed on yesterday

Yesterday's briefing led on 2.1.251 patching a symlink swapped inside the working directory after the permission check, which let Read, Write and Edit reach outside the approved location, and on Grep and Glob failing to apply Read(...) deny rules to files reached through a symlinked search path. It also covered the Workflow tool reading a scriptPath outside what the session may read before the permission check ran, plugin commands in a marketplace entry pointing outside the plugin directory, project settings enabling raw API body logging, and Bash auto-approving arithmetic assignments like OPTIND=1/0. All six landed in 2.1.251. None are in 2.1.247.

The same gap holds the fix for background sessions being unable to edit files in a git worktree they created with git worktree add — the one the briefing called the most important item for your loop work — plus the Opus 5 failure at xhigh and max effort with thinking off, and the change making CLAUDE_CODE_SUBAGENT_MODEL a default rather than an override.

So what for TSD: Run the upgrade before the next scheduled loop fires. Your unattended runs carry wide permissions with nobody watching the prompts, which is precisely the shape those permission escapes exploit, and the worktree-edit bug means a background loop may have been failing silently on the create-then-edit move all week.
Claude Code changelog — 2.1.251
Credentials 2.1.248

The version you are on still uploads uncommitted credential files during ultrareview

2.1.248 fixed /ultrareview and locally seeded cloud sessions uploading uncommitted edits to prod.env-style and *.tfvars files, along with editor swap, temp and backup copies of credential files such as key.pem.tmp and id_rsa.swo. Those now stay on the machine. 2.1.247 predates the fix.

The same release fixed a prompt-cache miss roughly once an hour in long sessions, caused by tool definitions being re-rendered after an OAuth token refresh — the hourly tax an earlier briefing flagged and 2.1.251 gave you a /cost readout for. It also fixed a backgrounded worktree session losing its checkout, since the session now holds the worktree lock while it runs so git worktree remove leaves it alone.

So what for TSD: This is the one with client blast radius. You run ultrareview against Bisque, Studio C and Sonderwerks repos that carry real .env files, and on 2.1.247 an uncommitted edit to one of those can ride along to the cloud. Upgrade before the next review, and if you have run ultrareview on a client repo recently, rotate anything that was sitting uncommitted in an env file at the time.
