◆ Automation you can leave running

Fix 2.1.290

/loop and scheduled tasks no longer drop out silently

A cluster of fixes: scheduled tasks didn't come back on resume once the conversation was compacted (fixed for compactions made from 2.1.290 on); foreground tasks never fired after a /background hand-off; recurring ones fired an extra run on every resume, respawn or fork; and Linux sandboxed Bash could trigger an extra run. Background sessions waiting on a /loop wakeup are now left running through updates and low memory, where a restart could lose the wakeup. Cloud sessions that lost a pending wakeup on container restart now tell Claude so it can reschedule.

So what for TSD: If any Nash OS job or client monitor has looked "flaky" in a loop, this is the likely cause. Update to 2.1.291, then restart long-lived loops so they start on a post-fix compaction history. Don't double-schedule as a workaround any more; the extra-run bug is gone too.
Changelog 2.1.290
Fix 2.1.290

Sleep, headless exit codes, and resumed subagents

Background agents failed with "Agent stalled" and Workflow subagents restarted from their prompt when a Mac woke from sleep; fixed. Automatic compaction gave up with "Prompt is too long" if the Mac slept mid-compaction; fixed. Headless --json-schema runs exited non-zero with is_error: true on a successful result when the connection dropped after delivery; fixed. Resumed subagents and teammates lost their earlier thinking and prompt cache after a mid-run message; fixed.

So what for TSD: The hub runs on a MacBook Air that sleeps. Any job that "failed" overnight with a stall or a false non-zero exit deserves a rerun on 2.1.291 before you debug your own code. If a hub script treats non-zero as failure on --json-schema output, it was getting false alarms.
Changelog 2.1.290
Improved 2.1.290

WebFetch stops truncating; WebSearch budget refills

WebFetch silently dropped page text past 100,000 characters. It now says how much was unread and accepts an offset to keep reading. Separately, the interactive session's WebSearch budget refills at 100 calls/hour (set with CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR, 0 turns it off); before, it ended after 200 calls.

So what for TSD: The scout routines read long pages (this changelog alone is ~970 KB). Briefings built from WebFetch were potentially missing the bottom of long sources. Competitor and client-site audits for Bisque, Studio C and Sonderwerks get the full page now; tell the agent to page with offset when it reports unread text.

/code-review at medium effort reports cleanup and CLAUDE.md conventions on Opus 5.5

On models without tuned review settings, including Opus 5.5 and Sonnet 5.5, medium-effort /code-review now also reports cleanup and CLAUDE.md-convention findings. Separately, GitHub Code Review stopped labeling blocking comments as "nit".

New 2.1.290

/claude-api managed-agents-onboard

Pass a URL and it sets up the Managed Agents pattern that page describes as ant apply files. Pass a Console quickstart name, such as deep-researcher, and it builds that template with the ant CLI. ◆ Permissions and the 2.1.291 patch

Security fix 2.1.290

Several Bash auto-approve holes closed

Read-only commands like rg and git grep were auto-approved even when the shell would expand wildcards in their arguments; they now prompt. Same for commands whose variable names zsh reads differently from bash, deny rules missed on names set via declare/export/readonly prefixes, and some rules skipped after a PreToolUse hook rewrote a tool's input. pyright and more forms of ps now ask. A repo's .claude/settings.json can no longer turn on Claude in Chrome or set CLAUDE_CODE_DISABLE_ATTACHMENTS.

So what for TSD: Expect a few more prompts on rg/git grep with globs. Accept them; they cover real holes. If a hub job runs a PreToolUse hook that rewrites commands, rerun it once interactively to confirm nothing now stops on a prompt.

Fix 2.1.291

Two regression fixes: lost final messages and dropped cloud permission answers

2.1.291 fixes a 2.1.288 regression where the last messages of a session could be lost on quit, and a 2.1.290 regression where cloud sessions could drop answers to permission prompts.

So what for TSD: Sessions quit on 2.1.288–2.1.290 may be missing their tail on resume. Update the hub Mac to 2.1.291 today.
