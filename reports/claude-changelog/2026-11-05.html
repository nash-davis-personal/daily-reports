Status 2.1.318

Still on 2.1.318 from yesterday

The changelog lists no version above 2.1.318 and no entry dated after November 4. That release added a 10-day sign-in expiry warning to claude -p, put the expiry date in claude auth status, kept background subagents' prompt cache alive through long shell commands, fixed Mac sessions stalling under many Bash commands, and stopped version cleanup deleting the binary of a running Remote Control host. Details and the full quick-hits list are in yesterday's briefing.

So what for TSD: Nothing new to act on. A quiet day is a good time to do the one chore from yesterday: run claude auth status on both Macs and note the sign-in expiry date, since every scout and Nash OS job dies silently when it lapses.
Changelog: 2.1.318
Reminder Nov 30, 2026

Opus 4.8 fast mode removal is 25 days out

Carried from the 2.1.316 entry (October 31): fast mode on Opus 4.8 was deprecated October 30 and is removed November 30, 2026. After that, fast mode requests on Opus 4.8 return an error and do not fall back to standard Opus 4.8. The changelog says to migrate to Opus 5.5 to keep the speedup.

So what for TSD: Still open. Grep scheduled tasks, launchd jobs and any client SDK code for a pinned Opus 4.8 model with fast mode on, and move them to Opus 5.5 before the end of the month.
