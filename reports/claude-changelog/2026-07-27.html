Setting 2.1.219 · Jul 24

strictAllowlist turns sandbox network egress into a hard deny

2.1.219 added sandbox.network.strictAllowlist, which denies any host outside the allowlist for sandboxed commands without opening a prompt. The default behaviour prompts instead, so an unattended run will sit waiting on a dialog nobody is there to answer.

So what for TSD: This is the setting that makes a scheduled or background agent fail fast instead of hanging on an unexpected egress prompt. If any client repo runs Claude unattended, set it and list the hosts you actually need — for a Next.js/Supabase build that is typically the Vercel API, your Supabase project host, and the npm registry.
Claude Code changelog — 2.1.219
Default change 2.1.219 · Jul 24

Dynamic workflows now default to a medium size guideline

Workflows now aim for fewer than 15 agents by default, and the guideline can be pinned from any settings file via the workflowSizeGuideline key — when it is set there, the /config row is hidden. The running-workflow status line shows the active size.

Pair this with the two spend guards from the same week: the concurrent-subagent cap (default 20, override with CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS) and the --max-budget-usd fix in 2.1.217, which now actually halts running background agents once the cap is hit.

So what for TSD: Put workflowSizeGuideline in project settings for anything client-billed so a fan-out can't quietly scale past what the engagement is worth. The --max-budget-usd fix is the one that makes an unattended cap trustworthy — before it, background agents kept spending past the limit.
Claude Code changelog — 2.1.219
Diagnostics 2.1.219 · Jul 24

Failed MCP servers now say why

claude mcp list and /mcp report the HTTP status and error text when a server fails to connect, and warn about config values carrying hidden leading or trailing whitespace. Headless runs get an mcp_server_errors entry in the stream-json init event listing skipped --mcp-config entries, and terminal runs print a startup warning.

So what for TSD: Next time a Supabase or Vercel MCP server goes missing mid-build, claude mcp list gives you the actual status code instead of a silent absence. The whitespace warning is worth knowing about — a trailing space on a pasted token reads as a valid string and fails as a bad credential.
