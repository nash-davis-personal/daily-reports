◆ Auto mode got a safety brake

Improve v2.1.183

Destructive git and infra-destroy commands are blocked unless you ask for them

In auto mode, Claude will no longer run git reset --hard, git checkout -- ., git clean -fd, or git stash drop when you didn't ask to throw away local work. git commit --amend is blocked when the commit wasn't made by the agent this session, and terraform destroy / pulumi destroy / cdk destroy are blocked unless you named the specific stack.

So what for TSD: You run auto mode across a fleet of repos — TSD app, Praxis, the renters funnels, the demo sites. This is the failure mode that wipes uncommitted work on the wrong checkout. It's now a default backstop, so you can leave auto mode on for the overnight demo builds without babysitting the git surface. Don't treat it as a license to skip commits, but it removes the worst tail risk.

Claude Code changelog — 2.1.183
Fix v2.1.183

Scheduled-task and webhook deliveries are no longer treated as keyboard input

Previously a scheduled task or webhook trigger arriving mid-session was processed like something you typed — which meant it could approve a pending permission prompt or set the session title in auto mode. They now classify as task notifications and can do neither.

So what for TSD: This is the same machinery that runs your daily reports, the Macroscope captures, the Frontier lessons, and the agentic-account manager — all local scheduled tasks firing into sessions. The old behavior was a quiet way for an automated delivery to rubber-stamp an action nobody reviewed. Worth a mental note that your unattended jobs are now safer by default; no config change needed.

◆ Automation reliability fixes

Fix v2.1.183

WebSearch returned empty results inside subagents

Subagents that called WebSearch were getting empty results back. Fixed in this release. The same drop also re-prompts a turn that returned only a thinking block instead of completing silently with no visible output.

So what for TSD: Your research-heavy automations lean on subagent WebSearch — the daily money-moves report, Macroscope's web reads, anything using the deep-research harness. If a recent run came back thin or oddly generic, this is a likely cause. Re-run anything that searched-via-subagent in the last few days and compare. The thinking-only re-prompt fix matters for unattended jobs that occasionally produced nothing.

Fix v2.1.183

Subagent spawns hitting a thinking-config 400, and headless MCP auth stubs

Two more headless-path fixes: subagent spawns and session-title generation no longer throw thinking.disabled.display: Extra inputs are not permitted 400 errors on affected configs, and MCP servers that require authentication no longer expose auth-stub tools to the model in headless/SDK mode.

So what for TSD: Both bite the SDK / -p path, which is exactly how your scheduled tasks and any programmatic runs execute. The MCP auth-stub fix means a half-authenticated connector no longer dangles a useless tool in front of the model — cleaner tool lists and fewer wasted calls in your automated runs.

◆ Models & commit attribution

Feature v2.1.183

Deprecated-model warning now also covers models pinned in agent frontmatter

When a requested model is deprecated or silently updated to a newer one, Claude Code now warns on stderr in print mode — and the check now also covers models set in agent frontmatter, not just the top-level model.

So what for TSD: You pin specific models in subagent files — Sonnet 4.6 on the receptionist, Fable 5 on the Field handoff, model overrides scattered through your workflows. A pinned ID that quietly got redirected is the kind of thing you'd never notice until output drifted. Watch your scheduled-task logs for the new stderr warning and clean up any stale IDs it flags.

Feature v2.1.183

attribution.sessionUrl drops the claude.ai link from commits and PRs

A new setting omits the claude.ai session link from commits and PRs in web and Remote Control sessions. Alongside it, /config --help now lists every shorthand key for the /config key=value syntax added in 2.1.181, and the /config toggle now saves on Esc instead of reverting.

So what for TSD: You already strip Claude co-author trailers on the Vercel-Hobby private repos because they block deploys. This is the matching control for the session URL — one more bit of agent metadata you can keep out of client-facing git history. Set it once if you do any web or Remote Control commits into repos a client will see.
