Improve 2.1.185 · Jun 20

Stream-stall hint reworded and slowed down

When the API goes quiet mid-response, Claude Code used to flash "No response from API · Retrying in …" after 10 seconds of silence. It now reads "Waiting for API response · will retry in …" and waits 20 seconds before showing it. Same underlying retry behavior — softer wording and a longer fuse so a normal slow stream doesn't look like a failure.

So what for TSD: Nothing to do. If you've been reflexively killing a build session when that "No response" line popped up, stop — it was usually just a slow stream, and the new copy makes that obvious. Let it ride for 20s.
