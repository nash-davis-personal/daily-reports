Deadline 2.1.316 · Oct 31

Opus 4.8 fast mode goes away on November 30

Fast mode on Opus 4.8 was deprecated as of October 30 and will be removed on November 30, 2026. After that, fast mode requests on Opus 4.8 return an error and do not fall back to standard Opus 4.8. The changelog says to move to Opus 5.5 to keep the speedup.

So what for TSD: 29 days left. Grep scheduled tasks, launchd jobs, client app configs and any SDK code for a pinned Opus 4.8 model with fast mode on, and switch them to Opus 5.5 before the 30th so nothing unattended starts erroring.
