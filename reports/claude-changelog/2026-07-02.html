◆ Agents that finish the job

Feature 2.1.198

Background agents commit, push, and open a draft PR when they're done

Background agents launched from claude agents now finish code work in a worktree by committing, pushing, and opening a draft PR — no more stopping mid-run to ask what to do with the changes. Paired with this: agents that need input or complete now fire the Notification hook (agent_needs_input / agent_completed), so you get pinged rather than having to babysit the agents view.

So what for TSD: This is the missing piece for your propose-only loops. The TSD site loop, sales loop, and Fleet Steward can now hand you a reviewable draft PR each cycle instead of leaving work parked in a worktree waiting for you to notice. Wire the new agent_completed hook to a notification you actually see, then let the overnight loops surface as a stack of draft PRs you triage in the morning.

Changelog · 2.1.198

◆ Delegation quality goes up for free

Improve 2.1.198

Explore inherits your model; subagents inherit extended thinking

Two quiet upgrades that touch every agent-heavy task. The built-in Explore agent now inherits the main session's model, capped at opus, instead of running on haiku — codebase searches and file discovery get materially smarter. Separately, subagents and context compaction now inherit the session's extended-thinking configuration, so anything you delegate reasons at the same depth as your main turn.

So what for TSD: Your fleet work leans hard on subagents and Explore — the loops, the security sweeps, the multi-repo audits. This is a straight quality bump with zero config change, but it also means delegated tasks now cost more tokens per run. Worth it on the hard audits; if you have a cheap mechanical loop, consider pinning it to a smaller model explicitly.

◆ New capabilities to use and sell

New 2.1.198

Claude in Chrome hits general availability

Browser control is out of preview and generally available. That means DOM-aware navigation, clicking, and form-filling you can rely on for real work — verifying a deployed client site behaves, walking a checkout flow, or driving a web app that has no API.

So what for TSD: Use it to smoke-test client launches end to end — click through Bisque's Clay embed, run Studio C's booking path, confirm the State Farm renters funnel actually submits — before you tell a client it's live. It also opens a service line: automating the repetitive browser chores your SMB clients still do by hand.

Changelog · 2.1.198
New 2.1.198

/dataviz skill for charts and dashboards

A new /dataviz skill gives chart and dashboard design guidance and ships a runnable color-palette validator, so the visualizations you generate come out legible and on-palette rather than default-AI garish.

So what for TSD: You build dashboards constantly — the Bisque analytics page, Grant's sales dashboard, the ARENA macro board. Run /dataviz before the next one so the color choices and chart types are deliberate, and use the palette validator to keep client dashboards inside their brand colors instead of eyeballing it.
